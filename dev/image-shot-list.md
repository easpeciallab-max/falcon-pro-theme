# รายการภาพหน้าจอที่ต้องถ่าย · หน้าคู่มือ FALCON PRO EA

เอกสารนี้สำหรับเจ้าของเว็บ บอกว่าหน้าคู่มือแต่ละหน้าต้องใช้ภาพหน้าจออะไร ขั้นไหน และอัปโหลดที่ช่องไหนใน Customizer

- ทั้งหมด **36 ภาพ** (6 หน้า × 6 ขั้น) ไม่มีภาพไหนบังคับ ใส่ทีละหน้าได้
- ภาพเดิมของหน้า How to Install (`assets/img/install/step-0*.jpg`) **ถูกลบออกแล้ว** เพราะเป็นภาพของแบรนด์อื่นและเห็นค่าพารามิเตอร์ในแท็บ Inputs ต้องถ่ายใหม่ตามรายการด้านล่าง
- ข้อความบอกว่าต้องถ่ายอะไรในตารางนี้ ตรงกับช่อง "โน้ตสำหรับแอดมินเมื่อยังไม่มีรูป" (`…_img_note`) ของแต่ละขั้น

## ธีมแสดงภาพอย่างไร

- **ยังไม่ใส่ภาพ:** ผู้เยี่ยมชมเห็นเฉพาะข้อความ ขั้นตอนเรียงเป็นเส้นเวลาแนวตั้ง ไม่มีกรอบว่าง
- **แอดมินที่ล็อกอินอยู่:** เห็นกรอบเส้นประสีส้ม "รอใส่รูป (เห็นเฉพาะแอดมิน)" พร้อมโน้ตว่าต้องถ่ายภาพอะไร ตรงตำแหน่งที่ภาพจะแสดง
- **ใส่ภาพแล้ว:** ขั้นนั้นเป็นสองคอลัมน์ (ข้อความ | ภาพ) สลับซ้ายขวาเฉพาะขั้นที่มีภาพ ใต้ภาพมีป้าย "ภาพ 01, ภาพ 02 …" และกดภาพเพื่อเปิดขนาดเต็มได้
- ภาพแนวตั้งจากมือถือใช้ได้ ธีมจำกัดความสูงที่แสดงไว้ 640px บนคอม และ 540px บนมือถือ แล้ววางภาพไว้กลางกรอบ

## กติกาภาพ (ต้องผ่านทุกข้อก่อนอัปโหลด)

1. **ห้ามมีโลโก้ ชื่อ หรือโดเมนของแบรนด์อื่น** รวมถึงชื่อไฟล์ EA ตัวอื่นในโฟลเดอร์ Experts และชื่อผู้ให้บริการ VPS ถ้าไม่จำเป็น
2. **ห้ามเห็นแท็บ Inputs หรือตารางค่าพารามิเตอร์ของ FALCON PRO EA** ขั้นที่ 5 ของหน้า How to Install ให้ถ่ายเฉพาะปุ่ม Load/Save กับหน้าต่างเลือกไฟล์ .set
3. **ห้ามเห็นรหัสผ่านทุกชนิด** (บัญชีเทรด Client Portal VPS)
4. **เบลอหรือปิดข้อมูลส่วนตัว:** เลขบัญชี (ปิดอย่างน้อยครึ่งหนึ่ง) ยอดเงิน ชื่อ-นามสกุล อีเมล เบอร์โทร และ IP จริงของ VPS (เปลี่ยนเป็นเลขตัวอย่าง เช่น 203.0.113.10 ก็ได้)
5. **ห้ามมีตัวเลขกำไรขาดทุนที่ดูเหมือนผลงานของระบบ** ถ้าเลี่ยงไม่ได้ ให้ใส่คำบรรยายใต้รูป (`…_img_caption`) ว่าเป็นภาพประกอบ ไม่ใช่ผลการเทรดจริง
6. ใช้ภาพที่ถ่ายเองเท่านั้น ห้ามนำภาพจากเว็บอื่นมาใช้
7. เก็บไฟล์ต้นฉบับ (ก่อนเบลอ) ไว้ในเครื่องเท่านั้น ห้ามอัปโหลดไฟล์ต้นฉบับขึ้นเว็บ

## ขนาดและไฟล์

- ภาพจากคอมหรือ VPS: ครอปเฉพาะส่วนที่เกี่ยวข้อง กว้างประมาณ 1280–1600px
- ภาพจากมือถือ: ถ่ายแนวตั้งหรือแนวนอนตามที่ระบุในตาราง ไม่ต้องย่อ
- บันทึกเป็น .webp หรือ .jpg คุณภาพประมาณ 80 ขนาดไม่เกินประมาณ 300 KB ต่อภาพ
- ตั้งชื่อไฟล์เป็นภาษาอังกฤษตัวเล็ก ใช้ขีดกลาง ไม่มีช่องว่าง เช่น `falcon-mt5-login-step-04.webp`

## วิธีอัปโหลด

1. เข้า **รูปแบบ → ปรับแต่ง → FALCON PRO · ตั้งค่าหน้าเว็บ**
2. เลือก section ตามตาราง เช่น "22) หน้า How to Install" หรือ "คู่มือ · VPS บน Windows"
3. ที่ช่อง **"ขั้นที่ N · รูป"** กด Select image แล้วเลือกหรืออัปโหลดภาพ
4. ตรวจช่องที่อยู่ถัดลงมาของขั้นเดียวกัน
   - **คำอธิบายรูป (alt)** มีค่าเริ่มต้นแล้ว แก้ให้ตรงกับภาพจริงถ้าจำเป็น
   - **คำบรรยายใต้รูป** ไม่บังคับ
   - **รูปสำหรับมือถือ** ไม่บังคับ ใส่เมื่อภาพหลักมีตัวหนังสือเล็กจนอ่านไม่ออกบนมือถือ
5. กด **เผยแพร่** แล้วเปิดหน้านั้นในหน้าต่างที่ไม่ได้ล็อกอิน ตรวจว่าภาพขึ้นครบและเบลอถูกจุด
