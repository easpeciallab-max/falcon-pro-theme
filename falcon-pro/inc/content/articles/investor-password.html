เปิด MT5 แล้วเห็นยอดเงินกับออเดอร์ครบ แต่กดซื้อขายไม่ได้ หรือมีคนขอ "รหัสดูพอร์ต" ไปเช็กบัญชีของคุณ สองเรื่องนี้มาจากรหัสผ่านชุดเดียวกันที่ชื่อ Investor Password บทความนี้ตอบว่า Investor Password คืออะไร ต่างจากรหัสอื่นรอบบัญชีอย่างไร เปลี่ยนที่ไหน ควรใช้ตอนไหน และทำอย่างไรเมื่อปุ่มซื้อขายหายไปจากหน้าจอ

สรุปสั้น: บัญชี MT5 หนึ่งบัญชีมีรหัสผ่านสองชุด รหัสผ่านเทรด (Master) ทำได้ทุกอย่าง ส่วน Investor Password ดูยอดเงิน ออเดอร์ และประวัติได้ แต่ส่งคำสั่งซื้อขายไม่ได้ ล็อกอินแล้วไม่มีปุ่มซื้อขายเมื่อไร ให้สงสัยรหัสชุดนี้ก่อน ทั้งสองชุดแยกจากรหัสพื้นที่สมาชิกของโบรกเกอร์ที่ใช้ฝากถอน และแดชบอร์ด FALCON ต้องใช้รหัสผ่านเทรดที่คุณพิมพ์เองในฟอร์มของระบบ

  • คิดว่าเปลี่ยนรหัสพื้นที่สมาชิกแล้วรหัสผ่านเทรดจะเปลี่ยนตาม โดยทั่วไปต้องเปลี่ยนแยกทีละชุด
  • ส่งรหัสดูอย่างเดียวให้คนที่อ้างว่าจะเทรดให้ แล้วถูกขอรหัสผ่านเทรดต่อในขั้นถัดไป

Investor Password ได้มาจากไหน

เมื่อบัญชีเทรด MT5 ถูกสร้าง เซิร์ฟเวอร์จะออกรหัสให้ทั้งสองชุดพร้อมกัน โบรกเกอร์ส่วนใหญ่แจ้งไว้ในอีเมลเปิดบัญชีหรือหน้ารายละเอียดบัญชีในพื้นที่สมาชิก บางแห่งแสดงแค่รหัสผ่านเทรด หรือให้คุณตั้งรหัสเองตอนสร้างบัญชี หาไม่เจอก็ไม่ต้องกังวล ตั้งชุดใหม่ได้ตามหัวข้อถัดไป

บัญชีที่เปิดจากในโปรแกรม MT5 บนคอม เช่น บัญชีทดลอง จะเห็นรหัสทั้งสองชุดในหน้าต่างที่ขึ้นหลังลงทะเบียน ขั้นตอนนี้และหน้าที่ของรหัสแต่ละชุดอธิบายไว้ในหน้า Opening an Account ของ MetaQuotes ซึ่งเป็นภาษาอังกฤษ ได้รหัสมาทางไหนก็ตาม ควรจดเก็บไว้ในที่ปลอดภัยก่อนปิดหน้าต่างหรือลบอีเมล

วิธีตั้งหรือเปลี่ยน Investor Password

ทำได้สองทาง คือในพื้นที่สมาชิกของโบรกเกอร์ และในโปรแกรม MT5 บนคอม ซึ่งต้องรู้รหัสผ่านเทรดปัจจุบันของบัญชี

ในพื้นที่สมาชิกของโบรกเกอร์

เลือกบัญชีเทรดที่ต้องการ แล้วหาเมนูรหัสผ่านของบัญชีนั้น หลายแห่งแยกปุ่มของรหัสสองชุดไว้คนละปุ่ม ชื่อเมนูต่างกันไปตามโบรกเกอร์ และบางแห่งให้เปลี่ยนได้แค่รหัสผ่านเทรด ทางนี้ยังเป็นทางรีเซ็ตเมื่อลืมรหัสผ่านเทรดด้วย

ในโปรแกรม MT5 บนคอม

  1. ล็อกอินบัญชีด้วยรหัสผ่านเทรด เปิดหน้าต่าง Navigator (Ctrl+N) คลิกขวาที่เลขบัญชีแล้วเลือก Change Password หรือเข้าทาง Tools → Options → แท็บ Server แล้วกดปุ่ม Change ชื่อเมนูอาจต่างเล็กน้อยตามรุ่นของโปรแกรม
  2. ใส่รหัสผ่านเทรดปัจจุบัน แล้วเลือกตัวเลือกของรหัสดูอย่างเดียว (Investor) ไม่ใช่ตัวเลือกของรหัสหลัก
  3. พิมพ์รหัสใหม่สองครั้งแล้วยืนยัน ถ้าไม่ผ่าน ลองตั้งให้ยาวขึ้นและผสมตัวพิมพ์ใหญ่ ตัวพิมพ์เล็ก และตัวเลข เพราะโบรกเกอร์อาจกำหนดความซับซ้อนขั้นต่ำไว้

หลังเปลี่ยน เครื่องที่ใช้รหัสดูอย่างเดียวชุดเก่าจะเชื่อมต่อไม่ได้อีก ส่วนรหัสผ่านเทรดไม่เปลี่ยนตาม ถ้าลืมรหัสผ่านเทรดด้วย หรือล็อกอินแล้วขึ้นว่าการอนุญาตล้มเหลว ดูวิธีไล่หาสาเหตุในบทความล็อกอิน MT5 ไม่ได้

ควรใช้ Investor Password ตอนไหน

หลักจำง่าย ๆ คือ ใครที่ต้อง "เห็น" บัญชีแต่ไม่มีเหตุผลต้อง "สั่ง" บัญชี ให้ใช้รหัสชุดนี้

  • ให้คนที่ไว้ใจช่วยดู เช่น คนในครอบครัวที่อยากรู้ว่าเงินก้อนนี้อยู่ในสภาพไหน หรือคนที่คุณขอให้ช่วยอ่านประวัติการเทรด ดูเสร็จแล้วเปลี่ยนรหัสใหม่
  • เครื่องที่คนอื่นหยิบใช้ และการเช็กบัญชีระหว่างวัน บัญชีที่มีบอทเทรดทำงานอยู่ การเข้าแบบดูอย่างเดียวตัดโอกาสที่นิ้วจะเผลอไปปิดออเดอร์
  • เว็บบันทึกสถิติการเทรด ที่ขอรหัสนี้เพื่ออ่านประวัติบัญชี เลือกเว็บที่ตรวจที่มาได้ เพราะเว็บจะเก็บรหัสไว้ฝั่งตัวเอง และเปลี่ยนรหัสทิ้งเมื่อเลิกใช้

ดูอย่างเดียวไม่ได้แปลว่าไม่มีอะไรรั่ว ผู้ถือรหัสเห็นยอดเงิน ขนาด Lot จังหวะเข้าออก และรายการฝากถอนทั้งหมด สัญญาณที่ควรหยุดคิดมีสองแบบ

  • ใครก็ตามที่ขอรหัสผ่านเทรดเพียงเพื่อ "ดูสถิติ" ทั้งที่รหัสดูอย่างเดียวก็เพียงพอ
  • คนแปลกหน้าที่ขอดูพอร์ตก่อน แล้วค่อยชวนให้ส่งรหัสผ่านเทรดเพื่อ "เทรดให้" หรือ "แก้พอร์ต"

รูปแบบการหลอกที่เริ่มจากการขอดูพอร์ตแล้วจบที่การขอรหัสหรือขอให้โอนเงิน รวบรวมวิธีสังเกตไว้ในบทความวิธีเช็กมิจฉาชีพชวนลงทุนเทรดทอง

MT5 ไม่มีปุ่มซื้อขาย หรือปุ่มซื้อขายหาย เกิดจากอะไร

บางคนเห็นปุ่ม Sell กับ Buy เป็นสีเทา บางคนไม่เห็นปุ่มบนกราฟเลย บางคนกดแล้วขึ้นว่าทำรายการไม่สำเร็จ ก่อนลบแอปแล้วลงใหม่ ให้ไล่ตารางนี้จากบนลงล่าง เพราะแถวแรกพบบ่อยที่สุดและแก้ได้ในหนึ่งนาที

อาการสาเหตุที่เป็นไปได้วิธีแก้
กดไม่ได้ทุกสัญลักษณ์ แต่เห็นยอดเงินและออเดอร์ตามปกติล็อกอินด้วย Investor Passwordล็อกอินใหม่ด้วยรหัสผ่านเทรด
บนคอม ปุ่ม Sell และ Buy บนกราฟหายไป แต่หน้าต่าง New Order (F9) ยังใช้ได้แผง One Click Trading ถูกซ่อนกด Alt+T หรือเปิดแผงคืนจากเมนูคลิกขวาของกราฟ (One Click Trading)
กดไม่ได้เฉพาะบางสัญลักษณ์ หรือขึ้นว่าตลาดปิดอยู่นอกเวลาซื้อขาย เช่น สุดสัปดาห์ วันหยุด หรือช่วงพักประจำวันของทองคำดูช่วงเวลาซื้อขายใน Specification ของสัญลักษณ์ แล้วรอตลาดเปิด
สัญลักษณ์หนึ่งส่งคำสั่งไม่ได้ตลอด แม้ตลาดเปิดอยู่โบรกเกอร์ปิดการเทรดสัญลักษณ์นั้น ให้ปิดออเดอร์ได้อย่างเดียว หรือเป็นสัญลักษณ์ของบัญชีประเภทอื่นดูช่อง Trade ใน Specification และเลือกชื่อสัญลักษณ์ที่ตรงกับบัญชี ซึ่งอาจมีอักษรต่อท้าย
ใช้รหัสผ่านเทรดแล้วก็ยังกดไม่ได้ทุกสัญลักษณ์โบรกเกอร์จำกัดสิทธิ์ของบัญชี เช่น ยืนยันตัวตนไม่ครบติดต่อฝ่ายบริการลูกค้าของโบรกเกอร์

เช็กอย่างไรว่าตอนนี้ล็อกอินด้วยรหัสชุดไหน

วิธีที่แน่นอนที่สุดคือล็อกอินซ้ำด้วยรหัสผ่านเทรดที่มั่นใจว่าถูก ถ้าปุ่มกลับมาก็จบเรื่อง บนคอมดูได้อีกทางจากแท็บ Journal ในหน้าต่าง Toolbox (Ctrl+T) หลังล็อกอินมักมีบรรทัดทำนองว่าการเทรดถูกปิดเพราะอยู่ในโหมด investor ต้นเหตุที่พบบ่อยคือคัดลอกรหัสจากอีเมลผิดบรรทัด เพราะรหัสสองชุดวางเรียงติดกัน หรือเคยให้แอปจำรหัสดูอย่างเดียวไว้แล้วลืมไป

ใช้ FALCON ผ่านแดชบอร์ด: รหัสชุดไหนอยู่ตรงไหน

[falcon_brand] เป็นบอทเทรดทองแบบกฎตายตัวสำหรับ XAUUSD บน MT5 ที่ใช้ผ่านแดชบอร์ดสมาชิกอย่างเดียว EA ทำงานบนเซิร์ฟเวอร์ของ FALCON และไม่มีไฟล์ให้ลงเครื่อง เมื่อ EA ต้องเปิดและปิดออเดอร์ในบัญชีของคุณ แดชบอร์ดจึงต้องใช้รหัสผ่านเทรด Investor Password ใช้แทนไม่ได้ เพราะรหัสชุดนั้นส่งคำสั่งไม่ได้ตั้งแต่ต้น

  • รหัสผ่านเทรด คุณพิมพ์เองในฟอร์มเพิ่มบัญชีของแดชบอร์ด ซึ่งเข้ารหัสตั้งแต่อยู่ในเบราว์เซอร์ ในบริการของเรามีที่กรอกรหัสนี้ที่เดียว และสิทธิ์ที่ให้คือการซื้อขายของ EA ไม่รวมการถอนหรือโอนเงิน
  • Investor Password ไม่ใช้กับแดชบอร์ด แต่ใช้ล็อกอินแอป MT5 ของคุณเพื่อดูบัญชีที่ EA กำลังเทรดได้
  • รหัสพื้นที่สมาชิกของโบรกเกอร์ แดชบอร์ดไม่ใช้ ส่วนรหัสสมาชิกแดชบอร์ดควรเปิด 2FA คู่กันไว้เสมอ

แอป MT5 บนมือถือรัน EA ไม่ได้อยู่แล้ว ตามที่อธิบายในบทความใช้ EA บนมือถือได้ไหม แต่มีกรณีหนึ่งที่รหัสดูอย่างเดียวไม่พอ คือหลังกดหยุด EA ในแดชบอร์ด ออเดอร์ที่เปิดอยู่จะไม่ถูกปิดให้ ถ้าตัดสินใจปิดเอง ต้องล็อกอินแอปด้วยรหัสผ่านเทรด วิธีดูออเดอร์ที่ปิดไปแล้วและกำไรขาดทุนย้อนหลังในแอป อยู่ในบทความดูประวัติการเทรดบน MT5 มือถือ

ทีมงานไม่ขอรหัสใดในแชท รวมถึงรหัสดูอย่างเดียว

ทีมงานไม่ขอรหัสผ่านทุกชนิด รหัส 2FA หรือรหัสยืนยัน ไม่ว่าทาง LINE หรือช่องทางใด Investor Password ก็ไม่ขอ เวลามีปัญหา ส่งแค่เลขบัญชี MT5 ชื่อเซิร์ฟเวอร์ และภาพหน้าจอก็พอ ใครใช้ชื่อทีมงานมาขอรหัส ให้ถือว่าเป็นการแอบอ้าง ถ้าเคยส่งรหัสไปในแชทแล้ว ไม่ว่าส่งให้ใคร ให้แก้ตามนี้

  1. เปลี่ยนรหัสชุดนั้นที่โบรกเกอร์ทันที แล้วลบข้อความที่มีรหัสออกจากแชท
  2. ถ้าเป็นรหัสผ่านเทรด ให้พิมพ์รหัสใหม่ที่การ์ดบัญชีในแดชบอร์ดด้วย ไม่อย่างนั้น EA จะเข้าบัญชีไม่ได้ ระบบไม่ลองรหัสที่ผิดซ้ำ เพื่อไม่ให้บัญชีถูกล็อก
  3. ถ้าเป็นรหัสสมาชิกแดชบอร์ด ให้เปลี่ยนในแดชบอร์ดแล้วเปิด 2FA

ขั้นตอนเพิ่มบัญชีและการแก้รหัสที่การ์ดบัญชีอยู่ที่หน้าใช้ FALCON ผ่านแดชบอร์ด ส่วนการลงแอปบนแต่ละอุปกรณ์อยู่ที่คู่มือติดตั้งและล็อกอิน MT5

นิสัยดูแลรหัสผ่าน MT5 ให้ปลอดภัย

  • ตั้งรหัสทุกชุดไม่ซ้ำกัน และไม่ซ้ำกับรหัสอีเมล เพราะอีเมลคือทางรีเซ็ตรหัสอื่นทั้งหมด
  • เปิด 2FA ทุกที่ที่มีให้ ทั้งอีเมล พื้นที่สมาชิกของโบรกเกอร์ และแดชบอร์ด
  • ไม่ให้คอมที่ใช้ร่วมกับคนอื่นจำรหัสผ่านเทรด ใช้รหัสดูอย่างเดียวบนเครื่องแบบนั้นแทน
  • ตรวจภาพหน้าจอก่อนส่งให้ใครว่าไม่มีรหัสติดอยู่ โดยเฉพาะภาพอีเมลเปิดบัญชีจากโบรกเกอร์
  • พิมพ์รหัสผ่านเทรดเฉพาะใน MT5 ที่โหลดจากแหล่งทางการ พื้นที่สมาชิกของโบรกเกอร์ และฟอร์มของแดชบอร์ดที่คุณเปิดเอง ไม่พิมพ์ลงในลิงก์ที่มีคนส่งมาให้

รหัสปลอดภัยไม่ได้แปลว่าเงินปลอดภัย: การดูแลรหัสผ่านกันคนอื่นเข้าบัญชีได้ แต่กันความเสี่ยงของตลาดไม่ได้ ทองคำที่เทรดผ่านบัญชี CFD ใช้เลเวอเรจ บัญชีอาจติดลบหนักภายในวันเดียวจนเสียเงินทุนไปทั้งหมด EA ทุกชุดของ FALCON เปิดออเดอร์แก้แบบกริดพร้อมขยาย Lot และไม่ตัดขาดทุนเอง ตัวเลขกำไรที่บัญชีใดเคยทำได้ ทั้งจากการทดสอบย้อนหลังและจากบัญชีจริง ไม่ได้ผูกมัดว่าช่วงถัดไปจะออกมาแบบเดิม เริ่มด้วยเงินจำนวนน้อยที่เสียไปทั้งก้อนได้ เช่น บัญชี Cent และอ่านประกาศความเสี่ยงก่อนตัดสินใจ
