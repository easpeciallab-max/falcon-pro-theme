เช่าเครื่องแล้ว รีโมตเข้าได้แล้ว ลง MetaTrader 5 เรียบร้อยแล้ว หลายคนคิดว่างานจบตรงนั้น แต่ค่าเริ่มต้นของ Windows ไม่ได้ออกแบบมาสำหรับเครื่องที่ต้องเปิดโปรแกรมเทรดค้างไว้ทั้งสัปดาห์ บทความนี้รวมขั้นตอนตั้งค่า VPS MT5 หลังติดตั้ง เพื่อให้ EA หรือบอทเทรดทำงานต่อเนื่อง และกลับมาพร้อมใช้งานได้เร็วเมื่อเครื่องรีสตาร์ต

สรุปสั้น: งานหลังติดตั้งมีหกเรื่อง คือ กันเครื่องพักตัวเอง คุมเวลารีสตาร์ตของ Windows Update ให้ MT5 เปิดและล็อกอินเองหลังรีบูต ลดการใช้ RAM ตั้งนาฬิกาให้ตรง และจดค่า Ping ไว้อ้างอิง แล้วตรวจตามเช็กลิสต์ทุกครั้งที่เครื่องรีสตาร์ต

ทำไมต้องตั้งค่า VPS MT5 ต่อหลังติดตั้งเสร็จ

EA ไม่ได้ทำงานอยู่บนเซิร์ฟเวอร์ของโบรกเกอร์ แต่ทำงานอยู่ข้างในโปรแกรม MT5 บนเครื่องของคุณ เมื่อ MT5 ถูกปิด หรือ Windows ยังไม่มีผู้ใช้เข้าสู่ระบบ EA ก็เงียบไปด้วยโดยไม่มีเสียงเตือน สาเหตุที่เจอบ่อยไม่ใช่ VPS ล่ม แต่เป็นเรื่องเล็กกว่านั้น เช่น Windows รีสตาร์ตตัวเองกลางดึกเพื่อลงอัปเดต แล้วไม่มีอะไรสั่งให้ MT5 เปิดขึ้นมาใหม่

บทความนี้เริ่มจากจุดที่คุณมีเครื่องและเข้าใช้งานได้แล้ว ถ้ายังเลือกสเปกหรือตำแหน่งเซิร์ฟเวอร์อยู่ อ่าน VPS สำหรับ EA ก่อน ถ้ายังไม่เคยรีโมตเข้าเครื่อง ดู คู่มือเชื่อมต่อ VPS Windows ส่วนการวาง EA ลงกราฟอยู่ใน วิธีติดตั้ง EA

ปิดโหมด Sleep และการพักเครื่อง

เมื่อ Windows เข้าโหมด Sleep ทุกโปรแกรมรวมถึง MT5 จะหยุดนิ่ง แม้ VPS จำนวนมากจะใช้ Windows Server ซึ่งมักไม่ได้เปิดโหมดนี้ไว้ ก็ควรเปิดดูให้เห็นกับตาหนึ่งครั้ง

เข้า Control Panel → Power Options แล้วกด Change when the computer sleeps ตั้งช่อง Put the computer to sleep เป็น Never ถ้าไม่มีตัวเลือก Sleep ให้เลือก มักหมายความว่าเครื่องนั้นไม่ได้เปิดใช้โหมดนี้ ข้ามได้ ส่วนการปิดหน้าจอ (Turn off the display) ไม่กระทบ MT5 เพราะโปรแกรมยังทำงานอยู่เบื้องหลัง

กำหนดเวลารีสตาร์ตของ Windows Update

Windows ต้องรีสตาร์ตเพื่อลงอัปเดตเป็นระยะ เรื่องนี้ห้ามไม่ได้ สิ่งที่ทำได้คือเลือกช่วงเวลาที่ยอมให้เครื่องรีสตาร์ต เครื่องมือที่มีให้คือ Active hours ซึ่งเป็นช่วงเวลาที่เครื่องจะไม่รีสตาร์ตเองเพื่อติดตั้งอัปเดต

  • Windows 11 เข้า Settings → Windows Update → Advanced options → Active hours ส่วน Windows 10 และ Windows Server หลายรุ่นอยู่ใน Settings → Update & Security ชื่อเมนูอาจต่างกันเล็กน้อยตามรุ่น
  • Active hours ตั้งได้ยาวสุด 18 ชั่วโมงใน Windows 10 และ 11 รุ่นปัจจุบัน รวมถึง Windows Server 2019 ขึ้นไป (Windows Server 2016 ตั้งได้สูงสุด 12 ชั่วโมง) จึงครอบคลุมทั้งวันไม่ได้ ให้เว้นช่องว่างไว้ในช่วงที่ตลาดเงียบที่สุดสำหรับสินทรัพย์ที่คุณเทรด
  • ลงอัปเดตเองในวันเสาร์หรืออาทิตย์ที่ตลาด Forex ปิด กด Check for updates ติดตั้งให้ครบ แล้วรีสตาร์ตด้วยตัวเอง เมื่อไม่มีอัปเดตค้าง โอกาสที่เครื่องจะรีสตาร์ตกลางสัปดาห์ก็ลดลง

เคล็ดลับ: อย่าแก้ปัญหาด้วยการปิดอัปเดตถาวร เพราะ VPS ต่ออินเทอร์เน็ตตลอดเวลาและเปิดช่องรีโมตไว้ แพตช์ความปลอดภัยจึงสำคัญมาก ผู้ให้บริการเองก็อาจมีรอบบำรุงรักษา ควรอ่านอีเมลแจ้งเตือนเสมอ

ให้ Windows และ MT5 กลับมาเองหลังรีสตาร์ต

หลังเครื่องบูตเสร็จ ต้องมีสามอย่างเกิดขึ้นตามลำดับ EA จึงจะกลับมาทำงาน คือ (1) มีผู้ใช้เข้าสู่ระบบ Windows (2) MT5 เปิดขึ้นมา และ (3) MT5 ล็อกอินเข้าบัญชีเทรด ขาดข้อใดข้อหนึ่ง ระบบจะค้างอยู่ตรงนั้นจนกว่าคุณจะเข้าไปทำเอง

เข้าสู่ระบบ Windows อัตโนมัติ (Auto-logon)

ปกติหลังรีบูต Windows จะหยุดรอที่หน้าจอใส่รหัสผ่าน และโปรแกรมของผู้ใช้ยังไม่เริ่มจนกว่าจะมีการเข้าสู่ระบบ ทางเลือกแรกคือรีโมตเข้าไปเองทุกครั้งที่เครื่องรีสตาร์ต ทางเลือกที่สองคือเปิด Auto-logon ด้วยเครื่องมือ Autologon ในชุด Sysinternals ของ Microsoft หรือให้ผู้ให้บริการ VPS ตั้งให้

ข้อแลกเปลี่ยนคือรหัสผ่าน Windows จะถูกเก็บไว้ในเครื่อง แม้เข้ารหัสไว้ แต่ผู้ที่มีสิทธิ์ผู้ดูแลระบบดึงออกมาได้ จึงเหมาะกับ VPS ที่รัน MT5 อย่างเดียวและไม่มีคนอื่นเข้าถึง ถ้าไม่สบายใจ ให้ใช้ทางเลือกแรก

วางทางลัด MT5 ในโฟลเดอร์ Startup

บน VPS ให้คลิกขวาที่ปุ่ม Start แล้วเลือก Run จากนั้นพิมพ์ shell:startup เพื่อเปิดโฟลเดอร์ Startup ของบัญชีผู้ใช้ที่ล็อกอินอยู่ หรือจะพิมพ์ shell:startup ในช่องที่อยู่ของ File Explorer บน VPS ก็ได้ผลเหมือนกัน ส่วนคีย์ลัด Windows + R นั้น ตามค่าเริ่มต้นของ Remote Desktop จะไปถึง VPS เฉพาะตอนหน้าต่างรีโมตอยู่ในโหมดเต็มจอ ถ้าเปิดรีโมตแบบหน้าต่าง คีย์ลัดจะไปเปิด Run ของคอมคุณเองแทน

เมื่อได้โฟลเดอร์แล้ว คัดลอกทางลัด (Shortcut) ของ MT5 ไปวาง หลังจากนั้น เมื่อใดที่บัญชีนี้เข้าสู่ระบบ Windows จะเรียก MT5 ขึ้นมาให้โดยไม่ต้องกดเอง ถ้ารัน MT5 หลายตัว ให้วางทางลัดให้ครบทุกตัว

ติ๊ก Save password ตอนล็อกอินบัญชีเทรด

ในหน้าต่างล็อกอินของ MT5 (File → Login to Trade Account) มีช่อง Save password เมื่อติ๊กไว้ ครั้งถัดไปที่เปิดโปรแกรม บัญชีที่ใช้ล่าสุดจะเชื่อมต่อเซิร์ฟเวอร์ให้อัตโนมัติ ถ้าไม่ติ๊ก MT5 จะเปิดขึ้นมาแต่ไม่ต่อบัญชี และ EA จะเทรดไม่ได้ ดูรายละเอียดที่ คู่มือล็อกอิน MT5

ทดสอบจริงหนึ่งรอบ: ตั้งเสร็จแล้วให้สั่ง Restart ในวันที่ตลาดปิด แล้วรีโมตกลับเข้าไปดูว่า MT5 เปิดอยู่หน้าต่างเดียวต่อหนึ่งบัญชี เชื่อมต่อแล้ว และ EA อยู่บนกราฟเดิม

ลดการใช้ RAM ของ MT5

VPS ราคาประหยัดมักมี RAM ไม่มาก และ Windows เองก็ใช้ไปส่วนหนึ่งแล้ว เมื่อหน่วยความจำใกล้เต็ม เครื่องจะช้าลงจนโปรแกรมค้างได้

ปรับ Max bars in chart

เข้า Tools → Options → แท็บ Charts จะมีช่อง Max bars in chart ซึ่งกำหนดจำนวนแท่งราคาที่แสดงบนกราฟ ยิ่งแสดงมากและมี Indicator หลายตัว ก็ยิ่งใช้ CPU และ RAM ค่าต่ำสุดที่ตั้งได้คือ 5000 และต้องปิดเปิด MT5 ใหม่ค่าจึงมีผล ก่อนลดค่าลงมาก ให้ดูคู่มือของ EA ก่อนว่าต้องการข้อมูลย้อนหลังบนกราฟเท่าไร

ปิดกราฟและสัญลักษณ์ที่ไม่ได้ใช้

  • เหลือไว้เฉพาะกราฟที่มี EA ทำงานอยู่ กราฟสำหรับดูเฉย ๆ ให้เปิดบนคอมหรือมือถือของคุณแทน
  • ซ่อนสัญลักษณ์ที่ไม่ได้เทรดออกจาก Market Watch และถอด Indicator ที่ไม่จำเป็นออกจากกราฟ
  • การรัน Backtest หรือ Optimization ใน Strategy Tester กินทรัพยากรเครื่องมาก ให้ทำบนคอมส่วนตัว แล้วปล่อย VPS ไว้รันบัญชีจริงอย่างเดียว

จากนั้นคลิกขวาที่ปุ่ม Start ของ VPS แล้วเลือก Task Manager ดูแท็บ Performance (คีย์ลัด Ctrl + Shift + Esc ใช้กับ VPS ได้เมื่อหน้าต่างรีโมตอยู่ในโหมดเต็มจอ ไม่เช่นนั้นจะเปิด Task Manager ของคอมคุณเอง) ถ้าหน่วยความจำใกล้เต็มตลอดทั้งที่ปรับแล้ว แปลว่าสเปกเล็กเกินไปสำหรับจำนวน MT5 ที่เปิด

ตั้งเวลาเครื่องให้ตรงและรู้จักเวลาเซิร์ฟเวอร์

เข้า Settings → Time & language → Date & time เปิด Set time automatically ถ้ามีปุ่ม Sync now ให้กดหนึ่งครั้ง (Windows Server รุ่นเก่าอย่าง 2016 และ 2019 ไม่มีปุ่มนี้ในหน้า Settings ให้เปิด Set time automatically ไว้ก็พอ) นาฬิกาที่ตรงช่วยให้เวลาในบันทึกการทำงาน (Log) เชื่อถือได้เมื่อต้องย้อนดูเหตุการณ์ และ EA บางตัวอาจอ่านเวลาจากนาฬิกาของเครื่อง

อย่าสับสนกับเวลาเซิร์ฟเวอร์ของโบรกเกอร์ แท่งราคาและเวลาของออเดอร์ใน MT5 อ้างอิงเวลาของเซิร์ฟเวอร์เทรด ซึ่งมักไม่ตรงกับเวลาไทยหรือนาฬิกาของ VPS เรื่องนี้เป็นเรื่องปกติ จึงไม่ต้องตั้งนาฬิกาเครื่องให้เท่ากับเวลาบนกราฟ

เช็กค่า Ping จาก MT5 ไปเซิร์ฟเวอร์โบรกเกอร์

มุมขวาล่างของ MT5 มีตัวแสดงสถานะการเชื่อมต่อ ใน MT5 รุ่นปัจจุบันจะมีค่า Ping เป็นมิลลิวินาที (ms) กำกับอยู่ ตัวเลขนี้คือเวลาที่ข้อมูลใช้เดินทางระหว่าง VPS กับเซิร์ฟเวอร์เทรด ยิ่งต่ำแปลว่าสองฝั่งอยู่ใกล้กัน

ไม่มีตัวเลขตายตัวที่ใช้ได้กับทุกระบบ ให้จดค่าในวันแรกไว้เป็นค่าอ้างอิง แล้วเทียบเมื่อเข้าไปตรวจครั้งต่อไป ถ้าสูงขึ้นมากและค้างอยู่หลายวัน ให้แจ้งผู้ให้บริการหรือพิจารณาย้ายตำแหน่งเซิร์ฟเวอร์ ค่า Ping ที่สูงเพิ่มโอกาสที่ราคาจะขยับก่อนคำสั่งไปถึง ดูบทความ Spread และ Slippage

เช็กลิสต์หลังรีบูตทุกครั้ง

ไม่ว่าเครื่องจะรีสตาร์ตด้วยเหตุใด ให้เข้าไปตรวจตามลำดับนี้

  1. MT5 เปิดอยู่และต่อบัญชีถูกต้อง

    ดูเลขบัญชีที่แถบชื่อโปรแกรม ดูสถานะการเชื่อมต่อมุมขวาล่าง และราคาใน Market Watch ต้องขยับในช่วงที่ตลาดเปิด

  2. ปุ่ม Algo Trading เปิดอยู่

    ดูสองจุด จุดแรกคือปุ่ม Algo Trading ด้านบนของโปรแกรมยังกดเปิดค้างอยู่ จุดที่สองคือไอคอนข้างชื่อ EA ตรงมุมขวาบนของกราฟ ซึ่งต้องไม่ขึ้นเป็นสถานะปิด

  3. EA อยู่บนกราฟเดิม ค่าไม่เปลี่ยน

    ตรวจสัญลักษณ์และ Timeframe ของกราฟ ถ้าใช้ [falcon_brand] ให้เทียบกับไฟล์ Preset และคู่มือที่ได้รับ หากสงสัยว่าค่าเปลี่ยน ให้โหลด Preset ซ้ำแทนการแก้ทีละช่องจากความจำ

  4. อ่านแท็บ Experts และ Journal

    ดูข้อความล่าสุดในหน้าต่าง Toolbox หลังเวลาที่เครื่องบูต ถ้ามีข้อผิดพลาดซ้ำ ๆ ให้บันทึกภาพหน้าจอไว้ก่อนแก้ไข

  5. เทียบออเดอร์ที่เปิดค้าง

    ดูแท็บ Trade ว่าออเดอร์ตรงกับที่คุณคาดไว้ก่อนเครื่องรีสตาร์ต

  6. ออกด้วยการ Disconnect

    ปิดหน้าต่างรีโมตด้วยปุ่ม X ของแถบเชื่อมต่อ ไม่ใช่ Sign out เพราะ Sign out จะปิดทุกโปรแกรมรวมถึง MT5

ถ้าตรวจครบแล้ว EA ยังไม่เปิดออเดอร์ ไล่สาเหตุได้จากบทความ EA ไม่เปิดออเดอร์ และวางรอบตรวจประจำตาม กิจวัตรดูแล EA

ความปลอดภัยพื้นฐานของ VPS ที่รัน EA

เครื่องที่ล็อกอินบัญชีเทรดค้างไว้และบันทึกรหัสผ่านใน MT5 ต้องระวังเป็นพิเศษ ใครเข้า VPS ได้ก็เท่ากับเข้าบัญชีเทรดของคุณได้

  • เปลี่ยนรหัสผ่าน Windows จากค่าที่ผู้ให้บริการส่งมาครั้งแรก ใช้รหัสที่ยาวและไม่ซ้ำกับบริการอื่น
  • เปิด Windows Security และ Firewall ไว้ตามค่าเริ่มต้น และลงเฉพาะโปรแกรมที่จำเป็น
  • ถ้าให้คนอื่นรีโมตเข้ามาช่วย ให้เปลี่ยนรหัสผ่านทันทีเมื่อเสร็จ ถ้าแค่ให้ดูบัญชี ใช้ Investor password ของ MT5 ซึ่งดูได้แต่เทรดไม่ได้
  • ไม่นำไฟล์ .ex5 หรือ DLL ที่ไม่รู้ที่มาไปรันบนเครื่องที่มีบัญชีจริง ตัวเลือก Allow DLL imports ควรเปิดเฉพาะกับโปรแกรมที่เชื่อถือได้ ดูสัญญาณอันตรายที่ เตือนภัย EA หลอกลวง
  • ไม่ส่งรหัสผ่านหลัก (Master password) ของบัญชีเทรดให้ใคร ไม่ว่าจะอ้างเหตุผลใด

คำเตือนความเสี่ยง: การตั้งค่าในบทความนี้ช่วยลดปัญหาทางเทคนิคเท่านั้น ไม่ได้ทำให้การเทรดปลอดภัยขึ้นหรือได้กำไรมากขึ้น การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง คุณอาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลการทดสอบและผลการเทรดในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต แม้ VPS จะเสถียร ก็ควรติดตามบัญชีด้วยตัวเองอย่างสม่ำเสมอ อ่านเพิ่มเติมที่ การเปิดเผยความเสี่ยง

คำถามที่พบบ่อยเรื่องการตั้งค่า VPS สำหรับ MT5

ตั้ง Active hours ให้ครอบคลุมตลอด 24 ชั่วโมงได้ไหม?

ไม่ได้ Windows ให้ตั้งได้ยาวสุด 18 ชั่วโมงต่อวัน (Windows Server 2016 ได้ 12 ชั่วโมง) วิธีที่ได้ผลกว่าคือลงอัปเดตและรีสตาร์ตเองในวันหยุดสุดสัปดาห์

VPS รีสตาร์ตตอนมีออเดอร์ค้างอยู่ จะเกิดอะไรขึ้น?

ออเดอร์ที่เปิดแล้ว รวมถึง Stop Loss และ Take Profit ที่ตั้งไว้กับออเดอร์นั้น เก็บอยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์ จึงยังอยู่แม้ MT5 ปิด แต่การจัดการที่ EA ทำเอง เช่น การเลื่อนจุดปิดหรือการปิดออเดอร์ตามเงื่อนไขของระบบ จะไม่เกิดขึ้นจนกว่า MT5 จะกลับมาทำงาน ช่วงที่ขาดไปจึงเป็นความเสี่ยงที่ต้องทำให้สั้นที่สุด

ตั้งค่าครบแล้ว ยังต้องเข้าไปดู VPS อีกไหม?

ต้องดู การตั้งค่าที่ดีไม่ได้แทนการติดตาม ควรเข้าไปตรวจสั้น ๆ วันละครั้งในวันที่ตลาดเปิด และทุกครั้งหลังได้รับแจ้งบำรุงรักษา ทำจากมือถือได้ตามคู่มือ VPS บน Android และ VPS บน iPhone

คู่มือที่เกี่ยวข้อง

  • เชื่อมต่อ Windows VPS ด้วย Remote Desktop
  • VPS สำหรับ EA: สเปกและตำแหน่งเซิร์ฟเวอร์
  • วิธีติดตั้ง EA บน MT5
  • กิจวัตรตรวจระบบ EA รายวันและรายสัปดาห์
  • EA ไม่เปิดออเดอร์บน MT5: สาเหตุและวิธีเช็ก

ถ้าตั้งค่า VPS MT5 ตามเช็กลิสต์นี้แล้วยังติดอยู่ขั้นไหน หรือมีคำถามเรื่องการติดตั้ง [falcon_brand] และการโหลดไฟล์ Preset ส่งภาพหน้าจอมาถามทีมงานทาง LINE ได้ โดยไม่ต้องส่งรหัสผ่านใด ๆ เราจะช่วยแนะนำขั้นตอนถัดไปให้
