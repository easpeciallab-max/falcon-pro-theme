ได้ไฟล์ EA มาแล้วอยากรู้ว่ามันเคยเทรดทองย้อนหลังออกมาแบบไหน คำถามถัดมาคือ Backtest MT5 ยังไง ต้องกดตรงไหน และแต่ละช่องควรตั้งเป็นอะไร บทความนี้พาทำจริงบน MT5 ฉบับคอม ตั้งแต่วางไฟล์จนเซฟรายงาน พร้อมวิธีไล่แก้เมื่อทดสอบแล้วไม่มีออเดอร์ ส่วนหลักคิดและความหมายของรายงานอยู่ในบทความBacktest คืออะไร

สรุปสั้น: วางไฟล์ EA ใน MQL5 → Experts แล้ว Refresh ใน Navigator เปิด Strategy Tester ด้วย Ctrl+R ตั้ง Symbol ให้ตรงกับชื่อในบัญชี ใช้โหมด Every tick based on real ticks กับ EA เทรดทองแบบกริดหรือเก็บกำไรสั้น ใส่เงินฝากกับ Leverage ที่จะใช้จริง แล้วกด Start รอบแรกช้าเพราะต้องโหลดประวัติราคา ส่วนแอปมือถือทดสอบไม่ได้

Backtest MT5 ยังไง: ภาพรวมและของที่ต้องเตรียม

วิธี Backtest MT5 ในบทความนี้มีห้าขั้น คือ วางไฟล์ ตั้งค่าตัวทดสอบ ตรวจพารามิเตอร์ กดเริ่ม และอ่านผล ปัญหาส่วนใหญ่มาจากการเตรียมไม่ครบ จึงเช็กรายการนี้ก่อน

  • MT5 ฉบับคอม บน Windows หรือฉบับ Mac ของ MetaQuotes แอปมือถือและหน้าเว็บไม่มีตัวทดสอบ
  • ล็อกอินบัญชีของโบรกเกอร์ที่จะใช้จริงค้างไว้ ตัวทดสอบดึงประวัติราคาและสเปกของสัญลักษณ์จากเซิร์ฟเวอร์นั้น
  • ไฟล์ EA สำหรับ MT5 ไฟล์ .ex5 ใช้ได้ทันที ไฟล์ .mq5 ต้องคอมไพล์ก่อน ส่วนไฟล์ของ MT4 ใช้ไม่ได้
  • คู่มือของ EA บอกสัญลักษณ์ Timeframe ทุนที่ต้องมี และค่าที่ไม่ควรแตะ
  • ไฟล์จากแหล่งที่ไว้ใจได้ ไฟล์ที่ส่งต่อกันในกลุ่มแชทอาจถูกดัดแปลง

ขั้นที่ 1: นำไฟล์ EA เข้าโฟลเดอร์ MQL5 → Experts

MT5 อ่าน EA จากโฟลเดอร์ข้อมูล (Data Folder) ของตัวเองเท่านั้น และ MT5 แต่ละตัวในเครื่องมีโฟลเดอร์แยกกัน

  1. เปิดโฟลเดอร์ข้อมูล

    ใน MT5 ตัวที่จะใช้ทดสอบ ไปที่เมนู File → Open Data Folder โปรแกรมจะเปิดโฟลเดอร์ของตัวเองให้ ไม่ต้องไล่หาใน Program Files

  2. วางไฟล์ใน MQL5 → Experts

    คัดลอกไฟล์ EA มาไว้ที่นี่ หรือในโฟลเดอร์ย่อยก็ได้ ไฟล์เสริมให้วางใน Indicators หรือ Libraries ตามที่คู่มือบอก

  3. สั่ง Refresh ใน Navigator

    กด Ctrl+N ให้หน้าต่าง Navigator ขึ้นมา คลิกขวาตรงกลุ่ม Expert Advisors แล้วกด Refresh ถ้าชื่อ EA ยังไม่ขึ้น ปิดแล้วเปิดโปรแกรมใหม่หนึ่งรอบ

  4. คอมไพล์ถ้าได้มาเป็นซอร์สโค้ด

    เปิดไฟล์ .mq5 ด้วย MetaEditor (กด F4 ใน MT5) แล้วกด Compile ส่วนไฟล์ของ MT4 เปลี่ยนนามสกุลแล้วก็ยังใช้ไม่ได้ ต้องขอเวอร์ชัน MT5 จากผู้พัฒนา

ขั้นที่ 2: เปิด Strategy Tester MT5 แล้วตั้งค่าแท็บ Settings

กด Ctrl+R หรือเมนู View → Strategy Tester แผงทดสอบจะเปิดด้านล่างของโปรแกรม ถ้าเปิดมาที่แท็บ Overview ให้เลือกการทดสอบ EA แบบรอบเดียว (Single) แล้วไปที่แท็บ Settings ตรวจว่าช่อง Optimization เป็น Disabled ไม่อย่างนั้นการกด Start จะกลายเป็นการไล่ลองค่าหลายร้อยชุด ซึ่งมีกับดักของตัวเองตามบทความOptimize EA และ Overfitting ชื่อเมนูอาจต่างกันตามรุ่น เทียบได้กับหน้าอธิบาย Strategy Tester ของ MetaTrader 5 (ภาษาอังกฤษ)

ช่องตั้งเป็นเหตุผล
ExpertEA ที่เพิ่งวางไว้ตรวจชื่อและเวอร์ชันให้ตรงกับตัวที่จะใช้
Symbolชื่อทองคำที่บัญชีของคุณเทรดได้รวมอักษรหรือจุดต่อท้ายทุกตัว
Timeframe (ถัดจาก Symbol)ตามคู่มือของ EAตั้งผิด บางระบบไม่เปิดออเดอร์เลย
DateCustom periodช่วงยาวพอจะรวมหลายสภาพตลาด
ForwardNoสำหรับการทดสอบรอบเดียว
DelaysRandom delayแบบ Zero latency ได้ราคาทันทีทุกคำสั่ง ดีกว่าตลาดจริง
ModellingEvery tick based on real ticksช้าที่สุด แต่ใกล้การซื้อขายจริงที่สุด
Deposit และ Leverageตัวเลขและสกุลเงินที่จะใช้จริงทุนหรือ Leverage ต่างจากจริง ผลก็เทียบกันไม่ได้
Profit in pips for faster calculationsไม่ติ๊กโหมดนี้คิดกำไรเป็นจุด ไม่ใช่เป็นเงิน

Symbol: ใช้ชื่อเดียวกับใน Market Watch

ชื่อทองคำไม่มีมาตรฐานกลาง อาจเป็น XAUUSD, XAUUSDm หรือ GOLD แล้วแต่โบรกเกอร์และประเภทบัญชี ให้ใช้ชื่อที่ตรงกับ Market Watch ของบัญชีที่จะเทรดจริง เพราะขนาดสัญญา Lot ขั้นต่ำ และ Spread ผูกอยู่กับชื่อนั้น (คลิกขวาที่สัญลักษณ์แล้วเลือก Specification เพื่อดูสเปก)

Modelling: EA เทรดทองควรใช้ tick จริง

EA ที่ปิดกำไรระยะสั้นหรือวางออเดอร์แก้เป็นชั้นถี่แบบกริด ได้รับผลมากจากลำดับที่ราคาแตะแต่ละจุดภายในนาทีเดียว โหมด tick จริงใช้ราคาที่โบรกเกอร์บันทึกไว้พร้อม Spread ที่ขยับตามจริง จึงควรใช้กับรอบที่จะนำผลไปตัดสินใจ โหมดที่หยาบกว่าใช้ลองว่า EA ทำงานหรือไม่ได้ แต่อย่าเอาตัวเลขไปเทียบกับบัญชีจริง ช่วงที่ไม่มี tick จริง ตัวทดสอบจะสร้างราคาจากแท่ง 1 นาทีแทน วันเริ่มจึงควรอยู่ในช่วงที่มีข้อมูลจริง

Deposit กับ Leverage: ตั้งเหมือนวันที่ใช้เงินจริง

Leverage ที่สูงกว่าบัญชีจริงทำให้ EA ในรายงานถือออเดอร์ได้มากกว่าที่บัญชีของคุณรับไหว เงินฝากที่มากเกินจริงก็ทำให้ช่วงติดลบดูตื้นกว่าที่จะเจอ ถ้าล็อกอินบัญชี Cent อยู่ ให้ดูว่าหน่วยเงินฝากในตัวทดสอบเป็นเซ็นต์หรือดอลลาร์

ขั้นที่ 3: ตรวจค่าของ EA ในแท็บ Inputs

แท็บ Inputs รวมค่าทุกตัวที่ EA ยอมให้แก้ อย่างขนาด Lot หรือระยะห่างของออเดอร์ ดับเบิลคลิกช่อง Value เพื่อแก้ค่า ถ้ามีไฟล์ชุดค่า (.set) คลิกขวาในตารางแล้วเลือก Load และใช้ Save เก็บชุดที่ทดสอบไว้ใช้ซ้ำ

  • อย่าติ๊กช่องหน้าชื่อพารามิเตอร์ ช่องนั้นใช้บอกว่าจะไล่ลองค่าไหนตอน Optimize
  • Lot ต้องไม่ต่ำกว่าขั้นต่ำของสัญลักษณ์ และต้องลงตัวกับ Volume step ไม่อย่างนั้นทุกคำสั่งจะถูกปฏิเสธ
  • EA ที่ต้องใส่รหัสไลเซนส์หรือล็อกกับเลขบัญชี ถามผู้พัฒนาก่อนว่าโหมดทดสอบต้องตั้งอย่างไร

ขั้นที่ 4: กด Start แล้วรอประวัติราคา

กดปุ่ม Start ที่มุมขวาล่างของแผง ตัวทดสอบจะโหลดประวัติราคาของช่วงที่เลือกจากเซิร์ฟเวอร์ของโบรกเกอร์ให้เอง รอบแรกของแต่ละสัญลักษณ์ช้าที่สุด โดยเฉพาะโหมด tick จริง รอบต่อไปเร็วขึ้นเพราะข้อมูลเก็บอยู่ในเครื่องแล้ว ระหว่างนี้ต้องต่ออินเทอร์เน็ตไว้ ถ้าหลุดกลางทาง ข้อมูลอาจไม่ครบ ซึ่งดูได้จากค่า History Quality ที่หัวรายงาน

ขั้นที่ 5: อ่านผลในแท็บ Backtest, Graph และ Journal แล้วเซฟรายงาน

เมื่อทดสอบจบ ผลจะแยกอยู่หลายแท็บ (MT5 บางรุ่นเรียกแท็บ Backtest ว่า Results)

แท็บเห็นอะไรใช้ตอบคำถาม
Backtestหัวรายงานที่บอกเงื่อนไข ตัวเลขสรุป และรายการดีลทุกรายการผลรวมเท่าไร ติดลบลึกสุดแค่ไหน เทรดกี่ไม้
Graphเส้น Balance และ Equity ตลอดช่วงทดสอบบัญชีเคยถูกกดลงแรงตอนไหน
Journalบันทึกของตัวทดสอบ ข้อความจาก EA และคำสั่งที่ถูกปฏิเสธทำไมไม่มีออเดอร์ หรือจบเร็วผิดปกติ
  • Profit Factor ต้องอ่านคู่กับจำนวนเทรดเสมอ วิธีอ่านอยู่ในบทความProfit Factor คืออะไร
  • สัดส่วนไม้ชนะที่สูงไม่ได้แปลว่าปลอดภัย เหตุผลอยู่ในบทความWin Rate คืออะไร
  • EA ที่ถือออเดอร์ติดลบไว้ ให้ดู Equity Drawdown มากกว่า Balance Drawdown

เซฟรายงานไว้เทียบทีหลัง

คลิกขวาในแท็บ Backtest เลือกเมนู Report แล้วเลือกรูปแบบ แบบ HTML เปิดในเบราว์เซอร์ได้ทันที แบบ XML เปิดใน Excel เพื่อกรองรายการดีลต่อได้ ตั้งชื่อไฟล์ให้บอกเงื่อนไข เช่น ชื่อและเวอร์ชันของ EA สัญลักษณ์ โหมดราคา และช่วงวันที่ แล้วเก็บไฟล์ชุดค่าไว้คู่กัน

Backtest MT5 มือถือได้ไหม

ไม่ได้ แอป MT5 บน Android และ iPhone ไม่มี Strategy Tester และไม่มีที่ให้ EA ทำงานตั้งแต่แรก ไม่เกี่ยวกับรุ่นโทรศัพท์ หน้าเว็บของ MT5 ก็ไม่มีเครื่องมือนี้ ทางที่ทำได้คือทดสอบบนคอม Windows หรือ Mac แล้วใช้มือถือดูบัญชีจริงทีหลัง หน้าที่ของ MT5 แต่ละเวอร์ชันสรุปไว้ในบทความMT5 คืออะไร

Backtest MT5 ไม่ได้ หรือไม่มีออเดอร์: ไล่แก้ทีละอาการ

ตัวทดสอบมักบอกสาเหตุไว้ในแท็บ Journal หาบรรทัดที่มีคำว่า failed หรือ error แล้วเทียบกับตารางนี้ ข้อความจริงอาจต่างตาม EA และรุ่นของโปรแกรม

อาการหรือข้อความสาเหตุที่พบบ่อยวิธีแก้
ไม่เห็น EA ในช่อง Expertไฟล์อยู่ผิดโฟลเดอร์ ยังไม่ Refresh หรือเป็นไฟล์ MT4วางใน MQL5 → Experts ของโปรแกรมตัวที่ใช้ แล้ว Refresh
จบแล้วไม่มีเทรด และ Journal ไม่มีข้อผิดพลาดSymbol หรือ Timeframe ไม่ตรงกับที่ EA ออกแบบ หรือช่วงวันที่สั้นเกินไปตั้งตามคู่มือ แล้วขยายช่วงวันที่
Invalid volumeLot ต่ำกว่าขั้นต่ำ หรือไม่ลงตัวกับ Volume stepดู Specification แล้วแก้ Lot ใน Inputs
Not enough money หรือ No moneyเงินฝากไม่พอ Margin ของ Lot ที่ขอเปิดใส่เงินฝากเท่าที่จะใช้จริง หรือลด Lot ให้สมดุลกับทุน
จบก่อนวันที่ตั้งไว้ และ Journal พูดถึง Stop Outเงินในบัญชีจำลองรับขาดทุนลอยตัวไม่ไหวนี่คือผลทดสอบ ไม่ใช่ข้อผิดพลาด อย่าแก้ด้วยการใส่ทุนเกินจริง
History Quality ต่ำ หรือไม่มีข้อมูลราคาประวัติโหลดไม่ครบ หรือวันเริ่มเก่ากว่าข้อมูลที่โบรกเกอร์มีตรวจการเชื่อมต่อ ขยับวันเริ่มให้ใหม่ขึ้น แล้วทดสอบซ้ำ
หยุดทันทีหรือแจ้งเรื่องไลเซนส์EA ตรวจสิทธิ์ผ่านอินเทอร์เน็ต ซึ่งโดยทั่วไปทำไม่ได้ในตัวทดสอบถามผู้พัฒนาว่ามีวิธีทดสอบแบบไหน
แจ้งเรื่อง DLLEA เรียกไฟล์ DLL ภายนอก ซึ่ง MT5 ปิดไว้เป็นค่าเริ่มต้นเปิด Allow DLL imports (Tools → Options แท็บ Expert Advisors หรือหน้าตั้งค่าของ EA แล้วแต่รุ่น) เฉพาะ EA ที่ไว้ใจได้

ปุ่ม Algo Trading ไม่เกี่ยวกับการทดสอบ

ปุ่ม Algo Trading บนแถบเครื่องมือคุม EA ที่วางบนกราฟจริง โดยทั่วไป Strategy Tester ทำงานได้ไม่ว่าปุ่มนี้จะเปิดหรือปิด ถ้า Backtest ผ่านแต่ EA ไม่เปิดออเดอร์บนบัญชีจริง ปัญหาอยู่อีกชุดหนึ่ง ไล่เช็กได้ตามบทความEA ไม่เปิดออเดอร์บน MT5

เช็กลิสต์ให้ผล Backtest EA MT5 เทียบกับบัญชีจริงได้

รายงานที่มีประโยชน์คือฉบับที่เงื่อนไขใกล้วันที่คุณใช้เงินจริงมากที่สุด ไม่ใช่ฉบับที่ตัวเลขสวยที่สุด

  • ข้อมูลมาจากเซิร์ฟเวอร์ของโบรกเกอร์และประเภทบัญชีที่จะใช้จริง และ Symbol ตรงทุกตัวอักษร
  • Spread มาจาก tick จริง และรายการดีลมีค่าคอมมิชชันกับ Swap ตามที่บัญชีจริงคิด (บางกรณีตัวทดสอบอาจหักไม่ครบ ต้องเปิดดูเอง)
  • เงินฝาก สกุลเงิน และ Leverage เท่ากับที่จะใช้จริง
  • EA เวอร์ชันเดียวกันและค่าใน Inputs ชุดเดียวกับที่จะรัน
  • ช่วงทดสอบมีทั้งช่วงที่ทองวิ่งแรงทางเดียว ช่วงแกว่งแคบ และวันประกาศข่าวสำคัญ
  • ขยับวันเริ่มหรือวันจบเล็กน้อยแล้วทดสอบซ้ำ ถ้าผลพลิกมาก แปลว่าตัวเลขพึ่งจังหวะเฉพาะช่วงนั้น

ไม่ได้ [falcon_brand] เป็น EA เทรดทองคำ XAUUSD บน MT5 ที่ใช้ผ่านแดชบอร์ดสมาชิกอย่างเดียว ระบบรันบนเซิร์ฟเวอร์ของ FALCON ลูกค้าไม่ได้รับไฟล์ไปวางในโฟลเดอร์ Experts ขั้นตอนข้างบนจึงใช้กับ EA ตัวอื่นที่คุณมีไฟล์อยู่ ส่วนการใช้ FALCON ไม่ต้องเปิดคอมทิ้งไว้ ไม่ต้องเช่า VPS แอป MT5 มีไว้ดูบัญชีเท่านั้น

ระบบมีสองรุ่น คือ EA FALCON รุ่น 1.10 (FALCON PRO, FALCON PLUS, FALCON ULTRA, FALCON FURY) และ FALCON 5.0 (FALCON SCOUT, FALCON HUNTER, FALCON APEX) ทุกชุดแก้ออเดอร์ที่ราคาวิ่งสวนด้วยการเปิดเพิ่มเป็นกริดพร้อมขยาย Lot และไม่มีชุดไหนตัดขาดทุนเอง ผลทดสอบของทั้งเจ็ดชุดพร้อมเงื่อนไขและข้อจำกัดอยู่ที่หน้าผล Backtest ของ FALCON ใช้เช็กลิสต์ข้างบนตรวจได้เหมือนผลของคนอื่น ส่วนวิธีเริ่มใช้งานอยู่ที่หน้าใช้ FALCON ผ่านแดชบอร์ด

อ่านก่อนนำผลทดสอบไปใช้: รายงานจาก Strategy Tester คือการจำลองกับราคาที่ผ่านไปแล้ว ไม่ใช่คำสัญญาว่าบัญชีจริงจะออกมาแบบเดียวกัน และกำไรที่เคยเกิดในอดีตไม่ได้รับรองผลข้างหน้า การเทรดทองคำแบบ CFD ที่ใช้ Leverage ทำให้เงินในบัญชีหายได้หมดทั้งก้อน โดยเฉพาะระบบที่ถือออเดอร์ติดลบไว้โดยไม่ตัดขาดทุน ซึ่งรวมถึงทุกชุดของ FALCON ถ้าจะเริ่มกับเงินจริง ใช้เงินจำนวนน้อยที่เสียได้ทั้งหมด เช่น บัญชี Cent และอ่านประกาศความเสี่ยงให้จบก่อน เนื้อหานี้มีไว้เพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน

คำถามที่พบบ่อย

Backtest MT5 ยังไง ถ้าสรุปให้สั้นที่สุด?

วางไฟล์ EA ใน MQL5 → Experts เปิด Strategy Tester ด้วย Ctrl+R ตั้งค่าในแท็บ Settings ให้ตรงกับบัญชีที่จะใช้จริง ตรวจแท็บ Inputs กด Start แล้วอ่านผลในแท็บ Backtest กับ Graph

Backtest MT5 มือถือได้ไหม?

ไม่ได้ แอป MT5 บน Android และ iPhone ไม่มี Strategy Tester และรัน EA ไม่ได้ ต้องใช้ MT5 ฉบับคอมบน Windows หรือ Mac

ทำไม Backtest แล้วไม่มีออเดอร์เลย?

เปิดแท็บ Journal ก่อน สาเหตุที่พบบ่อยคือ Symbol หรือ Timeframe ไม่ตรงกับที่ EA ออกแบบ Lot ต่ำกว่าขั้นต่ำ เงินฝากไม่พอ Margin ประวัติราคาโหลดไม่ครบ หรือ EA ต้องตรวจไลเซนส์ผ่านอินเทอร์เน็ต

Backtest ใช้เงินในบัญชีจริงไหม?

ไม่ใช้ ตัวทดสอบไม่ส่งคำสั่งเข้าตลาด เงินฝากในตัวทดสอบเป็นตัวเลขที่คุณกรอกเอง แต่ต้องล็อกอินบัญชีของโบรกเกอร์ไว้เพื่อดึงประวัติราคา ควรเป็นเซิร์ฟเวอร์เดียวกับบัญชีที่จะใช้เทรด
