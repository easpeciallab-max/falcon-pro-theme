หลายคนอยากให้บอทเทรดทำงานแทนระหว่างวัน แล้วเปิดดูผลจากโทรศัพท์ตอนว่าง คำถามแรกจึงมักเป็น "ใช้ EA บนมือถือได้ไหม" คำตอบสั้นคือแอป MT5 บน Android และ iPhone ใช้ดูบัญชีและส่งคำสั่งด้วยมือได้ แต่ไม่มีที่ให้ EA ทำงาน บทความนี้อธิบายว่าแอปทำอะไรได้ และมีทางไหนให้ระบบเทรดต่อโดยคุณไม่ต้องเฝ้าคอม ถ้ายังไม่แน่ใจว่าบอทเทรดทองทำงานอย่างไร อ่านภาพรวมของบอทเทรดทองและ EAก่อนได้

สรุปสั้น: EA ทำงานได้ในโปรแกรม MT5 สำหรับคอมพิวเตอร์เท่านั้น แอปบนมือถือรัน EA ไม่ได้ ถ้าอยากให้ระบบเทรดต่อตอนคุณไม่อยู่หน้าจอ มีสามทาง คือเปิดคอม Windows ของตัวเองค้างไว้ เช่า VPS หรือใช้บริการที่รัน EA บนเซิร์ฟเวอร์ของผู้ให้บริการ ทุกทางยังต้องใช้มือถือดูบัญชี และไม่มีทางไหนลดความเสี่ยงของตลาดได้

EA รันบนมือถือได้ไหม

ไม่ได้ แอป MetaTrader 5 บน Android และ iPhone ไม่มีรายการ EA ให้เลือก ไม่มีปุ่ม Algo Trading และไม่มีเมนูให้วาง EA ลงกราฟ เพราะ EA คือโปรแกรมที่เขียนด้วยภาษา MQL5 แล้วคอมไพล์เป็นไฟล์ (นามสกุล .ex5) ซึ่งต้องทำงานข้างในโปรแกรม MT5 สำหรับคอมพิวเตอร์ที่เปิดอยู่และต่อกับเซิร์ฟเวอร์ของโบรกเกอร์

ข้อจำกัดนี้มาจากตัวแอป ไม่ได้ขึ้นกับรุ่นโทรศัพท์หรือโบรกเกอร์ ไม่มี EA Forex ตัวไหนรันในแอปมือถือของ MT5 ได้ ไม่ว่าจะเทรดค่าเงินหรือทองคำ และหน้าเว็บเทรดของ MT5 ก็รัน EA ไม่ได้เช่นกัน

EA บนคอมส่งการแจ้งเตือนมาที่มือถือได้

สิ่งที่ทำได้คือการแจ้งเตือนทางเดียว เมื่อกรอก MetaQuotes ID ของแอปไว้ในเมนู Tools → Options → Notifications ของ MT5 บนคอม โปรแกรมจะส่งข้อความแบบ Push มาที่มือถือได้ และ EA บางตัวใช้ช่องทางนี้แจ้งตอนเปิดหรือปิดออเดอร์ แต่มือถือสั่งงาน EA กลับทางนี้ไม่ได้

แอป MT5 บนมือถือทำอะไรได้บ้าง

แม้รัน EA ไม่ได้ แอปก็ขาดไม่ได้ เพราะเข้าบัญชีเดียวกับที่ EA ใช้ และเห็นทุกอย่างในบัญชีนั้น

  • ราคาเรียลไทม์และกราฟ พร้อมอินดิเคเตอร์ที่ติดมากับแอป
  • Balance, Equity, Margin และ Margin Level ของบัญชี
  • ออเดอร์ที่เปิดอยู่ ทั้งที่คุณเปิดเองและที่ EA เปิด
  • เปิด ปิด หรือแก้ Stop Loss และ Take Profit ด้วยมือ เมื่อล็อกอินด้วยรหัสผ่านเทรด
  • ประวัติการเทรด รายการฝากถอน และการแจ้งเตือนจาก MT5 บนคอม

ส่วนงานที่ทำในแอปไม่ได้เลยมีดังนี้

  • วาง EA ลงกราฟ หรือเปิดการเทรดอัตโนมัติ
  • รันสคริปต์ หรือใช้อินดิเคเตอร์ที่ดาวน์โหลดมาเอง
  • ทดสอบ EA ย้อนหลังด้วย Strategy Tester

รายการความสามารถทั้งหมดอยู่ในคู่มือ MT5 สำหรับ iPhone และคู่มือฉบับ Android ของ MetaQuotes ซึ่งเป็นภาษาอังกฤษ ส่วนขั้นตอนลงแอปและล็อกอินเป็นภาษาไทยอยู่ที่หน้าติดตั้งและล็อกอิน MT5 พื้นฐานของตัวโปรแกรมทั้งหมดอยู่ในบทความMT5 คืออะไร

ใช้ EA บนมือถือได้แค่ไหน: มือถือเป็นจอดู ไม่ใช่เครื่องรัน

ออเดอร์ทุกตัวถูกเก็บที่เซิร์ฟเวอร์ของโบรกเกอร์ ไม่ใช่ในเครื่องที่ EA ทำงาน ไม่ว่า EA จะรันจากคอมที่บ้าน VPS หรือเซิร์ฟเวอร์ของผู้ให้บริการ แอปบนมือถือที่ล็อกอินบัญชีเดียวกันจะเห็นออเดอร์ชุดเดียวกันแทบทันที นี่คือความหมายที่ใช้ได้จริงของการใช้ EA บนมือถือ คือเครื่องหนึ่งทำงาน อีกเครื่องหนึ่งใช้ดู

ออเดอร์ที่เปิดแล้ว รวมถึง Stop Loss และ Take Profit ที่ผูกไว้กับออเดอร์ ยังอยู่ครบแม้เครื่องที่รัน EA ดับ แต่งานที่ EA ทำเองระหว่างทาง เช่น เปิดออเดอร์แก้ หรือปิดทั้งชุดเมื่อถึงเป้า จะหยุดทันทีที่ EA หยุด แอปบนมือถือไม่ได้ทำแทน

สามทางให้บอทเทรดทำงานต่อเมื่อคุณไม่อยู่หน้าคอม

เมื่อมือถือรัน EA ไม่ได้ ต้องมีเครื่องอื่นเปิด MT5 ค้างไว้แทน ทางเลือกที่ใช้กันจริงมีสามแบบ

ทางแรก: คอม Windows ของตัวเองที่เปิดค้างไว้

ลง MT5 บนคอมที่บ้าน วาง EA บนกราฟ แล้วเปิดเครื่องทิ้งไว้ตลอดช่วงที่ตลาดเปิด ทางนี้ไม่มีค่าเช่า แต่มีค่าไฟ จุดอ่อนคือทุกอย่างผูกกับสภาพของบ้านคุณ ไฟตก เน็ตบ้านสะดุด เครื่องพักจนหลับ หรือ Windows สั่งรีสตาร์ตกลางดึก ล้วนทำให้ EA เงียบไปโดยไม่มีใครรู้

ทางที่สอง: เช่า VPS

VPS คือเครื่อง Windows เสมือนในศูนย์ข้อมูลที่เปิดอยู่ตลอด คุณรีโมตเข้าไปลง MT5 กับ EA เอง ไฟและเน็ตเสถียรกว่าที่บ้าน แลกกับค่าเช่ารายเดือนหรือรายปี และงานดูแลที่ยังเป็นของคุณ ทั้งให้ MT5 ล็อกอินเองหลังรีบูต จัดเวลาอัปเดต Windows ต่ออายุให้ทัน และเก็บรหัสเข้าเครื่องให้ดี เพราะเครื่องนั้นล็อกอินบัญชีเทรดค้างไว้ตลอด เรื่องสเปกอยู่ในบทความVPS สำหรับ EA ส่วนการตั้งค่าหลังลงโปรแกรมอยู่ในเช็กลิสต์ตั้งค่า VPS ให้ MT5 รันต่อเนื่อง

ทางที่สาม: บริการที่รัน EA บนเซิร์ฟเวอร์ของผู้ให้บริการ

ทางนี้คุณไม่ได้ถือไฟล์ EA และไม่ต้องดูแลเครื่องใดเลย ผู้ให้บริการรัน MT5 กับ EA บนเซิร์ฟเวอร์ของตัวเอง โดยล็อกอินบัญชีเทรดในชื่อของคุณ คุณสั่งเริ่มและสั่งหยุดผ่านหน้าเว็บ แล้วใช้แอป MT5 ตรวจบัญชีซ้ำ ถ้าต้องการ EA ที่ไม่ต้องเปิดคอมและไม่ต้องดูแลเครื่องเอง ทางนี้ตรงที่สุด แลกกับการต้องไว้ใจระบบของคนอื่น และต้องรู้ว่ารหัสผ่านของคุณถูกส่งและเก็บอย่างไร

เทียบสามทางในตารางเดียว

หัวข้อคอมของตัวเองเช่า VPSบริการรัน EA บนเซิร์ฟเวอร์
สิ่งที่คุณต้องมีคอม Windows ที่เปิดค้าง เน็ตบ้าน และไฟล์ EAVPS Windows ไฟล์ EA และแอปรีโมตบัญชี MT5 ที่บริการรองรับ เบราว์เซอร์ และแอป MT5 ไว้ดู
ใครติดตั้งและดูแลคุณเองทั้งหมดผู้ให้เช่าดูแลฮาร์ดแวร์ คุณดูแล Windows, MT5 และ EAผู้ให้บริการดูแลเซิร์ฟเวอร์ MT5 และ EA คุณเลือกชุด สั่งเริ่ม และสั่งหยุด
ค่าใช้จ่ายของการรันค่าไฟและค่าเครื่องค่าเช่าต่อเนื่องรายเดือนหรือรายปีตามเงื่อนไขของแต่ละบริการ (FALCON จ่ายครั้งเดียวตามแพ็กเกจ ไม่มีค่ารายเดือน)
จุดที่มักพังไฟดับ เน็ตหลุด เครื่องหลับ Windows รีสตาร์ตเองรีบูตแล้ว MT5 ไม่ล็อกอินกลับ ลืมต่ออายุ รอบบำรุงรักษาเซิร์ฟเวอร์ เน็ต MT5 หรือระบบของโบรกเกอร์ขัดข้อง
รหัสผ่านเทรดอยู่ที่ไหนในเครื่องของคุณบน VPS ที่ล็อกอินค้างไว้ในระบบของผู้ให้บริการ ต้องรู้ว่าส่งและเก็บอย่างไร
ความเสี่ยงของตลาดและกลยุทธ์ EAเท่าเดิมทุกข้อเท่าเดิมทุกข้อเท่าเดิมทุกข้อ

ข้อที่เหมือนกันทุกทาง: เครื่องที่เสถียรช่วยให้ EA ทำงานต่อเนื่องเท่านั้น ไม่ได้ทำให้กลยุทธ์ปลอดภัยขึ้น ถ้าราคาวิ่งสวนทางแรง บัญชีขาดทุนได้เท่ากันไม่ว่า EA จะรันอยู่ที่ไหน

FALCON PRO EA ใช้ทางที่สาม: EA ทำงานบนแดชบอร์ด

[falcon_brand] เทรดทองคำ XAUUSD บน MT5 อย่างเดียว และใช้ผ่านแดชบอร์ดสมาชิกเท่านั้น EA ทำงานบนเซิร์ฟเวอร์ของ FALCON ไม่มีไฟล์ EA หรือไฟล์ชุดค่าส่งให้ลูกค้า ไม่มีอะไรต้องติดตั้งในเครื่องของคุณ ไม่ต้องเปิดคอมค้าง และไม่ต้องเช่า VPS แอป MT5 มีไว้ดูบัญชี และใช้ปิดออเดอร์เองเมื่อหยุด EA แล้ว

ชุด EA ที่เลือกได้มีสองระบบ คือ EA FALCON รุ่น 1.10 (FALCON PRO, FALCON PLUS, FALCON ULTRA และ FALCON FURY) กับ FALCON 5.0 (FALCON SCOUT, FALCON HUNTER และ FALCON APEX) ทุกชุดทำงานตามกฎตายตัว เมื่อราคาสวนทางจะเปิดออเดอร์แก้แบบกริดพร้อมขยาย Lot และไม่ตัดขาดทุนเอง รายละเอียดของแต่ละชุดอยู่ที่หน้าวิธีใช้ FALCON ผ่านแดชบอร์ด ส่วนเส้นทางโดยย่อเป็นแบบนี้

  1. เปิดบัญชี MT5 เงินจริงและฝากเงิน

    ใช้บัญชีจริงของโบรกเกอร์ที่แดชบอร์ดรองรับ บัญชี Cent ใช้ได้ บัญชี Demo เชื่อมไม่ได้ และผู้ใช้ต้องอายุ 20 ปีขึ้นไป

  2. ลงแอป MT5 บนมือถือไว้ดูบัญชี

    ล็อกอินบัญชีเดียวกันในแอป เพื่อเห็นยอดเงินและออเดอร์ด้วยตาตัวเอง

  3. คุยกับทีมงานและรับรหัสเชิญ

    เลือกแพ็กเกจ แจ้งเลขบัญชี MT5 แล้วรับรหัสเชิญสำหรับสมัครสมาชิก ขั้นนี้ไม่ต้องส่งรหัสผ่านใดทั้งสิ้น

  4. เพิ่มบัญชีในแดชบอร์ด เลือกชุด แล้วกดเริ่ม

    คุณพิมพ์รหัสผ่านเทรดของ MT5 เองในฟอร์มของแดชบอร์ด และกดหยุด EA ได้ทุกเมื่อ

แพ็กเกจที่เสียเงินจ่ายครั้งเดียวและรวมการรันบนแดชบอร์ดไว้แล้ว ไม่มีค่ารายเดือน ดูระดับแพ็กเกจได้ที่หน้าแพ็กเกจและราคา คำว่ารวมไว้หมายถึงค่าใช้จ่ายเท่านั้น ระบบยังขัดข้องได้ คุณจึงยังต้องเปิดแอป MT5 ดูบัญชีเป็นประจำ ถ้าเพิ่งเริ่ม ให้ใช้เงินจำนวนน้อยที่ยอมเสียได้ทั้งหมด เช่น บัญชี Cent ขั้นตอนตั้งแต่ยังไม่มีบัญชีจนระบบเริ่มทำงาน เล่าไว้ละเอียดในบทความวิธีใช้ EA เทรดทองสำหรับมือใหม่

ก่อนให้ใครรัน EA แทน ต้องเช็กอะไรบ้าง

บริการแบบทางที่สามต้องเข้าบัญชีเทรดของคุณได้จริงจึงจะเทรดได้ คำถามต่อไปนี้ใช้กับทุกบริการ รวมถึงของเราเองด้วย

  • ใครพิมพ์รหัสผ่านเทรด และพิมพ์ที่ไหน คุณควรพิมพ์รหัสผ่านเทรด (Master Password) เองในฟอร์มของระบบ ไม่ใช่ส่งทางแชทหรืออีเมล ทีมงานของ FALCON ไม่ขอรหัสผ่านหรือรหัสยืนยันใดทางแชท
  • รหัสหน้าสมาชิกของโบรกเกอร์ไม่เกี่ยว รหัสที่ใช้ฝากถอนเงินไม่ควรให้ใครเลย การรัน EA ใช้แค่รหัสผ่านเทรดของ MT5
  • Investor Password ใช้ดูได้อย่างเดียว รหัสนี้ส่งคำสั่งซื้อขายไม่ได้ จึงใช้รัน EA ไม่ได้
  • กดหยุดแล้วออเดอร์เป็นอย่างไร ที่แดชบอร์ดของ FALCON การหยุด EA ไม่ปิดออเดอร์ที่เปิดอยู่ ออเดอร์ยังกำไรหรือขาดทุนตามราคาต่อไปจนกว่าคุณจะปิดเองในแอป MT5
  • ระบบล่มแล้วเกิดอะไรขึ้น เซิร์ฟเวอร์ อินเทอร์เน็ต โปรแกรม MT5 หรือระบบของโบรกเกอร์ขัดข้องได้เสมอ ช่วงนั้น EA อาจไม่ได้ดูแลออเดอร์ทั้งที่หน้าเว็บยังเปิดได้
  • เงินอยู่ที่ไหน และจ่ายแบบไหน เงินควรอยู่ในบัญชีเทรดชื่อของคุณกับโบรกเกอร์ ส่วนค่าบริการควรรู้ว่าจ่ายครั้งเดียว รายเดือน หรือแบ่งกำไร

โฆษณาที่ขายบอทเทรด MT5 มือถือ มักเป็นแบบใดแบบหนึ่งในนี้

  • รันบนเครื่องอื่น แล้วดูจากมือถือ ตรงกับหลักการ ให้ถามต่อตามรายการด้านบน
  • สัญญาณหรือ Copy Trade ผู้ขายเทรดเองแล้วคัดลอกออเดอร์มาที่บัญชีคุณ ซึ่งไม่ใช่ EA ในบัญชีของคุณ และเสี่ยงคนละแบบ
  • แอปที่ไม่ได้เชื่อมกับโบรกเกอร์จริง โชว์กำไรสวยงามแต่ถอนเงินไม่ได้ เป็นรูปแบบที่มิจฉาชีพใช้บ่อย

สัญญาณที่ควรหยุดคุยทันที

  • ขอให้โอนเงินเข้าบัญชีส่วนตัวหรือบัญชีของผู้ให้บริการเพื่อ "เทรดให้"
  • ขอรหัส OTP รหัส 2FA หรือรหัสหน้าสมาชิกของโบรกเกอร์
  • สัญญากำไรตายตัวทุกเดือน หรือบอกว่าไม่มีทางขาดทุน
  • ส่งไฟล์แอปให้ลงนอก App Store หรือ Google Play โดยอ้างว่าเป็น EA Forex บนมือถือ

วิธีตรวจและกลโกงที่พบบ่อยอยู่ในบทความเตือนภัย EA หลอกลวง

ดูแลบัญชีจากมือถือเมื่อ EA ทำงานอยู่ที่อื่น

ไม่ว่าเลือกทางไหน มือถือคือจุดที่เห็นปัญหาก่อนใคร ใช้เวลาไม่กี่นาทีต่อวันดูเรื่องเหล่านี้

  • เทียบ Equity กับ Balance ถ้า Equity ต่ำกว่ามากและห่างออกไปเรื่อย ๆ แปลว่ามีออเดอร์ติดลบสะสม
  • ดู Margin Level ว่ายังห่างจากระดับ Margin Call และ Stop Out แค่ไหน ระดับนี้ต่างกันไปตามโบรกเกอร์และประเภทบัญชี
  • นับจำนวนออเดอร์และดูขนาด Lot ล่าสุด สำหรับ EA แบบกริด ตัวเลขนี้บอกว่าระบบแก้ไปแล้วกี่ชั้น
  • ถ้าตลาดเปิดแต่บัญชีนิ่งนานผิดปกติ ให้ตรวจสถานะของเครื่องหรือบริการที่รัน EA

ถ้าต้องการหยุดระบบ ให้หยุด EA จากที่ที่มันทำงานก่อน แล้วค่อยจัดการออเดอร์ที่ค้างในแอป เพราะ EA หลายแบบ โดยเฉพาะแบบกริดที่นับออเดอร์เป็นชุด ทำงานคลาดได้เมื่อมีออเดอร์ถูกปิดหรือเพิ่มเข้ามาจากภายนอก รอบตรวจแบบละเอียดอยู่ในบทความกิจวัตรตรวจ EA

ก่อนใช้เงินจริง: ทองคำ Forex และ CFD ที่เทรดด้วยเลเวอเรจเป็นสินทรัพย์เสี่ยงสูง คุณอาจเสียเงินทุนทั้งหมดในบัญชี EA แบบกริดที่ไม่ตัดขาดทุนเองเสียหายได้ถึงทั้งบัญชีเมื่อราคาวิ่งทางเดียว ผลทดสอบหรือผลที่ผ่านมาไม่ได้บอกว่าอนาคตจะเป็นแบบเดิม จึงควรใส่เฉพาะเงินที่ยอมเสียได้ และอ่านประกาศความเสี่ยงก่อนเริ่ม

คำถามที่พบบ่อย

ลง EA MT5 บนมือถือ iPhone หรือ Android ได้ไหม?

ไม่ได้ ไม่ว่ารุ่นไหนหรือโบรกเกอร์ไหน แอป MT5 บนมือถือก็ไม่มีส่วนสำหรับวางหรือรัน EA ตัว EA ต้องทำงานในโปรแกรม MT5 บนคอม บน VPS หรือบนเซิร์ฟเวอร์ของผู้ให้บริการ แล้วใช้แอปดูผล

ใช้ EA โดยไม่ต้องเช่า VPS ได้ไหม?

ได้ ทางหนึ่งคือเปิดคอม Windows ของตัวเองค้างไว้ ซึ่งต้องรับความเสี่ยงเรื่องไฟและเน็ตบ้าน อีกทางคือใช้บริการที่รัน EA บนเซิร์ฟเวอร์ของผู้ให้บริการ เช่น [falcon_brand] ที่ใช้ผ่านแดชบอร์ด ซึ่งไม่ต้องเช่า VPS และไม่ต้องเปิดคอมค้าง

ปิดแอปหรือปิดมือถือแล้ว EA ยังทำงานอยู่ไหม?

ยังทำงาน เพราะ EA ไม่ได้อยู่ในมือถือ EA จะหยุดเมื่อเครื่องที่รันมันดับหรือหลุดจากเน็ต เมื่อโปรแกรม MT5 ที่รัน EA ถูกปิด หรือเมื่อคุณสั่งหยุด

ล็อกอินแอปด้วย Investor Password แทนรหัสผ่านเทรดได้ไหม?

ได้ และเหมาะถ้าต้องการดูอย่างเดียว คุณจะเห็นยอดเงิน ออเดอร์ และประวัติได้ครบ แต่เปิดหรือปิดออเดอร์ไม่ได้ ถ้าอยากเก็บทางปิดออเดอร์เองไว้ยามจำเป็น ต้องล็อกอินด้วยรหัสผ่านเทรด
