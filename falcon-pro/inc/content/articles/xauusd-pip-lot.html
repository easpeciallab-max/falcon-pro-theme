ราคาทองขยับจาก 4,000.00 ไป 4,001.00 คนหนึ่งเรียก 100 จุด อีกคนเรียก 10 pip อีกคนบอกแค่ 1 ดอลลาร์ ทั้งที่พูดถึงการขยับครั้งเดียวกัน ถ้าคุณเคยงงว่า XAUUSD นับจุดยังไง หน้านี้เรียงให้ตั้งแต่ Point ของ MT5 Pip ที่แต่ละคนนับไม่ตรงกัน เงินต่อ Lot เป็นดอลลาร์และบาท จนถึงคำถามว่า 1 Lot ทองเท่ากับกี่บาท ตัวเลขทุกตัวเป็นตัวอย่างสมมติ

สรุปสั้น: หนึ่ง Point ใน MT5 คือขั้นราคาที่เล็กที่สุด ราคาทองทศนิยมสองตำแหน่ง 1 Point = 0.01 ดอลลาร์ ทศนิยมสามตำแหน่ง 1 Point = 0.001 ดอลลาร์ ส่วน Pip ไม่มีนิยามกลาง ที่ได้ยินบ่อยคือ 0.10 ถ้า 1 Lot = 100 ออนซ์ ราคาขยับ 1.00 ดอลลาร์ ออเดอร์ 1 Lot ได้หรือเสีย 100 USD และ 0.01 Lot ได้หรือเสีย 1 USD สเปกจริงดูได้จาก Digits กับ Contract size ในหน้า Specification ของบัญชีคุณ

ในตัว MT5 หน่วยที่ใช้นับระยะราคาคือ Point คือหนึ่งหน่วยของหลักขวาสุดหลังจุดทศนิยม ส่วนจำนวนหลักหลังจุดเรียกว่า Digits บัญชีส่วนใหญ่แสดงราคาทองสองตำแหน่ง เช่น 4,000.25 บางบัญชีแสดงสามตำแหน่ง เช่น 4,000.253

  • Digits = 3: 1 Point = 0.001 ราคาขยับ 1.00 ดอลลาร์ เท่ากับ 1,000 Point

ระยะราคาเท่ากัน แต่จำนวนจุดต่างกันสิบเท่า และเรื่องนี้สำคัญกับบอทเทรดด้วย เพราะ EA บน MT5 ส่วนใหญ่รับระยะ Stop Loss หรือระยะห่างของออเดอร์เป็นหน่วย Point ค่า 300 บนบัญชีหนึ่งจึงเท่ากับ 3.00 ดอลลาร์ แต่บนอีกบัญชีเท่ากับ 0.30 ดอลลาร์

เปิดดู Digits และ Contract size ในบัญชีของคุณ

บน MT5 ในคอมพิวเตอร์ เปิดหน้าต่าง Market Watch คลิกขวาที่ชื่อทอง แล้วเลือก Specification ในแอปมือถือ แตะชื่อทองในหน้าราคาแล้วเลือกเมนูดูรายละเอียดของสัญลักษณ์ (ชื่อเมนูต่างกันตามรุ่นแอป) ช่องที่ต้องจดมีสามช่อง

  • Digits: จำนวนทศนิยมของราคา บอกว่า 1 Point เท่ากับเท่าไร
  • Contract size: จำนวนออนซ์ในออเดอร์ขนาด 1 Lot
  • Tick size และ Tick value (ถ้าหน้าต่างแสดง): ขั้นราคาที่เล็กที่สุด กับมูลค่าของขั้นนั้นต่อ 1 Lot บัญชีสกุล USD ที่ Tick size 0.01 และ 1 Lot = 100 ออนซ์ ควรเห็น Tick value ราว 1

0.01 Lot ทองเท่ากับกี่บาท?

ถ้าหมายถึงเงินต่อการขยับ บนบัญชีที่ 1 Lot = 100 ออนซ์ ออเดอร์ 0.01 Lot ได้หรือเสียราว 1 USD ต่อราคา 1.00 ดอลลาร์ หรือราว 33 บาทที่อัตราสมมติ 33 บาท ถ้าหมายถึงมูลค่าทองในออเดอร์ คือทอง 1 ออนซ์ตามราคาขณะนั้น ส่วน Margin ที่ต้องวางขึ้นกับ Leverage และเงื่อนไขทองของโบรกเกอร์

ราคาทองขยับ 1 ดอลลาร์ เท่ากับกี่จุด?

100 จุดบนบัญชีที่ราคามีทศนิยมสองตำแหน่ง และ 1,000 จุดบนบัญชีทศนิยมสามตำแหน่ง ดูจำนวนทศนิยมได้จากช่อง Digits ในหน้า Specification ของทองในบัญชีคุณ

ทำไมกำไรขาดทุนในแอป MT5 ไม่ตรงกับที่คิดจากตาราง?

ที่เจอบ่อยคือ Spread, ค่าคอมมิชชัน และ Swap ที่ตารางยังไม่หัก Contract size ของบัญชีไม่ใช่ 100 ออนซ์ หรือบัญชีแสดงเงินเป็นเซ็นต์หรือสกุลอื่น ให้เทียบกับหน้า Specification ทีละช่อง
