EA ทำงานได้เฉพาะตอนที่ MT5 เปิดอยู่และเชื่อมต่อเซิร์ฟเวอร์ ถ้าคุณอยากให้บอทเทรดทำงานต่อเนื่องโดยไม่ต้องเปิดคอมที่บ้านทิ้งไว้ VPS สำหรับ EA คือคำตอบที่คนส่วนใหญ่เลือก บทความนี้อธิบายว่า VPS คืออะไร เลือกสเปกและตำแหน่งเซิร์ฟเวอร์อย่างไร และดูแลให้ปลอดภัยได้แบบไหน

สรุปสั้น: VPS คือเครื่อง Windows เสมือนที่เปิดอยู่ตลอดเวลาในศูนย์ข้อมูล คุณติดตั้ง MT5 และ EA ไว้บนนั้น แล้วรีโมตเข้าไปดูจากคอมหรือมือถือได้ เลือกเซิร์ฟเวอร์ที่อยู่ใกล้เซิร์ฟเวอร์โบรกเกอร์ ใช้รหัสผ่านที่แข็งแรง และตรวจระบบอย่างสม่ำเสมอ

VPS สำหรับ EA คืออะไร

VPS ย่อมาจาก Virtual Private Server คือการแบ่งทรัพยากรของเซิร์ฟเวอร์ขนาดใหญ่ออกเป็นเครื่องเสมือนหลายเครื่อง แต่ละเครื่องมีระบบปฏิบัติการ หน่วยความจำ และพื้นที่ของตัวเอง สำหรับสายเทรดอัตโนมัติ เรามักเช่า VPS ที่เป็น Windows เพื่อติดตั้ง MetaTrader 5 แล้วปล่อยให้ EA ทำงานบนนั้นตลอด 24 ชั่วโมง

คุณเชื่อมต่อเข้า VPS ผ่านโปรแกรม Remote Desktop จากคอมพิวเตอร์ หรือผ่านแอป Windows App บนมือถือ (ชื่อเดิมคือ Remote Desktop) หน้าจอที่เห็นจะเหมือนใช้คอมพิวเตอร์ Windows อีกเครื่องหนึ่ง

ทำไมบอทเทรดต้องรันบน VPS

ปัญหาของการรัน EA บนคอมที่บ้านไม่ได้อยู่ที่ความแรงของเครื่อง แต่อยู่ที่ความต่อเนื่อง เหตุการณ์ธรรมดาอย่างไฟดับ เน็ตหลุด เครื่องเข้าโหมด Sleep หรือ Windows รีสตาร์ตเพื่ออัปเดต ล้วนทำให้ EA หยุดส่งคำสั่งได้ทั้งสิ้น ถ้าเกิดขึ้นช่วงที่มีออเดอร์เปิดอยู่ ระบบอาจจัดการออเดอร์ไม่ได้ตามที่ออกแบบไว้

อีกเหตุผลคือความหน่วง (Latency) ระหว่างเครื่องที่รัน MT5 กับเซิร์ฟเวอร์เทรดของโบรกเกอร์ ยิ่งอยู่ใกล้ คำสั่งยิ่งไปถึงเร็ว ซึ่งสำคัญมากสำหรับระบบที่เทรดบ่อยหรือเก็บกำไรระยะสั้น

VPS เทียบกับคอมพิวเตอร์ที่บ้าน

ค่าใช้จ่ายมีค่าเช่ารายเดือนไม่มีค่าเช่า แต่มีค่าไฟและค่าเสื่อมเครื่อง

ตำแหน่งเซิร์ฟเวอร์และค่า Latency

หลักสำคัญคือเลือก VPS ที่อยู่ใกล้เซิร์ฟเวอร์เทรดของโบรกเกอร์ ไม่ใช่ใกล้บ้านคุณ เพราะคำสั่งซื้อขายเดินทางจาก VPS ไปยังโบรกเกอร์โดยตรง โบรกเกอร์หลายแห่งตั้งเซิร์ฟเวอร์ไว้ในศูนย์ข้อมูลใหญ่ของยุโรปหรือเอเชีย สอบถามโบรกเกอร์หรือดูจากเอกสารของโบรกเกอร์ได้

วิธีเช็กง่าย ๆ คือล็อกอิน MT5 บน VPS แล้วดูตัวเลขมุมขวาล่างของโปรแกรม ซึ่งแสดงสถานะการเชื่อมต่อและค่า Ping เป็นมิลลิวินาที ยิ่งต่ำยิ่งดี ถ้าตัวเลขสูงผิดปกติ ให้ลองคลิกที่ช่องนั้นแล้วเลือกสแกนเซิร์ฟเวอร์ใหม่ หรือพิจารณา VPS ในตำแหน่งอื่น

Virtual Hosting ของ MT5 เทียบกับ Windows VPS

นอกจากเช่า Windows VPS จากผู้ให้บริการทั่วไป MT5 ยังมีบริการ Virtual Hosting ของ MetaQuotes ในตัว ทั้งสองแบบมีจุดเด่นต่างกัน

Virtual Hosting ในตัว MT5

เช่าได้จากในโปรแกรม โดยคลิกขวาที่บัญชีเทรดในหน้าต่าง Navigator แล้วเลือก Register a Virtual Server ระบบจะเลือกเซิร์ฟเวอร์ที่ใกล้โบรกเกอร์ให้อัตโนมัติ ชำระเงินผ่านบัญชี MQL5.community จากนั้นใช้การซิงก์ (Migration) ส่งกราฟ EA และ Indicator จาก MT5 เครื่องของคุณขึ้นไปทำงาน

  • ไม่มีหน้าจอ Windows ให้รีโมตเข้าไปใช้ ต้องแก้ไขที่เครื่องตัวเองแล้วซิงก์ใหม่ทุกครั้ง
  • ห้ามเรียกใช้ DLL ถ้า EA ต้องใช้ DLL จะทำงานบนบริการนี้ไม่ได้
  • Script ไม่ถูกย้ายขึ้นไป และเช่าผูกกับบัญชีเทรดทีละบัญชี

หลังย้าย EA ขึ้นไปแล้ว MT5 จะปิด Algo Trading บนเครื่องของคุณให้อัตโนมัติ เพื่อป้องกันการเปิดออเดอร์ซ้ำจากสองที่

เชื่อมต่อ VPS จากคอมพิวเตอร์และมือถือ

บนคอมพิวเตอร์ Windows ใช้โปรแกรม Remote Desktop Connection ที่มีมาในเครื่อง ส่วนบนมือถือใช้แอป Windows App ทำตามขั้นตอนพร้อมภาพประกอบได้ที่ คู่มือ VPS Windows, เชื่อม VPS จาก Android และ เชื่อม VPS จาก iPhone และ iPad

เคล็ดลับ: เมื่อดูระบบเสร็จ ให้ปิดหน้าต่าง Remote Desktop ด้วยการกดปิดหรือ Disconnect ห้ามกด Sign out เพราะ Sign out จะปิดโปรแกรมทั้งหมด รวมถึง MT5 ที่รัน EA อยู่

เคล็ดลับความปลอดภัยของ VPS

VPS ที่รัน EA เชื่อมอยู่กับบัญชีเทรดของคุณ จึงควรดูแลเหมือนเป็นกระเป๋าเงินใบหนึ่ง

  • ตั้งรหัสผ่าน VPS ให้ยาว เดายาก และไม่ซ้ำกับบริการอื่น
  • ไม่แชร์รหัสผ่าน VPS หรือรหัสผ่านหลักของบัญชีเทรดกับใคร ถ้าจำเป็นต้องให้คนช่วยดู ให้เปลี่ยนรหัสผ่านทันทีเมื่อเสร็จ
  • ถ้าต้องการให้คนอื่นดูผลอย่างเดียว ใช้ Investor Password ของ MT5 ซึ่งดูได้แต่เทรดไม่ได้
  • เปิดการยืนยันตัวตนสองขั้นตอนกับบัญชีผู้ให้บริการ VPS ถ้าผู้ให้บริการมีให้
  • ติดตั้ง Windows Update อย่างสม่ำเสมอ และลงเฉพาะโปรแกรมที่จำเป็น
  • ไม่เปิดเว็บหรือดาวน์โหลดไฟล์ที่ไม่รู้ที่มาบน VPS

การดูแล VPS และ EA เป็นประจำ

  1. เช็กสถานะทุกวัน

    ดูว่า MT5 เชื่อมต่ออยู่ ปุ่ม Algo Trading เปิด และไอคอนของ EA บนกราฟแสดงว่ากำลังทำงาน ใช้เวลาไม่กี่นาทีจากมือถือ

  2. อ่านแท็บ Experts และ Journal

    ข้อความแจ้งเตือนหรือข้อผิดพลาดมักบอกปัญหาก่อนที่มันจะกระทบบัญชี เช่น คำสั่งถูกปฏิเสธหรือการเชื่อมต่อหลุดบ่อย

  3. อัปเดตและรีสตาร์ตช่วงตลาดปิด

    จัดการ Windows Update และรีสตาร์ตเครื่องช่วงสุดสัปดาห์ หลังรีสตาร์ตให้เปิด MT5 และตรวจสถานะ EA ทุกครั้ง

  4. ตรวจทรัพยากรเครื่อง

    ดู RAM และพื้นที่ดิสก์ใน Task Manager เป็นระยะ ถ้าใช้งานใกล้เต็ม ให้ลดกราฟหรือพิจารณาขยายสเปก

คำเตือนความเสี่ยง: VPS ช่วยให้ EA ทำงานต่อเนื่องเท่านั้น ไม่ได้ลดความเสี่ยงของการเทรด การเทรด Forex ทองคำ และ CFD อาจทำให้สูญเสียเงินทุนบางส่วนหรือทั้งหมด และผลการทดสอบหรือผลลัพธ์ในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต

คำถามที่พบบ่อยเรื่อง VPS สำหรับ EA

ปิดหน้าต่าง Remote Desktop แล้ว EA ยังทำงานอยู่ไหม?

ยังทำงานอยู่ ถ้าคุณปิดหน้าต่างหรือกด Disconnect แต่ถ้ากด Sign out โปรแกรมทั้งหมดบน VPS จะถูกปิด รวมถึง MT5 ด้วย

ใช้ Virtual Hosting ของ MT5 กับ EA ทุกตัวได้ไหม?

ไม่ทุกตัว บริการนี้ไม่อนุญาตให้เรียกใช้ DLL ถ้า EA ต้องใช้ DLL จะต้องรันบน Windows VPS แทน ควรสอบถามผู้พัฒนา EA ก่อนเลือกบริการ

รัน MT5 หลายบัญชีบน VPS เครื่องเดียวได้ไหม?

ได้ บน Windows VPS สามารถติดตั้ง MT5 แยกโฟลเดอร์สำหรับแต่ละบัญชี ขอเพียงให้ RAM และ CPU เพียงพอกับจำนวนโปรแกรมที่เปิด

ถ้าจะใช้ VPS ต้องเปิดคอมที่บ้านทิ้งไว้ด้วยไหม?

ไม่ต้อง EA ทำงานบน VPS อย่างอิสระ คอมหรือมือถือของคุณใช้แค่ตอนรีโมตเข้าไปดูหรือปรับค่าเท่านั้น
