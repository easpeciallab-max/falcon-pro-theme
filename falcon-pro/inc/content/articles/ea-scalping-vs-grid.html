บอทที่เปิดปิดออเดอร์ทองวันละหลายสิบไม้ ไม้ละไม่กี่นาที มักถูกเรียกว่า EA Scalping ทอง ฟังดูปลอดภัยเพราะไม่ถือออเดอร์นาน แต่กำไรต่อไม้บางมาก จน Spread หรือความหน่วงไม่กี่มิลลิวินาทีตัดสินผลได้ทั้งเดือน บทความนี้อธิบายว่า Scalping ทำงานอย่างไร ต่างจาก EA Grid ตรงไหน ควรทดสอบอย่างไร และแต่ละแบบซ่อนความเสี่ยงอะไรไว้

สรุปสั้น: EA Scalping เข้าออกเร็ว เป้ากำไรต่อไม้เล็ก มักมี Stop Loss แคบ และเทรดถี่ ผลจึงขึ้นกับต้นทุนต่อไม้ คุณภาพการส่งคำสั่ง และข้อมูลราคาที่ใช้ทดสอบ ส่วน EA Grid ไวต่อต้นทุนต่อไม้น้อยกว่า แต่แพ้ทางราคาที่วิ่งทางเดียวยาวเพราะถือออเดอร์ขาดทุนไว้ ทุกชุดของ FALCON เป็นแบบกริดกู้คืนที่ขยาย Lot และไม่ตัดขาดทุนเอง ไม่ใช่ Scalping

Scalping คืออะไร

Scalping คือ การเทรดเก็บกำไรจากการขยับของราคาช่วงสั้นมาก ถือออเดอร์ไม่กี่วินาทีถึงไม่กี่นาที แล้วปิดทันทีที่ได้กำไรเล็ก ๆ ตามเป้า คนที่เทรดทอง Scalping ด้วยมือต้องจ้องกราฟและกดให้ทัน งานนี้จึงมักถูกยกให้บอทเทรดทำแทน ถ้ายังไม่แน่ใจว่าบอทเทรดทองแบ่งได้กี่แบบ อ่านภาพรวมของบอทเทรดทองฉบับเต็มก่อน แล้วค่อยกลับมาที่บทนี้

ที่แยก Scalping ออกจากเดย์เทรดคือสัดส่วนระหว่างกำไรที่หวังกับต้นทุน เดย์เทรดอาจรอให้ทองขยับหลายดอลลาร์ต่อออนซ์ ส่วน Scalping อาจหวังไม่ถึงหนึ่งดอลลาร์ ต้นทุนก้อนเดียวกันจึงกินกำไรของ Scalping มากกว่าหลายเท่า

EA Scalping ทองทำงานอย่างไร

  • ถือสั้นและเป้าเล็ก: ออเดอร์ส่วนใหญ่ปิดในไม่กี่นาที Take Profit อยู่ใกล้ราคาเข้า หรือปิดด้วยเงื่อนไขในโค้ด
  • Stop Loss มักแคบ: เพื่อทิ้งไม้ที่ผิดทางให้เร็ว แต่บางตัวที่ขายในชื่อ Scalping กลับถือไม้ขาดทุนไว้แก้แบบกริด
  • เทรดถี่: ต้นทุนต่อไม้ถูกคูณด้วยจำนวนไม้ที่มาก
  • เลือกช่วงเวลา: หลายตัวเทรดเฉพาะช่วงที่ Spread แคบ และหลบช่วงก่อนประกาศข่าวแรง

ความเร็ว เซิร์ฟเวอร์ และกติกาของโบรกเกอร์

บอทเก็บกำไรสั้นยังขึ้นกับสี่เรื่องที่โฆษณาไม่ค่อยพูดถึง

  • ความหน่วง (Latency): ระหว่างที่คำสั่งเดินทางไปถึงเซิร์ฟเวอร์ซื้อขาย ราคายังขยับต่อ เครื่องที่รัน EA ยิ่งอยู่ไกลหรือเน็ตไม่นิ่ง ราคาที่ได้ยิ่งคลาด
  • ประเภท Execution: แบบ Market คำสั่งมักผ่านแต่ราคาอาจเลื่อน แบบ Instant อาจได้ Requote จนพลาดจังหวะทั้งไม้
  • เซิร์ฟเวอร์และประเภทบัญชี: โบรกเกอร์เดียวกันอาจมีหลายบัญชีที่ต้นทุนและสภาพคล่องไม่เท่ากัน ผลของบัญชีหนึ่งจึงใช้แทนอีกบัญชีไม่ได้
  • กติกาการถือสั้น: โบรกเกอร์บางแห่งจำกัดไม้ที่ถือสั้นกว่าเวลาที่กำหนดและอาจยกเลิกกำไรของไม้นั้น ส่วนค่า Stops level ในหน้าต่าง Specification คือระยะใกล้สุดที่วาง Stop Loss และ Take Profit ได้ บอทที่ต้องการระยะแคบกว่านั้นจะถูกปฏิเสธคำสั่ง

ความเสี่ยงที่แต่ละแบบซ่อนไว้

Scalping: กำไรหายได้โดยไม่มีใครแก้โค้ด

  • โบรกเกอร์ปรับ Spread ค่าคอมมิชชัน หรือย้ายเซิร์ฟเวอร์ ผลที่เคยบวกก็พลิกเป็นลบได้
  • ผลบนบัญชี โบรกเกอร์ หรือเครื่องของคนอื่น ใช้แทนผลของคุณไม่ได้
  • Stop Loss แคบไม่ได้แปลว่าขาดทุนต่อไม้เล็กเสมอ ช่วงข่าวหรือราคากระโดด ราคาที่ปิดได้อาจเลยไปไกล

Grid: ขาดทุนถูกพักไว้ ไม่ได้หายไป

  • Balance นับเฉพาะไม้ที่ปิดแล้ว ขาดทุนของไม้ที่ค้างอยู่เห็นได้ที่ Equity เท่านั้น
  • รอบที่ปิดบวกมีมาก แต่รอบเดียวที่ราคาไม่กลับอาจกินกำไรสะสมทั้งหมด
  • ถ้าขยาย Lot ขาดทุนต่อการขยับของราคาจะเร่งขึ้นทุกชั้น ดูตารางสมมติได้ในบทความEA Martingale และ Grid

เช็ก EA Scalping Gold MT5 ก่อนใช้เงินจริง

บอทที่ขายในชื่อแนว EA Scalping Gold MT5 มักโชว์เส้นกำไรชันแทบไม่มีช่วงลง ห้าขั้นนี้ช่วยดูว่าตัวเลขนั้นจะรอดถึงบัญชีของคุณไหม

  1. ทดสอบด้วย tick จริงของบัญชีที่จะใช้

    ใช้เซิร์ฟเวอร์และประเภทบัญชีเดียวกับที่จะเทรด ถ้าผู้ขายส่งรายงานมา ดูหัวรายงานว่าใช้โหมดไหน

  2. เพิ่มต้นทุนแล้วดูว่ากำไรเหลือไหม

    ตั้ง Delays ให้มีความหน่วง แล้วนำจำนวนเทรดคูณต้นทุนเพิ่มที่สมมติ ลบออกจากกำไรสุทธิ ถ้ากำไรหายเกือบหมด ระบบไม่มีที่ว่างสำหรับตลาดจริง

  3. วัด Slippage ด้วยเงินจำนวนน้อย

    รันบนบัญชีจริงด้วยเงินที่เสียได้ทั้งหมด เช่น บัญชี Cent แล้วเทียบราคาที่ขอกับราคาที่ได้ (ออเดอร์จิ๋วมักได้ราคาง่ายกว่าออเดอร์ใหญ่) บัญชี Demo วัดเรื่องนี้ไม่ได้ เพราะการจับคู่คำสั่งอาจต่างจากบัญชีจริง

  4. อ่านกติกาของโบรกเกอร์

    หาเงื่อนไขเรื่องเวลาถือขั้นต่ำและการยกเลิกกำไร แล้วดู Stops level กับประเภท Execution ใน Specification

  5. เทียบผลจริงกับผลทดสอบช่วงเดียวกัน

    ถ้ากำไรเฉลี่ยต่อไม้บนบัญชีจริงต่ำกว่าผลทดสอบชัดเจน หยุดหาสาเหตุก่อนเพิ่มเงิน

[falcon_brand] ไม่ใช่ EA Scalping เป็นระบบเทรดทองคำ XAUUSD บน MT5 อย่างเดียว มีเจ็ดชุด คือ EA FALCON รุ่น 1.10 (FALCON PRO, FALCON PLUS, FALCON ULTRA, FALCON FURY) และ FALCON 5.0 (FALCON SCOUT, FALCON HUNTER, FALCON APEX) ทุกชุดเป็นแบบกริดกู้คืน เมื่อราคาวิ่งสวนจะเปิดออเดอร์แก้เป็นชั้นพร้อมขยาย Lot และไม่มีชุดไหนตัดขาดทุนเอง ถ้าใช้ตารางด้านบนประเมิน FALCON ให้อ่านคอลัมน์ EA Grid

  • ความเสี่ยงหลัก: วันที่ทองวิ่งทางเดียวไกลเกินกว่าการแก้ออเดอร์รองรับ เงินในบัญชีอาจหายได้ทั้งหมด
  • ใช้ผ่านแดชบอร์ดอย่างเดียว: EA รันบนเซิร์ฟเวอร์ของ FALCON ไม่มีไฟล์ให้ลงเครื่อง ไม่ต้องเช่า VPS แอป MT5 มีไว้ดูบัญชี ดูขั้นตอนที่หน้าใช้ FALCON ผ่านแดชบอร์ด
  • ผลทดสอบอยู่ที่เดียว: ผลย้อนหลังของทั้งเจ็ดชุดพร้อมเงื่อนไขและข้อจำกัดทุกข้ออยู่ที่หน้าผล Backtest
  • บัญชีที่ใช้ได้: บัญชีเงินจริงของโบรกเกอร์ที่แดชบอร์ดรองรับ บัญชี Cent ใช้ได้ Demo ใช้ไม่ได้ ถ้าเพิ่งเริ่มให้ใช้เงินน้อยที่เสียได้ทั้งหมด

ก่อนเลือกบอทแบบไหน: ไม่ว่าจะเป็น Scalping หรือ Grid การเทรดทองคำแบบ CFD ที่มี Leverage ทำให้เงินในบัญชีหายได้ทั้งก้อน แบบแรกมักเสียทีละน้อย แบบหลังมักเสียครั้งใหญ่ในวันที่ราคาไม่กลับ ตัวเลขทดสอบหรือผลบัญชีจริงที่ดีในช่วงที่ผ่านมาไม่ได้รับรองว่าข้างหน้าจะออกมาแบบเดิม บทความนี้เป็นความรู้ทั่วไป ไม่ใช่คำแนะนำการลงทุน อ่านประกาศความเสี่ยงให้ครบก่อนฝากเงิน

คำถามที่พบบ่อย

EA XAUUSD M1 ทุกตัวเป็น Scalping ไหม?

ไม่เสมอไป Timeframe บอกแค่ว่าบอทอ่านแท่งราคาขนาดไหน บางตัวบนกราฟ 1 นาทีถือออเดอร์นานและแก้แบบกริด ให้ดูประวัติการเทรดว่าถือนานแค่ไหน มี Stop Loss ไหม และเปิดออเดอร์เพิ่มตอนราคาวิ่งสวนหรือเปล่า

EA Scalping ทองกับ EA Grid แบบไหนเสี่ยงน้อยกว่า?

ไม่มีแบบไหนเสี่ยงน้อยกว่าเสมอ Scalping เสียจากต้นทุน Slippage และไม้แพ้ติดกัน Grid เสียก้อนใหญ่ในวันที่ราคาวิ่งทางเดียวไกล ให้ถามว่าคุณรับความเสียหายแบบไหนได้ และทดสอบตรงจุดอ่อนของแบบนั้นแล้วหรือยัง

ทำไม EA Scalping ที่ Backtest สวยถึงขาดทุนบนบัญชีจริง?

สาเหตุที่พบบ่อยคือทดสอบด้วย tick ที่โปรแกรมสร้างขึ้น ไม่ตั้งความหน่วง ใช้ข้อมูลของบัญชีที่ต้นทุนต่ำกว่าบัญชีจริง หรือนับ Slippage และค่าคอมมิชชันไม่ครบ เมื่อกำไรต่อไม้บาง ความต่างเล็ก ๆ เหล่านี้พลิกผลได้ทั้งระบบ

FALCON PRO EA เป็น EA Scalping ไหม?

ไม่ใช่ ทั้งเจ็ดชุดของ FALCON เป็นระบบกริดกู้คืนบนทองคำ XAUUSD ที่เปิดออเดอร์แก้เป็นชั้นพร้อมขยาย Lot และไม่ตัดขาดทุนเอง ความเสี่ยงหลักคือวันที่ราคาวิ่งทางเดียวยาว ซึ่งทำให้เงินในบัญชีหายได้ทั้งหมด

บทความและคู่มือที่เกี่ยวข้อง

  • บอทเทรดทองคืออะไร ดีไหม
  • Grid Trading คืออะไร
  • EA Martingale และ Grid คืออะไร
  • EA ไม่มี Stop Loss เสี่ยงแค่ไหน
  • EA เทรดทองตัวไหนดี
  • Spread และ Slippage
  • วิธี Backtest EA บน MT5
  • Win Rate คืออะไร
  • ผล Backtest ของ FALCON และข้อจำกัด
