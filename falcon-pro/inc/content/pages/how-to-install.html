ส่วนนี้ขยายรายละเอียดของวิธีติดตั้ง EA MT5 ต่อจากภาพรวม 6 ขั้นด้านบน ครอบคลุมเรื่องที่มักทำให้ติดตั้งแล้วไม่ทำงาน ตั้งแต่ชนิดไฟล์ ตำแหน่งโฟลเดอร์ สิทธิ์ Algo Trading การโหลด Preset ไปจนถึงตารางแก้ปัญหา การรันบน VPS และการอัปเดตเวอร์ชัน

ไฟล์ .ex5 กับ .mq5 ต่างกันอย่างไร

EA บน MetaTrader 5 มีไฟล์ที่เกี่ยวข้องอยู่ไม่กี่แบบ รู้ความต่างไว้ก่อนจะช่วยให้ไม่วางไฟล์ผิดที่หรือใช้ไฟล์ผิดแพลตฟอร์ม

ไฟล์คืออะไรใช้งานอย่างไร
.ex5ไฟล์ EA ที่คอมไพล์แล้ว MT5 รันได้ทันที แต่เปิดดูหรือแก้โค้ดไม่ได้วางในโฟลเดอร์ MQL5 → Experts แล้วแนบขึ้นกราฟ เป็นไฟล์หลักที่ใช้งานจริง
.mq5ซอร์สโค้ดที่เขียนด้วยภาษา MQL5 เป็นข้อความที่อ่านและแก้ไขได้ต้องเปิดใน MetaEditor แล้วกด Compile ก่อน จึงจะได้ไฟล์ .ex5 ที่ใช้งานได้
.setไฟล์ Preset เก็บค่าพารามิเตอร์ (Inputs) ชุดหนึ่งไม่ต้องวางใน Experts ให้โหลดผ่านปุ่ม Load ในแท็บ Inputs ตำแหน่งเริ่มต้นของ MT5 คือโฟลเดอร์ MQL5 → Presets
.ex4 / .mq4ไฟล์ของ MetaTrader 4ใช้กับ MT5 ไม่ได้ ถ้าวางลงไปจะไม่ขึ้นในรายการ EA

EA เชิงพาณิชย์ส่วนใหญ่ส่งให้ผู้ใช้เป็นไฟล์ .ex5 ถ้าไฟล์ที่ได้รับถูกบีบอัดเป็น .zip ให้แตกไฟล์ออกมาก่อน แล้วค่อยคัดลอกเฉพาะไฟล์ .ex5 ไปวาง

โฟลเดอร์ Experts อยู่ที่ไหน

ใน MT5 ไปที่เมนู File → Open Data Folder จะมีหน้าต่างโฟลเดอร์เปิดขึ้นมา ให้เข้าไปที่ MQL5 → Experts แล้ววางไฟล์ .ex5 ลงไป บนเครื่องที่ติดตั้ง MT5 แบบปกติ ที่อยู่จริงของโฟลเดอร์มักมีลักษณะประมาณ C:\Users\ชื่อผู้ใช้\AppData\Roaming\MetaQuotes\Terminal\รหัสยาว\MQL5\Experts

หลังวางไฟล์แล้ว เปิดหน้าต่าง Navigator (Ctrl+N) คลิกขวาที่หัวข้อ Expert Advisors แล้วเลือก Refresh หรือปิดแล้วเปิด MT5 ใหม่ EA จะปรากฏในรายการ

ถ้าในเครื่องมี MT5 หลายตัว เช่น แยกตามโบรกเกอร์ แต่ละตัวมีโฟลเดอร์ข้อมูลเป็นของตัวเอง ต้องกด Open Data Folder จาก MT5 ตัวที่จะใช้งานเท่านั้น คุณยังสร้างโฟลเดอร์ย่อยใน Experts เพื่อจัดกลุ่ม EA ได้ด้วย

เปิดสิทธิ์ Algo Trading ใน Tools → Options

ไปที่เมนู Tools → Options (หรือกด Ctrl+O) แล้วเลือกแท็บ Expert Advisors ตัวเลือกที่ควรรู้มีดังนี้

  • Allow algorithmic trading ต้องติ๊กไว้ ถ้าไม่ติ๊ก EA จะโหลดขึ้นกราฟได้แต่ส่งคำสั่งเทรดไม่ได้ MT5 รุ่นเก่าอาจใช้ชื่อว่า Allow Automated Trading
  • ตัวเลือกกลุ่ม Disable algorithmic trading when... เป็นระบบป้องกัน ถ้าติ๊กไว้ การสลับบัญชี สลับโปรไฟล์ หรือเปลี่ยนสัญลักษณ์และ Timeframe ของกราฟ จะทำให้ Algo Trading ถูกปิดอัตโนมัติ คุณต้องกลับมาเปิดเอง
  • Allow DLL imports เปิดเฉพาะเมื่อผู้พัฒนาแจ้งว่า EA ต้องใช้ไฟล์ DLL และไฟล์มาจากแหล่งที่เชื่อถือได้ ถ้าไม่จำเป็นให้ปิดไว้เพื่อความปลอดภัย
  • Allow WebRequest for listed URL ใช้เมื่อ EA ต้องเชื่อมต่อเว็บไซต์ภายนอก ใส่เฉพาะ URL ที่ทีมงานแจ้งเท่านั้น

จากนั้นกดปุ่ม Algo Trading บนแถบเครื่องมือด้านบน (หรือกด Ctrl+E) ให้อยู่ในสถานะเปิด ปุ่มนี้คือสวิตช์หลักที่เปิดปิดการเทรดอัตโนมัติของ EA ทุกตัวในโปรแกรม

แนบ EA ขึ้นกราฟและติ๊ก Allow Algo Trading ในแท็บ Common

  1. เปิดกราฟให้ถูกสัญลักษณ์และ Timeframe

    คลิกขวาที่สัญลักษณ์ในหน้าต่าง Market Watch เลือก Chart Window หรือใช้เมนู File → New Chart แล้วปรับ Timeframe ให้ตรงตามคู่มือ

  2. ลาก EA จาก Navigator ขึ้นกราฟ

    ลากชื่อ EA ไปวางบนกราฟ หรือดับเบิลคลิก หรือคลิกขวาแล้วเลือก Attach to a chart จะมีหน้าต่างตั้งค่า EA เปิดขึ้นมา

  3. ติ๊ก Allow Algo Trading ในแท็บ Common

    ในแท็บ Common ให้ติ๊ก Allow Algo Trading ถ้า EA ใช้ไฟล์ DLL จะมีตัวเลือก Allow DLL imports ในแท็บ Common หรือ Dependencies ขึ้นกับเวอร์ชันของ MT5 ติ๊กเฉพาะเมื่อไฟล์มาจากแหล่งที่เชื่อถือได้

  4. ตั้งค่าในแท็บ Inputs แล้วกด OK

    ตั้งค่าพารามิเตอร์หรือโหลด Preset ตามหัวข้อถัดไป ตรวจค่า Lot หรือ % ความเสี่ยงอีกครั้ง แล้วกด OK

กราฟหนึ่งกราฟแนบ EA ได้เพียงหนึ่งตัว ถ้าต้องการรันหลายสัญลักษณ์ ให้เปิดกราฟแยกตามสัญลักษณ์ แล้วแนบ EA ทีละกราฟ

โหลด Preset (.set) ผ่าน Inputs → Load

  1. เปิดหน้าต่างตั้งค่า EA

    ถ้า EA อยู่บนกราฟแล้ว ให้คลิกขวาบนกราฟ เลือก Expert Advisors → Properties หรือกด F7 ขณะเลือกกราฟนั้นอยู่

  2. ไปที่แท็บ Inputs แล้วกด Load

    เลือกไฟล์ .set ที่ได้รับ ค่าในตารางจะเปลี่ยนตามไฟล์ทันที เก็บไฟล์ .set ไว้ในโฟลเดอร์ MQL5 → Presets จะหาง่ายที่สุด

  3. ตรวจค่าก่อนกด OK

    เช็กค่าหลักอย่าง Lot หรือ % ความเสี่ยง และค่าที่เกี่ยวกับสัญลักษณ์ ถ้าคุณปรับค่าเองแล้วอยากเก็บไว้ ให้กด Save เป็นไฟล์ใหม่ อย่าเขียนทับไฟล์ต้นฉบับ

Preset แต่ละไฟล์มักออกแบบมาสำหรับสัญลักษณ์และช่วงทุนหนึ่ง ๆ อย่านำ Preset ของสัญลักษณ์หนึ่งไปใช้กับอีกสัญลักษณ์ ถ้าไม่แน่ใจว่าไฟล์ไหนเหมาะกับบัญชีของคุณ ให้ถามทีมงานก่อน

ตรวจว่า EA ทำงานอยู่จริง

ขั้นตอนที่คนมักข้ามในวิธีติดตั้ง EA MT5 คือการตรวจว่าระบบพร้อมเทรดจริง ใช้เวลาไม่ถึงนาที แต่ช่วยกันปัญหา EA ค้างอยู่บนกราฟเฉย ๆ โดยไม่รู้ตัว

  • มุมขวาบนของกราฟ จะมีชื่อ EA พร้อมไอคอน ใน MT5 รุ่นปัจจุบันเป็นรูปหมวก สีฟ้าแปลว่าพร้อมเทรด สีเทาแปลว่าโหลดแล้วแต่ถูกปิดการเทรด (MT5 รุ่นเก่าใช้รูปหน้ายิ้มและหน้าบึ้ง)
  • ปุ่ม Algo Trading บนแถบเครื่องมืออยู่ในสถานะเปิด
  • แท็บ Experts ในหน้าต่าง Toolbox (Ctrl+T) แสดงข้อความของ EA เช่น ข้อความว่าโหลดสำเร็จ และข้อความแจ้งเตือนจากตัว EA เอง
  • แท็บ Journal แสดงบันทึกของแพลตฟอร์ม เช่น สถานะการเชื่อมต่อ การเปิดปิด Algo Trading และคำสั่งเทรดที่ถูกปฏิเสธพร้อมสาเหตุ
  • มุมขวาล่างของ MT5 แสดงสถานะการเชื่อมต่อกับเซิร์ฟเวอร์ ถ้าขึ้นว่าไม่มีการเชื่อมต่อหรือบัญชีไม่ถูกต้อง EA จะเทรดไม่ได้

ถ้ายังไม่มีออเดอร์ ไม่ได้แปลว่า EA ไม่ทำงาน EA จะรอจนเงื่อนไขครบตามกลยุทธ์ก่อนเปิดออเดอร์ ให้ดูจากไอคอนและแท็บ Experts เป็นหลัก

ตารางแก้ปัญหาที่เจอบ่อย

อาการสาเหตุที่พบบ่อยวิธีแก้
ไม่เห็น EA ใน Navigatorวางไฟล์ผิดโฟลเดอร์ เช่น Indicators หรือโฟลเดอร์ของ MT5 ตัวอื่น ยังไม่ได้ Refresh หรือเป็นไฟล์ .ex4 ของ MT4เปิด File → Open Data Folder จาก MT5 ตัวที่ใช้ วางไฟล์ .ex5 ใน MQL5 → Experts แล้วคลิกขวาที่ Expert Advisors เลือก Refresh
ไอคอนมุมกราฟเป็นสีเทา หรือหน้าบึ้งปุ่ม Algo Trading ปิดอยู่ หรือยังไม่ได้ติ๊ก Allow Algo Trading ในแท็บ Commonเปิดปุ่ม Algo Trading แล้วกด F7 บนกราฟ เข้าแท็บ Common ติ๊ก Allow Algo Trading
Journal ขึ้นว่า trade is disabledล็อกอินด้วยรหัส Investor ซึ่งอ่านได้อย่างเดียว หรือบัญชีหรือสัญลักษณ์นั้นถูกปิดการเทรดล็อกอินใหม่ด้วยรหัสผ่านหลัก ตรวจช่อง Trade ในหน้า Specification ของสัญลักษณ์ ถ้ายังไม่ได้ให้ติดต่อโบรกเกอร์
ขึ้นว่า not enough moneyLot ใหญ่เกินกว่า Free Margin ที่มี Leverage ต่ำ หรือทุนน้อยกว่าที่ Preset ออกแบบไว้ลด Lot หรือ % ความเสี่ยง ตรวจ Leverage ของบัญชี และใช้ Preset ที่เหมาะกับขนาดทุน
ขึ้นว่า invalid stopsระยะ Stop Loss หรือ Take Profit ใกล้ราคาเกินค่า Stops level ของโบรกเกอร์ ตั้งค่าผิดหน่วย (point กับ pip) หรือ Spread ถ่างกว้างดูค่า Stops level ในหน้า Specification ปรับระยะให้กว้างกว่าขั้นต่ำ และตรวจหน่วยของพารามิเตอร์ตามคู่มือ
ขึ้นว่า AutoTrading disabled by clientปุ่ม Algo Trading ถูกปิด เช่น ปิดอัตโนมัติหลังสลับบัญชีหรือโปรไฟล์เปิดปุ่ม Algo Trading อีกครั้ง และตรวจตัวเลือก Disable algorithmic trading when... ใน Tools → Options
ขึ้นข้อความว่าไม่อนุญาตให้โหลด DLLEA ต้องใช้ DLL แต่ยังไม่ได้อนุญาตติ๊ก Allow DLL imports ทั้งใน Tools → Options และในหน้าต่างตั้งค่า EA เฉพาะเมื่อไฟล์มาจากแหล่งที่เชื่อถือได้
EA ไม่เปิดออเดอร์ หรือหาสัญลักษณ์ไม่เจอโบรกเกอร์ใช้ชื่อสัญลักษณ์ที่มี suffix หรือชื่อต่างออกไป เช่น XAUUSDm, XAUUSD.r หรือ GOLDแนบ EA บนกราฟของสัญลักษณ์ที่ถูกต้องตาม Market Watch เปิดดูสัญลักษณ์ทั้งหมดได้ด้วย Ctrl+U ถ้า EA มีช่องกรอกชื่อสัญลักษณ์ให้กรอกตามโบรกเกอร์
EA หลุดออกจากกราฟทันทีหลังแนบEA เริ่มต้นทำงานไม่สำเร็จ เช่น สิทธิ์ใช้งานไม่ตรงกับบัญชี MT5 เวอร์ชันเก่าเกินไป หรือสัญลักษณ์ไม่รองรับอ่านข้อความในแท็บ Experts อัปเดต MT5 เป็นเวอร์ชันล่าสุด แล้วส่งภาพหน้าจอแท็บ Experts ให้ทีมงานตรวจ
ขึ้นว่า market is closedอยู่นอกเวลาเทรดของสัญลักษณ์ เช่น วันหยุดสุดสัปดาห์หรือช่วงพักตลาดรายวันรอตลาดเปิด ดูเวลาเทรดได้ที่หัวข้อ Sessions ในหน้า Specification
ขึ้นว่า invalid volumeLot ต่ำกว่าขั้นต่ำหรือไม่ตรงกับขั้นของ Lot ที่โบรกเกอร์กำหนดดูค่า Minimal volume และ Volume step ในหน้า Specification แล้วปรับ Lot ให้ตรง

หน้า Specification เปิดได้โดยคลิกขวาที่สัญลักษณ์ในหน้าต่าง Market Watch แล้วเลือก Specification ถ้าลองแก้ตามตารางแล้วยังไม่หาย ส่งภาพหน้าจอแท็บ Experts และ Journal มาให้ทีมงานดูได้

รัน EA บน VPS ให้ทำงานต่อเนื่อง

EA ทำงานได้เฉพาะตอนที่โปรแกรม MT5 บนคอมพิวเตอร์เปิดอยู่และเชื่อมต่อกับเซิร์ฟเวอร์ ปิดคอมเมื่อไร EA ก็หยุดทันที และแอป MT5 บนมือถือรัน EA ไม่ได้ ใช้ได้แค่ดูผล วิธีที่นิยมจึงเป็นการเช่า VPS ที่เป็น Windows ซึ่งเปิดอยู่ตลอด 24 ชั่วโมง

  • เลือก VPS ที่ตั้งอยู่ใกล้เซิร์ฟเวอร์ของโบรกเกอร์เพื่อให้ ping ต่ำ และมี RAM พอสำหรับจำนวน MT5 ที่จะเปิด
  • ติดตั้ง MT5 บน VPS แล้วทำทุกขั้นตอนในหน้านี้ซ้ำบน VPS ทั้งการวางไฟล์ การตั้งค่า Options และการโหลด Preset
  • เมื่อจะเลิกใช้งาน ให้ปิดหน้าต่าง Remote Desktop เพื่อตัดการเชื่อมต่อ อย่ากด Sign out เพราะจะปิดโปรแกรมทั้งหมดรวมถึง MT5
  • ตั้งเวลาการอัปเดต Windows ให้เหมาะสม และตั้งให้ MT5 เปิดเองเมื่อเครื่องรีสตาร์ท
  • อย่ารัน EA ตัวเดียวกันบนบัญชีเดียวกันจากสองเครื่องพร้อมกัน เช่น คอมที่บ้านกับ VPS เพราะอาจเปิดออเดอร์ซ้อนกัน

MT5 ยังมีบริการ Virtual Hosting ของ MetaQuotes ในตัว ซึ่งย้าย EA จากเครื่องคุณไปรันบนเซิร์ฟเวอร์ แต่มีข้อจำกัดบางอย่าง เช่น ไม่รองรับการเรียกใช้ DLL จึงควรสอบถามทีมงานก่อนว่า EA รองรับหรือไม่ ดูขั้นตอนเช่าและใช้งาน VPS แบบละเอียดได้ที่ คู่มือ VPS Windows

อัปเดต EA เป็นเวอร์ชันใหม่

  1. เลือกเวลาที่ปลอดภัย

    ทำตอนที่ไม่มีออเดอร์เปิดค้าง หรือช่วงตลาดปิด ถ้ามีออเดอร์ค้างอยู่ ให้ถามทีมงานก่อนว่าเวอร์ชันใหม่จะดูแลออเดอร์เดิมต่อได้หรือไม่

  2. สำรองไฟล์เดิม

    คัดลอกไฟล์ .ex5 และ .set ที่ใช้อยู่ไปเก็บไว้อีกโฟลเดอร์ และบันทึกค่า Inputs ปัจจุบันด้วยปุ่ม Save เผื่อต้องย้อนกลับ

  3. ถอดเวอร์ชันเก่าออกจากกราฟ

    คลิกขวาบนกราฟ เลือก Expert Advisors → Remove

  4. วางไฟล์ใหม่ใน Experts

    วางไฟล์ .ex5 ใหม่ใน MQL5 → Experts จะเขียนทับไฟล์เดิมหรือใช้ชื่อใหม่ก็ได้ตามที่ทีมงานแนะนำ แล้ว Refresh ใน Navigator

  5. แนบเวอร์ชันใหม่และโหลด Preset

    เวอร์ชันใหม่อาจมีพารามิเตอร์เพิ่มหรือเปลี่ยนชื่อ ให้ใช้ Preset ที่ส่งมาพร้อมเวอร์ชันนั้น และตรวจค่าทีละบรรทัดก่อนกด OK

  6. ตรวจแท็บ Experts และ Journal

    ดูว่า EA โหลดสำเร็จและไม่มีข้อความผิดพลาด ถ้าใช้หลายเครื่องหรือหลาย VPS ต้องอัปเดตให้ครบทุกเครื่อง

คำถามที่พบบ่อยเรื่องวิธีติดตั้ง EA MT5

ติดตั้ง EA บนมือถือได้ไหม?

ไม่ได้ แอป MT5 บน Android และ iPhone รัน EA ไม่ได้ ต้องใช้ MT5 บนคอมพิวเตอร์ Windows หรือ VPS ส่วนมือถือใช้ดูผลผ่านแอป MT5 หรือควบคุม VPS ผ่านแอป Windows App ได้

ต้องเปิดคอมพิวเตอร์ทิ้งไว้ตลอดเวลาไหม?

ถ้ารันบนคอมที่บ้าน ต้องเปิดเครื่องและ MT5 ไว้ตลอด และห้ามให้เครื่องเข้าโหมด Sleep ทางที่สะดวกกว่าคือใช้ VPS ซึ่งเปิดอยู่ตลอด 24 ชั่วโมง

เปลี่ยน Timeframe บนกราฟที่มี EA อยู่ได้ไหม?

เปลี่ยนได้ แต่ EA จะเริ่มทำงานใหม่ และถ้าเปิดตัวเลือกปิด Algo Trading เมื่อเปลี่ยนสัญลักษณ์หรือ Timeframe ไว้ การเทรดจะถูกปิดด้วย ควรใช้ Timeframe ตามคู่มือและไม่เปลี่ยนระหว่างใช้งาน

ปิด MT5 แล้วออเดอร์ที่เปิดอยู่จะเป็นอย่างไร?

ออเดอร์ยังอยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์ Stop Loss และ Take Profit ที่ตั้งไว้ในออเดอร์ยังทำงานตามปกติ แต่การจัดการที่ EA ทำภายในโปรแกรม เช่น การปิดตามเงื่อนไขหรือการเลื่อนจุดตัดขาดทุน จะหยุดจนกว่าจะเปิด MT5 และ EA ใหม่

คำเตือนความเสี่ยง: การติดตั้ง EA ให้ทำงานได้ถูกต้องไม่ได้แปลว่าจะมีกำไร การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง คุณอาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด ผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต ควรเริ่มจากบัญชีเดโมหรือบัญชีขนาดเล็ก และใช้เฉพาะเงินที่พร้อมรับความเสี่ยงได้

คู่มือที่เกี่ยวข้อง

  • คู่มือเช่าและใช้งาน VPS Windows
  • วิธีล็อกอินบัญชีใน MT5
  • วิธี Backtest EA บน MT5 และอ่านผลให้เป็น
  • แพ็กเกจและราคา
