ส่วนนี้เป็นรายละเอียดเสริมของวิธีติดตั้ง EA MT5 ต่อจาก 6 ขั้นตอนด้านบน รวมเรื่องที่ทำให้ติดตั้งแล้วไม่ทำงานบ่อยที่สุด ตั้งแต่ชนิดไฟล์ ที่อยู่จริงของโฟลเดอร์ ตัวเลือกใน Tools → Options การจัดการ Preset ไปจนถึงตารางแก้ปัญหา การรันบน VPS และการอัปเดตเวอร์ชัน

ไฟล์ .ex5, .mq5 และ .set คืออะไร

EA บน MetaTrader 5 มีไฟล์ที่เกี่ยวข้องอยู่ไม่กี่แบบ รู้ความต่างไว้ก่อนจะช่วยให้ไม่วางไฟล์ผิดที่หรือใช้ไฟล์ผิดแพลตฟอร์ม

ไฟล์คืออะไรใช้งานอย่างไร
.ex5ไฟล์ EA ที่คอมไพล์แล้ว MT5 รันได้ทันที แต่เปิดดูหรือแก้โค้ดไม่ได้วางในโฟลเดอร์ MQL5 → Experts แล้วแนบขึ้นกราฟ เป็นไฟล์หลักที่ใช้งานจริง
.mq5ซอร์สโค้ดที่เขียนด้วยภาษา MQL5 เป็นข้อความที่อ่านและแก้ไขได้ต้องเปิดใน MetaEditor แล้วกด Compile ก่อน จึงจะได้ไฟล์ .ex5 ที่ใช้งานได้
.setไฟล์ Preset เก็บค่าพารามิเตอร์ (Inputs) ชุดหนึ่งไม่ต้องวางใน Experts ให้โหลดผ่านปุ่ม Load ในแท็บ Inputs ตำแหน่งเริ่มต้นของ MT5 คือโฟลเดอร์ MQL5 → Presets
.ex4 / .mq4ไฟล์ของ MetaTrader 4ใช้กับ MT5 ไม่ได้ ถ้าวางลงไปจะไม่ขึ้นในรายการ EA

EA เชิงพาณิชย์ส่วนใหญ่ส่งให้ผู้ใช้เป็นไฟล์ .ex5 ถ้าไฟล์ที่ได้รับถูกบีบอัดเป็น .zip ให้แตกไฟล์ออกมาก่อน แล้วค่อยคัดลอกเฉพาะไฟล์ .ex5 ไปวาง

โฟลเดอร์ Experts อยู่ที่ไหนในเครื่อง

เมนู File → Open Data Folder พาไปที่โฟลเดอร์ข้อมูลของ MT5 ตัวที่เปิดอยู่เสมอ ถ้าอยากรู้ที่อยู่จริงบนเครื่องที่ติดตั้งแบบปกติ มักมีหน้าตาประมาณ C:\Users\ชื่อผู้ใช้\AppData\Roaming\MetaQuotes\Terminal\รหัสยาว\MQL5\Experts โดยรหัสยาวจะไม่ซ้ำกันในแต่ละการติดตั้ง

ถ้าในเครื่องมี MT5 หลายตัว เช่น แยกตามโบรกเกอร์ แต่ละตัวมีโฟลเดอร์ข้อมูลเป็นของตัวเอง ต้องกด Open Data Folder จาก MT5 ตัวที่จะใช้งานเท่านั้น คุณยังสร้างโฟลเดอร์ย่อยใน Experts เพื่อจัดกลุ่ม EA ได้ด้วย

ตัวเลือกใน Tools → Options → Expert Advisors

ขั้นที่ 3 ด้านบนให้ติ๊ก Allow algorithmic trading ไปแล้ว ตัวเลือกอื่นในแท็บเดียวกันมีผลกับการทำงานของ EA ดังนี้

  • Allow algorithmic trading ต้องติ๊กไว้ ถ้าไม่ติ๊ก EA จะโหลดขึ้นกราฟได้แต่ส่งคำสั่งเทรดไม่ได้ MT5 รุ่นเก่าอาจใช้ชื่อว่า Allow Automated Trading
  • ตัวเลือกกลุ่ม Disable algorithmic trading when... เป็นระบบป้องกัน ถ้าติ๊กไว้ การสลับบัญชี สลับโปรไฟล์ หรือเปลี่ยนสัญลักษณ์และ Timeframe ของกราฟ จะทำให้ Algo Trading ถูกปิดอัตโนมัติ คุณต้องกลับมาเปิดเอง
  • Allow DLL imports เปิดเฉพาะเมื่อผู้พัฒนาแจ้งว่า EA ต้องใช้ไฟล์ DLL และไฟล์มาจากแหล่งที่เชื่อถือได้ ถ้าไม่จำเป็นให้ปิดไว้เพื่อความปลอดภัย
  • Allow WebRequest for listed URL ใช้เมื่อ EA ต้องเชื่อมต่อเว็บไซต์ภายนอก ใส่เฉพาะ URL ที่ทีมงานแจ้งเท่านั้น

จัดเก็บไฟล์ Preset ให้หาง่ายและไม่สับสน

เมื่อใช้ EA ไปสักพัก มักมีไฟล์ .set หลายชุดทั้งที่ได้รับจากทีมงานและที่ปรับเอง ถ้าตั้งชื่อไม่เป็นระบบ วันหนึ่งอาจโหลดผิดไฟล์โดยไม่รู้ตัว แนวทางที่ช่วยได้มีดังนี้

  • ตั้งชื่อไฟล์ให้บอกสัญลักษณ์ ขนาดทุนโดยประมาณ และวันที่ปรับ เช่น XAUUSD-1000usd-2026-09.set
  • เก็บไฟล์ต้นฉบับจากทีมงานไว้ในโฟลเดอร์ย่อยแยกจากไฟล์ที่คุณปรับเอง
  • เมื่ออัปเดต EA เป็นเวอร์ชันใหม่ ให้ใช้ Preset ที่มาพร้อมเวอร์ชันนั้น เพราะชื่อหรือจำนวนพารามิเตอร์อาจเปลี่ยน

ตารางแก้ปัญหาที่เจอบ่อย

อาการสาเหตุที่พบบ่อยวิธีแก้
ไม่เห็น EA ใน Navigatorวางไฟล์ผิดโฟลเดอร์ เช่น Indicators หรือโฟลเดอร์ของ MT5 ตัวอื่น ยังไม่ได้ Refresh หรือเป็นไฟล์ .ex4 ของ MT4เปิด File → Open Data Folder จาก MT5 ตัวที่ใช้ วางไฟล์ .ex5 ใน MQL5 → Experts แล้วคลิกขวาที่ Expert Advisors เลือก Refresh
ไอคอนมุมกราฟเป็นสีเทา หรือหน้าบึ้งปุ่ม Algo Trading ปิดอยู่ หรือยังไม่ได้ติ๊ก Allow Algo Trading ในแท็บ Commonเปิดปุ่ม Algo Trading แล้วกด F7 บนกราฟ เข้าแท็บ Common ติ๊ก Allow Algo Trading
Journal ขึ้นว่า trade is disabledล็อกอินด้วยรหัส Investor ซึ่งอ่านได้อย่างเดียว หรือบัญชีหรือสัญลักษณ์นั้นถูกปิดการเทรดล็อกอินใหม่ด้วยรหัสผ่านหลัก ตรวจช่อง Trade ในหน้า Specification ของสัญลักษณ์ ถ้ายังไม่ได้ให้ติดต่อโบรกเกอร์
ขึ้นว่า not enough moneyLot ใหญ่เกินกว่า Free Margin ที่มี Leverage ต่ำ หรือทุนน้อยกว่าที่ Preset ออกแบบไว้ลด Lot หรือ % ความเสี่ยง ตรวจ Leverage ของบัญชี และใช้ Preset ที่เหมาะกับขนาดทุน
ขึ้นว่า invalid stopsระยะ Stop Loss หรือ Take Profit ใกล้ราคาเกินค่า Stops level ของโบรกเกอร์ ตั้งค่าผิดหน่วย (point กับ pip) หรือ Spread ถ่างกว้างดูค่า Stops level ในหน้า Specification ปรับระยะให้กว้างกว่าขั้นต่ำ และตรวจหน่วยของพารามิเตอร์ตามคู่มือ
ขึ้นว่า AutoTrading disabled by clientปุ่ม Algo Trading ถูกปิด เช่น ปิดอัตโนมัติหลังสลับบัญชีหรือโปรไฟล์เปิดปุ่ม Algo Trading อีกครั้ง และตรวจตัวเลือก Disable algorithmic trading when... ใน Tools → Options
ขึ้นข้อความว่าไม่อนุญาตให้โหลด DLLEA ต้องใช้ DLL แต่ยังไม่ได้อนุญาตติ๊ก Allow DLL imports ทั้งใน Tools → Options และในหน้าต่างตั้งค่า EA เฉพาะเมื่อไฟล์มาจากแหล่งที่เชื่อถือได้
EA ไม่เปิดออเดอร์ หรือหาสัญลักษณ์ไม่เจอโบรกเกอร์ใช้ชื่อสัญลักษณ์ที่มี suffix หรือชื่อต่างออกไป เช่น XAUUSDm, XAUUSD.r หรือ GOLDแนบ EA บนกราฟของสัญลักษณ์ที่ถูกต้องตาม Market Watch เปิดดูสัญลักษณ์ทั้งหมดได้ด้วย Ctrl+U ถ้า EA มีช่องกรอกชื่อสัญลักษณ์ให้กรอกตามโบรกเกอร์ ดูสาเหตุอื่นที่พบบ่อยได้ในบทความ EA ไม่เปิดออเดอร์บน MT5: วิธีเช็กทีละจุด
EA หลุดออกจากกราฟทันทีหลังแนบEA เริ่มต้นทำงานไม่สำเร็จ เช่น สิทธิ์ใช้งานไม่ตรงกับบัญชี MT5 เวอร์ชันเก่าเกินไป หรือสัญลักษณ์ไม่รองรับอ่านบรรทัดแจ้งเตือนในแท็บ Experts และอัปเดต MT5 ให้เป็นรุ่นปัจจุบัน ถ้ายังไม่หาย แคปแท็บ Experts ให้ทีมงานช่วยดู
ขึ้นว่า market is closedอยู่นอกเวลาเทรดของสัญลักษณ์ เช่น วันหยุดสุดสัปดาห์หรือช่วงพักตลาดรายวันรอตลาดเปิด ดูเวลาเทรดได้ที่หัวข้อ Sessions ในหน้า Specification
ขึ้นว่า invalid volumeLot ต่ำกว่าขั้นต่ำหรือไม่ตรงกับขั้นของ Lot ที่โบรกเกอร์กำหนดดูค่า Minimal volume และ Volume step ในหน้า Specification แล้วปรับ Lot ให้ตรง

หน้า Specification เปิดได้โดยคลิกขวาที่สัญลักษณ์ในหน้าต่าง Market Watch แล้วเลือก Specification

รัน EA บน VPS ให้ทำงานต่อเนื่อง

EA จะทำงานได้ก็ต่อเมื่อโปรแกรม MT5 เวอร์ชันคอมพิวเตอร์ยังเปิดค้างและออนไลน์อยู่ ปิดคอมเมื่อไร EA ก็หยุดทันที ส่วนแอป MT5 บนมือถือใช้ดูผลได้อย่างเดียว คนส่วนใหญ่จึงเลือกเช่า VPS ที่เป็น Windows ซึ่งเปิดทิ้งไว้ได้ตลอด 24 ชั่วโมง

  • เลือก VPS ที่ศูนย์ข้อมูลอยู่ใกล้เซิร์ฟเวอร์โบรก เพื่อให้ ping ต่ำ และมี RAM พอสำหรับจำนวน MT5 ที่จะเปิด
  • ติดตั้ง MT5 บน VPS แล้วทำทุกขั้นตอนในหน้านี้ซ้ำบน VPS ทั้งการวางไฟล์ การตั้งค่า Options และการโหลด Preset
  • เมื่อจะเลิกใช้งาน ให้ปิดหน้าต่าง Remote Desktop เพื่อตัดการเชื่อมต่อ อย่ากด Sign out เพราะจะปิดโปรแกรมทั้งหมดรวมถึง MT5
  • ตั้งเวลาการอัปเดต Windows ให้เหมาะสม และตั้งให้ MT5 เปิดเองเมื่อเครื่องรีสตาร์ท
  • อย่ารัน EA ตัวเดียวกันบนบัญชีเดียวกันจากสองเครื่องพร้อมกัน เช่น คอมที่บ้านกับ VPS เพราะอาจเปิดออเดอร์ซ้อนกัน

MT5 ยังมีบริการ Virtual Hosting ของ MetaQuotes ในตัว ซึ่งย้าย EA จากเครื่องคุณไปรันบนเซิร์ฟเวอร์ แต่มีข้อจำกัดบางอย่าง เช่น ไม่รองรับการเรียกใช้ DLL จึงควรสอบถามทีมงานก่อนว่า EA รองรับหรือไม่ ดูขั้นตอนเช่าและใช้งาน VPS แบบละเอียดได้ที่ คู่มือ VPS Windows

อัปเดต EA เป็นเวอร์ชันใหม่

เมื่อทีมงานส่งไฟล์เวอร์ชันใหม่มา ให้เปลี่ยนตามลำดับนี้เพื่อไม่ให้ออเดอร์ที่เปิดอยู่ได้รับผลกระทบ

  1. เลือกเวลาที่ปลอดภัย ทำตอนที่ไม่มีออเดอร์เปิดค้าง หรือช่วงตลาดปิด ถ้ามีออเดอร์ค้างอยู่ ให้ถามทีมงานก่อนว่าเวอร์ชันใหม่จะดูแลออเดอร์เดิมต่อได้หรือไม่
  2. สำรองไฟล์เดิม คัดลอกไฟล์ .ex5 และ .set ที่ใช้อยู่ไปเก็บไว้อีกโฟลเดอร์ และบันทึกค่า Inputs ปัจจุบันด้วยปุ่ม Save เผื่อต้องย้อนกลับ
  3. ถอดเวอร์ชันเก่าออกจากกราฟ คลิกขวาบนกราฟ เลือก Expert Advisors → Remove
  4. วางไฟล์ใหม่ใน Experts จะเขียนทับไฟล์เดิมหรือใช้ชื่อใหม่ก็ได้ตามที่ทีมงานแนะนำ แล้ว Refresh ใน Navigator
  5. แนบเวอร์ชันใหม่และโหลด Preset ใช้ Preset ที่ส่งมาพร้อมเวอร์ชันนั้น และตรวจค่าทีละบรรทัดก่อนกด OK
  6. ตรวจแท็บ Experts และ Journal ดูว่า EA โหลดสำเร็จและไม่มีข้อความผิดพลาด ถ้าใช้หลายเครื่องหรือหลาย VPS ต้องอัปเดตให้ครบทุกเครื่อง

คำถามที่พบบ่อยเรื่องวิธีติดตั้ง EA MT5

ติดตั้ง EA บนมือถือได้ไหม?

ไม่ได้ แอป MT5 บน Android และ iPhone รัน EA ไม่ได้ ต้องใช้ MT5 บนคอมพิวเตอร์ Windows หรือ VPS ส่วนมือถือใช้ดูผลผ่านแอป MT5 หรือควบคุม VPS ผ่านแอป Windows App ได้

ต้องเปิดคอมค้างไว้ตลอดเวลาไหม?

ถ้ารันบนคอมที่บ้าน ต้องเปิดเครื่องและ MT5 ไว้ตลอด และห้ามให้เครื่องเข้าโหมด Sleep ทางที่สะดวกกว่าคือใช้ VPS ซึ่งเปิดอยู่ตลอด 24 ชั่วโมง

เปลี่ยน Timeframe บนกราฟที่มี EA อยู่ได้ไหม?

เปลี่ยนได้ แต่ EA จะเริ่มทำงานใหม่ และถ้าเปิดตัวเลือกปิด Algo Trading เมื่อเปลี่ยนสัญลักษณ์หรือ Timeframe ไว้ การเทรดจะถูกปิดด้วย ควรใช้ Timeframe ตามคู่มือและไม่เปลี่ยนระหว่างใช้งาน

ปิด MT5 แล้วออเดอร์ที่เปิดอยู่จะเป็นอย่างไร?

ออเดอร์ยังอยู่ที่เซิร์ฟเวอร์ของโบรกเกอร์ Stop Loss และ Take Profit ที่ตั้งไว้ในออเดอร์ยังทำงานตามปกติ แต่การจัดการที่ EA ทำภายในโปรแกรม เช่น การปิดตามเงื่อนไขหรือการเลื่อนจุดตัดขาดทุน จะหยุดจนกว่าจะเปิด MT5 และ EA ใหม่

คำเตือนความเสี่ยง: การติดตั้ง EA ให้ทำงานได้ถูกต้องไม่ได้แปลว่าจะมีกำไร Forex ทองคำ และ CFD เป็นตลาดความเสี่ยงสูง ขาดทุนได้ตั้งแต่บางส่วนไปจนถึงเงินทุนทั้งก้อน และผลที่เคยเกิดขึ้นในอดีตไม่ใช่หลักประกันของผลในอนาคต ควรเริ่มจากบัญชีเดโมหรือบัญชีขนาดเล็ก และใช้เฉพาะเงินที่พร้อมรับความเสี่ยงได้
