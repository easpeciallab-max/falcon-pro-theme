ล็อกอิน MT5 คือการเชื่อมโปรแกรม MetaTrader 5 เข้ากับบัญชีเทรดที่คุณเปิดไว้กับโบรกเกอร์ หน้านี้สอนตั้งแต่ดาวน์โหลดโปรแกรมจากแหล่งทางการ กรอกข้อมูลล็อกอิน ไปจนตรวจว่าเชื่อมต่อสำเร็จจริง ทั้งบนคอมพิวเตอร์ Windows ที่ใช้รัน EA และบนมือถือ Android กับ iPhone ที่ใช้ติดตามบัญชี

สรุปสั้น: ติดตั้ง MT5 → เปิดหน้าล็อกอิน (คอม: File → Login to Trade Account / มือถือ: เพิ่มบัญชีใหม่) → เลือกเซิร์ฟเวอร์ของโบรกเกอร์ → กรอก Login, Password, Server → ดูสถานะมุมขวาล่างว่ามีข้อมูลวิ่ง ไม่ขึ้น Invalid account หรือ No connection

ข้อมูลที่ต้องมีก่อนล็อกอิน MT5

ข้อมูลทั้งหมดนี้ได้มาตอนสร้างบัญชีเทรด ส่วนใหญ่อยู่ในอีเมลยืนยันจากโบรกเกอร์ หรือในหน้าบัญชีของ Client Portal ถ้ายังไม่มีบัญชี ให้ทำตามคู่มือ เปิดบัญชี MT5 ก่อน

  • เลขบัญชี (Login) เป็นตัวเลขล้วน ไม่ใช่อีเมลหรือรหัสลูกค้าที่ใช้เข้า Client Portal
  • รหัสผ่าน (Password) รหัสผ่านของบัญชีเทรด ซึ่งเป็นคนละตัวกับรหัสผ่าน Client Portal
  • ชื่อเซิร์ฟเวอร์ (Server) สำหรับบัญชีของคุณคือ [falcon_broker field="server"] ต้องเลือกให้ตรงทุกตัวอักษร เพราะบัญชี Demo กับบัญชีจริงมักอยู่คนละเซิร์ฟเวอร์
  • อินเทอร์เน็ตที่เสถียร และอุปกรณ์ที่จะติดตั้ง โดยเครื่องที่ใช้รัน EA ต้องเป็นคอมพิวเตอร์ Windows หรือ VPS

ขั้นตอนติดตั้ง MetaTrader 5 และเข้าสู่ระบบ 6 ขั้น

  1. ดาวน์โหลด MT5 จากแหล่งทางการ

    ดาวน์โหลดจากเว็บไซต์ของ MetaQuotes ผู้พัฒนา MetaTrader 5 หรือจากหน้าดาวน์โหลดของโบรกเกอร์ บนมือถือให้ค้นหา MetaTrader 5 ใน Google Play หรือ App Store แล้วดูว่าผู้พัฒนาคือ MetaQuotes หลีกเลี่ยงไฟล์จากลิงก์ที่ไม่รู้ที่มา เพราะอาจเป็นโปรแกรมปลอมที่ขโมยรหัสผ่าน

  2. ติดตั้งและเปิดโปรแกรม

    บน Windows ให้เปิดไฟล์ติดตั้ง กด Next จนเสร็จ แล้วเปิดโปรแกรมขึ้นมา ครั้งแรกอาจมีหน้าต่างชวนเปิดบัญชีทดลองเด้งขึ้น ถ้ามีบัญชีอยู่แล้วให้ปิดไปได้เลย บนมือถือ แอปอาจสร้างบัญชี Demo ให้อัตโนมัติ ไม่ต้องสนใจ เพราะเราจะเพิ่มบัญชีของเราเองในขั้นถัดไป

  3. เปิดหน้าล็อกอิน

    บนคอมพิวเตอร์ ไปที่เมนู File → Login to Trade Account บน iPhone ไปที่ Settings → New Account ส่วนบน Android ให้แตะเมนูด้านซ้าย เลือก Manage accounts แล้วแตะปุ่ม + มุมบน

  4. ค้นหาเซิร์ฟเวอร์ของโบรกเกอร์

    บนมือถือ พิมพ์ชื่อโบรกเกอร์อย่างน้อย 3 ตัวอักษรในช่องค้นหา แล้วเลือกเซิร์ฟเวอร์ให้ตรงกับที่ได้รับ บนคอม ให้เลือกจากช่อง Server ถ้าไม่มีชื่อเซิร์ฟเวอร์ในรายการ ให้เปิด File → Open an Account แล้วพิมพ์ชื่อโบรกเกอร์ในช่องค้นหา โปรแกรมจะดึงรายชื่อเซิร์ฟเวอร์มาเพิ่ม จากนั้นกด Cancel แล้วกลับไปหน้าล็อกอินใหม่

  5. กรอก Login, Password และ Server

    กรอกเลขบัญชีและรหัสผ่านอย่างระมัดระวัง ตรวจภาษาแป้นพิมพ์ให้เป็นภาษาอังกฤษ และระวังตัวพิมพ์เล็ก-ใหญ่ แนะนำให้ติ๊ก Save password บนเครื่องที่รัน EA เพื่อให้ MT5 เชื่อมต่อบัญชีเองทุกครั้งที่เปิดโปรแกรมใหม่ จากนั้นกด OK หรือ Login

  6. ตรวจสถานะการเชื่อมต่อ

    บนคอม ดูที่มุมขวาล่างของโปรแกรม ถ้าเชื่อมต่อสำเร็จจะเห็นตัวเลขปริมาณข้อมูลที่รับ-ส่งเป็นหน่วย kb เพิ่มขึ้นเรื่อย ๆ และราคาใน Market Watch ขยับ ถ้าขึ้นว่า Invalid account แปลว่าเลขบัญชี รหัสผ่าน หรือเซิร์ฟเวอร์ไม่ถูก ถ้าขึ้น No connection แปลว่ายังติดต่อเซิร์ฟเวอร์ไม่ได้ ดูรายละเอียดเพิ่มได้ในแท็บ Journal ของหน้าต่าง Toolbox (กด Ctrl+T) บนมือถือ ให้ดูว่ามียอดเงินแสดงในแท็บ Trade และราคาใน Quotes ขยับตามตลาด

เข้าใช้ MT5 บน Windows

คอมพิวเตอร์ Windows คือที่ที่ EA ทำงานได้จริง จึงควรตั้งค่าให้เรียบร้อยที่สุด แนะนำ Windows 10 หรือ 11 แบบ 64 บิต หรือ Windows Server บน VPS นอกจากเมนู File แล้ว คุณยังล็อกอินได้จากหน้าต่าง Navigator (กด Ctrl+N) โดยคลิกขวาที่หัวข้อ Accounts แล้วเลือก Login to Trade Account

MT5 หนึ่งโปรแกรมเชื่อมต่อได้ครั้งละหนึ่งบัญชี ถ้าต้องการรัน EA บนสองบัญชีพร้อมกัน ให้ติดตั้ง MT5 อีกชุดในโฟลเดอร์แยก แล้วล็อกอินคนละบัญชี การสลับบัญชีไปมาในโปรแกรมเดียวจะทำให้ EA ของบัญชีก่อนหน้าหยุดทำงาน

เข้าใช้ MT5 บน Android

ติดตั้งแอป MetaTrader 5 จาก Google Play แล้วเปิดเมนูด้านซ้าย เลือก Manage accounts จะเห็นรายการบัญชีที่เคยเพิ่มไว้ แตะ + เพื่อค้นหาโบรกเกอร์ จากนั้นกรอกข้อมูลในส่วนของบัญชีที่มีอยู่แล้ว (Use existing account) แตะ Login เมื่อต้องการสลับบัญชีในภายหลัง ให้กลับมาที่ Manage accounts แล้วแตะบัญชีที่ต้องการ

แอปบน Android เหมาะกับการดูยอดเงิน ออเดอร์ที่เปิดอยู่ ประวัติการเทรด และกราฟราคา ระหว่างที่ EA ทำงานอยู่บนคอมหรือ VPS

เข้าใช้ MT5 บน iPhone และ iPad

บน iPhone และ iPad ใช้แอป MetaTrader 5 ตัวเดียวกันจาก App Store เข้าแท็บ Settings แล้วแตะ New Account ค้นหาชื่อโบรกเกอร์ เลือกเซิร์ฟเวอร์ กรอกข้อมูลในส่วนบัญชีที่มีอยู่แล้ว แล้วแตะ Sign In บัญชีที่ใช้อยู่จะแสดงอยู่ด้านบนของหน้า Settings แตะที่บัญชีนั้นเพื่อดูรายการบัญชีทั้งหมดและสลับบัญชีได้

บน iPad หน้าจอกว้างกว่า ดูกราฟและรายการออเดอร์ได้สะดวกขึ้น แต่ข้อจำกัดเหมือนกับ iPhone ทุกอย่าง คือใช้ติดตามและเทรดด้วยมือได้ แต่รัน EA ไม่ได้

รหัสผ่านหลัก (Master) กับรหัสผ่านนักลงทุน (Investor) ต่างกันอย่างไร

บัญชี MT5 มีรหัสผ่านสองแบบ ใช้กับเลขบัญชีเดียวกันแต่ได้สิทธิ์ไม่เท่ากัน

  • รหัสผ่านหลัก (Master Password) ให้สิทธิ์เต็ม เปิด-ปิดออเดอร์ แก้ Stop Loss และใช้ EA ส่งคำสั่งเทรดได้ เครื่องที่รัน EA ต้องล็อกอินด้วยรหัสนี้
  • รหัสผ่านนักลงทุน (Investor Password) เป็นแบบอ่านอย่างเดียว เห็นยอดเงิน ออเดอร์ และประวัติ แต่ส่งคำสั่งเทรดไม่ได้

อย่าให้รหัสผ่านหลักกับใคร ไม่ว่าจะอ้างว่าเป็นทีมงาน โค้ช หรือผู้ดูแลบัญชี เพราะผู้ที่มีรหัสนี้เปิดและปิดออเดอร์แทนคุณได้ทั้งหมด ถ้าต้องการให้ทีมงานช่วยตรวจบัญชี ให้ส่งเลขบัญชี ชื่อเซิร์ฟเวอร์ และรหัสผ่านนักลงทุนแทน

ตั้งหรือเปลี่ยนรหัสผ่านนักลงทุนได้ใน MT5 บนคอม โดยไปที่ Tools → Options → แท็บ Server แล้วกดปุ่ม Change ใส่รหัสผ่านหลักปัจจุบัน เลือก Change investor password แล้วตั้งรหัสใหม่ โบรกเกอร์บางแห่งให้ตั้งจาก Client Portal ได้ด้วย เมื่อตรวจบัญชีเสร็จแล้วจะเปลี่ยนรหัสนี้ใหม่อีกครั้งก็ได้

ล็อกอิน MT5 ไม่ได้ แก้อย่างไร

อาการสาเหตุที่เป็นไปได้วิธีแก้
ขึ้น Invalid account ทั้งที่มั่นใจว่ารหัสถูกเลือกเซิร์ฟเวอร์ผิด เช่น เอาบัญชีจริงไปล็อกอินเซิร์ฟเวอร์ Demo หรือเลือกเซิร์ฟเวอร์เบอร์อื่นเทียบชื่อเซิร์ฟเวอร์กับอีเมลหรือ Client Portal ให้ตรงทุกตัวอักษร รวมถึงตัวเลขท้ายชื่อ
ขึ้น Invalid accountใช้เลขผิด เช่น ใส่รหัสลูกค้าหรืออีเมลแทนเลขบัญชี MT5ใช้เลขบัญชีเทรดที่เป็นตัวเลขล้วน ดูได้จากหน้ารายการบัญชีใน Client Portal
รหัสผ่านไม่ผ่านใช้รหัสผ่าน Client Portal แทนรหัสบัญชีเทรด หรือพิมพ์ผิดตัวพิมพ์เล็ก-ใหญ่ใช้รหัสบัญชีเทรดที่ได้ตอนสร้างบัญชี ถ้าลืมให้รีเซ็ตใน Client Portal
คัดลอกมาวางแล้วไม่ผ่านมีช่องว่างเกินติดมาหน้าหรือหลังรหัส หรือแป้นพิมพ์เป็นภาษาไทยลบช่องว่างออก หรือพิมพ์เองทีละตัว และตรวจภาษาแป้นพิมพ์
ขึ้น No connectionอินเทอร์เน็ตหลุด Firewall หรือโปรแกรมป้องกันไวรัสบล็อก หรือเซิร์ฟเวอร์ปิดปรับปรุงตรวจอินเทอร์เน็ต ลองสลับ Wi-Fi กับเน็ตมือถือ บนคอมคลิกที่สถานะการเชื่อมต่อมุมขวาล่าง แล้วเลือก Rescan servers ให้โปรแกรมหาจุดเชื่อมต่อใหม่
เคยล็อกอินได้ แต่ตอนนี้ไม่ได้บัญชีถูกปิดใช้งานหรือเก็บถาวร (Archived) เพราะไม่มีการใช้งานนาน บัญชี Demo มักมีวันหมดอายุติดต่อฝ่ายบริการลูกค้าของโบรกเกอร์ หรือสร้างบัญชีใหม่ใน Client Portal
ล็อกอินไม่ได้เลยทั้งที่ข้อมูลถูกบัญชีเป็นแบบ MT4 ซึ่งล็อกอินใน MT5 ไม่ได้ตรวจประเภทแพลตฟอร์มใน Client Portal ถ้าเป็น MT4 ให้สร้างบัญชี MT5 ใหม่

ทำไมต้องเป็น MT5 ไม่ใช่ MT4

[falcon_brand] พัฒนาด้วยภาษา MQL5 สำหรับ MetaTrader 5 โดยเฉพาะ ไฟล์ EA ของ MT5 เป็นนามสกุล .ex5 ส่วน EA ของ MT4 เป็น .ex4 ทั้งสองแบบใช้แทนกันไม่ได้ และบัญชีเทรดของ MT4 กับ MT5 ก็แยกขาดจากกัน บัญชี MT4 จะล็อกอินในโปรแกรม MT5 ไม่ได้ ดังนั้นทั้งโปรแกรมและบัญชีต้องเป็น MT5 ทั้งคู่

มือถือล็อกอินได้ แต่รัน EA ไม่ได้

แอป MT5 บนมือถือไม่รองรับการรัน EA ไม่ว่าจะเป็น Android หรือ iPhone บอทเทรดทุกตัวต้องทำงานบน MT5 เวอร์ชันคอมพิวเตอร์ที่เปิดค้างไว้ หรือบน VPS ที่เปิดตลอด 24 ชั่วโมง มือถือจึงมีหน้าที่เป็นหน้าจอติดตามบัญชี

โดยทั่วไปคุณล็อกอินบัญชีเดียวกันพร้อมกันได้ทั้งบนคอมหรือ VPS และบนมือถือ สิ่งที่ควรระวังคือการปิดออเดอร์หรือแก้ Stop Loss ด้วยมือจากมือถือ เพราะอาจรบกวนตรรกะของ EA ถ้าไม่แน่ใจ ให้ถามทีมงานก่อนแทรกแซงออเดอร์ที่ EA เปิดไว้ ถ้าต้องการดูหน้าจอ MT5 บน VPS จากมือถือ ให้ใช้คู่มือ VPS บน Android หรือ VPS บน iPhone

คำถามที่พบบ่อยเรื่องการล็อกอิน MT5

ลืมรหัสผ่านบัญชี MT5 ต้องทำอย่างไร?

เข้า Client Portal ของโบรกเกอร์แล้วหาเมนูรีเซ็ตหรือเปลี่ยนรหัสผ่านบัญชีเทรด ถ้าไม่มีเมนูนี้ให้ติดต่อฝ่ายบริการลูกค้าของโบรกเกอร์ บัญชีเทรดเป็นของโบรกเกอร์ ไม่ใช่ของ MetaQuotes จึงต้องรีเซ็ตผ่านโบรกเกอร์เท่านั้น

ล็อกอินบัญชีเดียวกันหลายเครื่องพร้อมกันได้ไหม?

โดยทั่วไปทำได้ เช่น VPS หนึ่งเครื่องกับมือถืออีกเครื่อง แต่ควรรัน EA บนเครื่องเดียวเท่านั้น ถ้าเปิด EA ตัวเดียวกันบนบัญชีเดียวกันสองเครื่อง อาจได้ออเดอร์ซ้ำกันและความเสี่ยงเพิ่มขึ้นเป็นสองเท่า

ต้องล็อกอินใหม่ทุกครั้งที่เปิด MT5 ไหม?

ไม่ต้อง ถ้าติ๊ก Save password ตอนล็อกอิน MT5 จะเชื่อมต่อบัญชีล่าสุดให้เองเมื่อเปิดโปรแกรม ข้อนี้สำคัญมากบน VPS เพราะถ้าเครื่องรีสตาร์ตแล้ว MT5 ไม่ล็อกอินเอง EA จะไม่ทำงาน
