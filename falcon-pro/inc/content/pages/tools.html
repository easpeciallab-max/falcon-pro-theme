เครื่องมือคำนวณ Lot ในหน้านี้ช่วยให้ขนาด Lot สัมพันธ์กับความเสี่ยงที่คุณรับได้ในการเทรดที่ทุกไม้มีจุด Stop Loss และเครื่องมือคำนวณ Drawdown ช่วยให้เห็นว่าการติดลบแต่ละระดับต้องทำกำไรคืนมากแค่ไหน ซึ่งใช้ได้กับการเทรดทุกแบบ รวมถึง EA ที่ถือออเดอร์และเปิดออเดอร์แก้ซ้อนกัน

เครื่องมือคำนวณ Lot ตามความเสี่ยงต่อไม้

[falcon_calc type="lot"]

เครื่องมือนี้ใช้กับการเทรดที่กำหนดจุด Stop Loss ไว้ทุกไม้ หลักคิดคือกำหนดก่อนว่าถ้าไม้นี้โดน Stop Loss คุณยอมเสียเงินได้เท่าไร แล้วค่อยย้อนกลับมาหาขนาด Lot ไม่ใช่เลือก Lot ก่อนแล้วค่อยลุ้นว่าจะเสียเท่าไร สูตรที่ใช้คือ

Lot = (Balance × Risk%) ÷ (Stop Loss เป็น pip × Pip value ต่อ 1 Lot)

ตัวอย่างสมมติ

สมมติทุน 1,000 USD เสี่ยง 1% ต่อไม้ เท่ากับยอมเสียได้ 10 USD ตั้ง Stop Loss 50 pip กับคู่เงิน EURUSD บนบัญชีที่ใช้สกุล USD ซึ่งมี Pip value ราว 10 USD ต่อ 1 Lot ผลคือ 10 ÷ (50 × 10) = 0.02 Lot ตัวอย่างนี้แสดงแค่วิธีคิดเลข ไม่ได้แนะนำว่าควรตั้งค่าเท่านี้

Pip value ไม่เท่ากันทุกสัญลักษณ์

Pip value ต่างกันไปตามสัญลักษณ์ โบรกเกอร์ และสกุลเงินของบัญชี ตัวอย่างเช่น ทองคำ (XAUUSD) ที่หลายโบรกกำหนดขนาดสัญญา 100 ออนซ์ต่อ 1 Lot ราคาขยับ 1 USD เท่ากับกำไรหรือขาดทุนประมาณ 100 USD ต่อ 1 Lot แต่คำว่า 1 pip ของทองคำแต่ละโบรกนิยามไม่เหมือนกัน บางที่นับ 0.10 USD บางที่นับ 0.01 USD

เช็กค่าจริงของโบรกเกอร์คุณได้ใน MT5 โดยคลิกขวาที่สัญลักษณ์ในหน้าต่าง Market Watch แล้วเลือก Specification ดูค่า Contract size, Digits และ Tick size กับ Tick value (ถ้ามี) รวมถึง Minimal volume และ Volume step แล้วปัด Lot ที่คำนวณได้ลงให้ตรงกับขั้นที่โบรกเกอร์กำหนดเสมอ

Drawdown กับกำไรที่ต้องทำคืน

[falcon_calc type="drawdown"]

เมื่อบัญชีติดลบ ฐานเงินที่เหลือจะเล็กลง การกลับไปที่จุดเดิมจึงต้องใช้ % กำไรมากกว่า % ที่เสียไปเสมอ และยิ่งติดลบลึก ช่องว่างนี้ยิ่งกว้างแบบก้าวกระโดด สูตรคือ

กำไรที่ต้องทำคืน = DD ÷ (1 − DD) โดย DD คือ Drawdown ในรูปทศนิยม เช่น 20% = 0.20

Drawdownกำไรที่ต้องทำคืนตัวอย่างสมมติ ทุน 1,000 USD
10%11.1%เหลือ 900 USD ต้องทำเพิ่ม 100 USD
20%25%เหลือ 800 USD ต้องทำเพิ่ม 200 USD
30%42.9%เหลือ 700 USD ต้องทำเพิ่ม 300 USD
50%100%เหลือ 500 USD ต้องทำเพิ่มอีกเท่าตัว

ตัวเลขในตารางเป็นผลทางคณิตศาสตร์ล้วน ๆ ไม่ใช่ผลการเทรดของระบบใด สิ่งที่ควรจำคือการคุม Drawdown ไม่ให้ลึกสำคัญกว่าการไล่หากำไรคืนทีหลัง

ใช้สองเครื่องมือนี้ร่วมกันอย่างไร

ลองคิดย้อนจากชุดแพ้ติดกัน สมมติเสี่ยง 1% ต่อไม้แล้วแพ้ติดกัน 10 ไม้ บัญชีจะติดลบประมาณ 9.6% แต่ถ้าเสี่ยง 5% ต่อไม้ แพ้ 10 ไม้ติดกันเท่าเดิม บัญชีจะติดลบประมาณ 40.1% และต้องทำกำไรคืนราว 67% จึงจะกลับที่เดิม นี่คือเหตุผลที่ควรตั้ง % ความเสี่ยงต่อไม้ก่อน แล้วใช้เครื่องคำนวณ Lot ด้านบนหาขนาดที่สอดคล้องกัน

เวลาวางแผนการเทรดที่มี Stop Loss ทุกไม้กับบัญชีของตัวเอง ให้ไล่สี่ขั้นนี้ตามลำดับ ตัวเลขทุกตัวเป็นค่าที่คุณกำหนดเอง หน้านี้ไม่ได้แนะนำค่าใดให้

  1. ตั้งเพดานความเสียหายต่อไม้ เป็น % ของทุน โดยคิดจากเงินที่เสียได้จริง ไม่ได้คิดจากกำไรที่อยากได้
  2. สมมติชุดแพ้ติดกันให้ยาวไว้ก่อน ตั้งให้ยาวกว่าช่วงแพ้ที่ยาวที่สุดในรายงานทดสอบ เพราะตลาดจริงไม่จำเป็นต้องซ้ำรอยข้อมูลย้อนหลัง
  3. ประมาณยอดติดลบสะสมของชุดแพ้นั้น ด้วยวิธีคิดแบบเดียวกับตัวอย่างข้างบน แล้วใส่ลงในเครื่องคำนวณ Drawdown ถ้า % ที่ต้องทำคืนสูงเกินกว่าที่คุณรับไหว ให้ย้อนไปลดความเสี่ยงต่อไม้ในข้อแรก
  4. หาขนาด Lot ด้วยเครื่องคำนวณตัวแรก แล้วปัดลงให้ตรงกับ Volume step ของโบรกเกอร์ ไม่ปัดขึ้น

สองเรื่องที่สูตรยังไม่ได้นับให้

  • ต้นทุนการเทรด Spread และค่าคอมมิชชันถูกหักเพิ่มจากผลของสูตร ไม้ที่โดน Stop Loss จึงเสียมากกว่าตัวเลขที่คำนวณไว้เสมอ มากหรือน้อยขึ้นกับสัญลักษณ์และประเภทบัญชี
  • EA ที่ไม่ได้ตั้ง Stop Loss ต่อไม้ สูตรคำนวณ Lot ใช้ได้เฉพาะเมื่อทุกไม้มีจุด Stop Loss ให้กรอก EA ที่ถือออเดอร์ติดลบไว้แล้วเปิดออเดอร์แก้เพิ่มเป็นขั้น (กริดหรือมาร์ติงเกล) ไม่มีระยะ Stop Loss แบบนั้น ความเสี่ยงของ EA แบบนี้อยู่ที่ขนาด Lot รวมของออเดอร์ทุกขั้นเทียบกับเงินในบัญชี ไม่ได้อยู่ที่ไม้ใดไม้หนึ่ง

ถ้าใช้ [falcon_brand]: ชุด EA ของเราเป็นระบบแก้ออเดอร์แบบกริดที่ขยาย Lot และไม่ตัดขาดทุนเอง ผลจากเครื่องคำนวณ Lot ในหน้านี้จึงไม่ได้บอกความเสี่ยงของบัญชีที่รัน EA ชุดนี้ และไม่ใช่ค่าที่นำไปกรอกใน แดชบอร์ด ที่นั่นขนาด Lot ตั้งเองได้เฉพาะในชุดที่เปิดให้ตั้ง ส่วน FALCON 5.0 ระบบคิดขนาด Lot ให้เอง ให้ดูเงินที่แนะนำของแต่ละชุดในหน้าเลือก EA ของแดชบอร์ด อ่านหัวข้อวิธีแก้ออเดอร์ในหน้า ประกาศความเสี่ยง แล้วใช้เครื่องคำนวณ Drawdown ดูว่าการติดลบระดับที่คุณกังวลต้องทำกำไรคืนเท่าไร

อยากให้มีคนช่วยดูว่าทุนกับขนาด Lot หรือชุด EA ที่เลือกไปด้วยกันได้หรือไม่ ส่งตัวเลขให้ทีมงานทาง LINE ได้ ไม่ต้องส่งเลขบัญชีหรือรหัสผ่านใด ๆ

อ่านต่อเรื่อง Lot และ Drawdown

ถ้าอยากเข้าใจที่มาของตัวเลขในสองเครื่องมือนี้ให้ลึกขึ้น อ่านต่อได้ที่ วิธีคำนวณ Lot Size ให้เหมาะกับทุนและความเสี่ยง และ Drawdown คืออะไร และทำไมต้องคุมให้อยู่ ส่วนข้อควรรู้ก่อนใช้ EA กับเงินจริงรวมไว้ที่ ประกาศความเสี่ยง

ค่า Drawdown ในรายงานของ Strategy Tester มีหลายแบบและอ่านไม่เหมือนกัน วิธีดูแต่ละค่าอธิบายไว้ในหน้า Backtest EA บน MT5

คำถามที่พบบ่อย

ควรเสี่ยงกี่ % ต่อไม้?

ไม่มีตัวเลขที่ถูกกับทุกคน เทรดเดอร์จำนวนมากเริ่มศึกษาจากช่วงเล็ก ๆ เช่น 0.5–2% ต่อไม้ แต่ตัวเลขที่เหมาะกับคุณขึ้นกับทุน ประสบการณ์ ลักษณะกลยุทธ์ และ Drawdown ที่คุณรับได้จริง

EA คำนวณ Lot ให้อัตโนมัติ ยังต้องใช้เครื่องมือนี้ไหม?

ขึ้นกับว่า EA ตัวนั้นตั้ง Stop Loss ต่อไม้หรือไม่ ถ้าตั้ง ใช้เครื่องคำนวณ Lot ตรวจได้ว่าค่าที่ตั้งให้ความเสี่ยงต่อไม้ตรงกับที่คุณตั้งใจ ถ้า EA ถือออเดอร์ไว้และเปิดออเดอร์แก้ซ้อนกันหลายขั้น สูตรต่อไม้ใช้ไม่ได้ ต้องคิดจากขนาด Lot รวมของทุกออเดอร์เทียบกับเงินในบัญชี ส่วนเครื่องคำนวณ Drawdown ใช้ได้กับ EA ทุกแบบ

ทำไมผลจากเครื่องคำนวณไม่ตรงกับที่ MT5 แสดง?

สาเหตุหลักคือ Pip value และขนาดสัญญาของแต่ละโบรกไม่เท่ากัน การแปลงสกุลเงินของบัญชี Spread ตอนเปิดออเดอร์ และการปัดเศษ Lot ตาม Volume step ให้ยึดค่าจากหน้า Specification ของโบรกเกอร์คุณเป็นหลัก

บัญชีเป็นสกุลเงินอื่นที่ไม่ใช่ USD ใช้เครื่องคำนวณ Lot ได้ไหม?

ใช้ได้ หลักคือทุนกับ Pip value ต้องเป็นสกุลเงินเดียวกัน ให้กรอกทุนเป็นสกุลของบัญชี เลือกตัวเลือก "กำหนดมูลค่า pip เอง" แล้วใส่ Pip value ต่อ 1 Lot ที่แปลงเป็นสกุลของบัญชีแล้ว เช่น บัญชีสกุล THB ให้นำ Pip value ที่เป็น USD มาคูณอัตราแลกเปลี่ยน USD/THB ของวันนั้น อัตราแลกเปลี่ยนขยับทุกวัน ผลที่ได้จึงเป็นค่าประมาณ ควรคิดใหม่เมื่อค่าเงินเปลี่ยนไปมาก

คำเตือนความเสี่ยง: เครื่องมือเหล่านี้ช่วยคิดตัวเลขเท่านั้น ความเสี่ยงของตลาดไม่ได้ลดลงเพราะใช้เครื่องมือ การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง ขาดทุนได้ตั้งแต่บางส่วนจนถึงทั้งหมดของเงินทุน ราคาอาจกระโดดข้าม Stop Loss ทำให้ขาดทุนมากกว่าที่คำนวณไว้ และผลในอดีตไม่ใช่หลักประกันของผลในอนาคต
