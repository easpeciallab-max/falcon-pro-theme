ส่วนนี้ต่อจากขั้นตอนเข้า VPS บน iPhone และ iPad ด้านบน อธิบายการใช้นิ้วควบคุมหน้าจอ เรื่องแบตเตอรี่กับการแจ้งเตือนที่ผู้ใช้ iOS สงสัยบ่อย ความต่างระหว่างแอป MT5 บน iPhone กับ MT5 ที่รันบน VPS และตารางแก้ปัญหา

ควบคุมหน้าจอ VPS ด้วยนิ้วบน iPhone และ iPad

Windows App บน iOS มีโหมดการควบคุมให้เลือก 2 แบบ เปลี่ยนได้จากแถบเครื่องมือระหว่างใช้งาน

  • Direct touch นิ้วแตะจุดไหนก็เท่ากับคลิกจุดนั้น เหมาะกับการกดปุ่มใหญ่ ๆ หรือเลื่อนหน้าต่าง แตะค้างหนึ่งนิ้วคือคลิกขวา
  • Mouse pointer มีลูกศรเมาส์แสดงบนจอ ลากนิ้วเพื่อพาลูกศรไปวางแล้วแตะเพื่อคลิก แตะสองนิ้วพร้อมกันคือคลิกขวา แตะค้างสองนิ้วแล้วลากคือการเลื่อนหน้า และถ่างหรือจีบสองนิ้วเพื่อซูม โหมดนี้เหมาะกับปุ่มเล็ก ๆ ในแถบเครื่องมือของ MT5

ถ้าต้องพิมพ์ ให้แตะไอคอนคีย์บอร์ดบนแถบด้านบนเพื่อเรียกแป้นพิมพ์ขึ้นมา บน iPad ยังใช้ Trackpad หรือเมาส์ Bluetooth ได้ตามที่ iPadOS รองรับ ทำให้ใช้งานใกล้เคียงคอมมากขึ้น ส่วนบน iPhone การใช้นิ้วร่วมกับการซูมคือวิธีที่สะดวกที่สุด

บน iPhone ให้ใช้แนวนอนเสมอเวลาเปิด MT5 และซูมเข้าก่อนแตะปุ่มเล็กที่มุมจอ โดยเฉพาะแถวปุ่มมุมขวาบน ซึ่งมีปุ่มปิดโปรแกรมอยู่ใกล้กันจนแตะพลาดได้ง่าย

แบตเตอรี่และการแจ้งเตือน: สิ่งที่ผู้ใช้ iPhone ควรรู้

ปิดหน้าจอหรือสลับแอป EA ไม่หยุด

iOS จะพักการทำงานของแอปที่ไม่ได้อยู่บนหน้าจอ เมื่อคุณสลับไปแอปอื่นหรือล็อกจอ การเชื่อมต่อของ Windows App จะหลุดไปในไม่ช้า อาการนี้เป็นเรื่องปกติ ฝั่ง VPS จะเก็บเซสชันไว้ในสถานะตัดการเชื่อมต่อ MT5 และ EA ทำงานต่อไม่สะดุด เมื่อเปิดแอปแล้วแตะเชื่อมต่อใหม่ก็จะกลับมาที่หน้าจอเดิม

ใช้แบตเตอรี่มากกว่าแอปทั่วไป

ระหว่างเชื่อมต่อ แอปต้องรับภาพหน้าจอจาก VPS ตลอดเวลา จึงกินแบตและอินเทอร์เน็ตมากกว่าการเปิดแอปแชตหรือแอป MT5 ธรรมดา วิธีที่ดีคือเข้าไปเช็คให้เสร็จแล้วออกทันที ไม่เปิดค้างไว้ทั้งวัน การเปิดโหมดประหยัดพลังงานบน iPhone ไม่มีผลต่อ VPS เพราะ EA ไม่ได้ใช้แบตเตอรี่ของมือถือเลย

Windows App ไม่ส่งการแจ้งเตือนจาก MT5

Windows App เป็นเพียงหน้าจอระยะไกล จึงไม่แจ้งเตือนเมื่อมีออเดอร์ใหม่ ถ้าต้องการรับแจ้งเตือนบน iPhone ให้ใช้ระบบ Push Notification ของ MetaTrader 5 แทน โดยเปิดแอป MT5 บน iPhone เข้าส่วน Messages เพื่อดู MetaQuotes ID จากนั้นใน MT5 บน VPS ไปที่ Tools → Options → แท็บ Notifications ติ๊ก Enable Push Notifications แล้วใส่ MetaQuotes ID นั้น และอย่าลืมอนุญาตการแจ้งเตือนของแอป MetaTrader 5 ใน Settings ของ iPhone ประเภทการแจ้งเตือนที่ได้รับขึ้นกับตัวเลือกที่ตั้งไว้ใน MT5

แอป MT5 บน iPhone ต่างจาก MT5 บน VPS อย่างไร

หลายคนสับสนว่าทำไมต้องใช้สองแอป คำตอบคือแต่ละแอปทำหน้าที่ต่างกัน ตารางนี้สรุปให้เห็นชัดขึ้น

เรื่องแอป MT5 บน iPhoneMT5 บน VPS (ดูผ่าน Windows App)
รัน EAไม่ได้ได้ EA ทำงานอยู่ที่นี่
ดูยอดเงินและออเดอร์ได้ สะดวกและเร็วได้
ดูสถานะ EA เช่น ปุ่ม Algo Trading ไอคอนบนกราฟ และแท็บ Expertsไม่ได้ได้
ติดตั้งไฟล์ .ex5 หรือแก้ค่าของ EAไม่ได้ได้
รับ Push Notificationได้ ผ่าน MetaQuotes IDเป็นฝั่งที่ส่งการแจ้งเตือนออกไป
ต้องเปิดค้างไว้หรือไม่ไม่ต้องMT5 บน VPS ต้องเปิดตลอด แต่ Windows App บนมือถือไม่ต้องเปิดค้าง

สรุปง่าย ๆ ถ้าอยากรู้แค่ยอดเงินหรือกำไรขาดทุนของออเดอร์ เปิดแอป MT5 ก็พอ แต่ถ้าอยากรู้ว่าตัว EA ยังทำงานปกติหรือไม่ ต้องเข้าไปดูที่ VPS

ออกจากแอปได้ แต่ห้ามปิดระบบบน VPS

การปัดปิด Windows App หรือกดตัดการเชื่อมต่อจากเมนูของแอป ถือว่าปลอดภัย เซสชันบน VPS ยังอยู่ครบ สิ่งที่ต้องระวังคือคำสั่งที่ทำให้ Windows บน VPS ปิดโปรแกรมทั้งหมด

  • เลือก Sign out จากเมนู Start ของ VPS เพราะ MT5 จะถูกปิดไปด้วย
  • สั่ง Restart หรือ Shut down VPS โดยไม่ได้วางแผนว่าจะเข้าไปเปิด MT5 ใหม่
  • แตะโดนปุ่ม X ของหน้าต่าง MT5 บน VPS ซึ่งจะปิดโปรแกรมและหยุด EA ทันที

ตารางแก้ปัญหาบน iPhone และ iPad

อาการสาเหตุที่เป็นไปได้วิธีแก้
แอปแจ้งว่าเชื่อมต่อไม่ได้IP หรือพอร์ตผิด VPS ปิดอยู่ หรือเครือข่ายที่ใช้อยู่บล็อก Remote Desktopตรวจ IP ในรายการ PC ดูในแผงควบคุมว่า VPS เปิดอยู่ แล้วลองเปลี่ยนเครือข่าย เช่น จาก Wi-Fi เป็น 4G/5G
รหัสผ่านไม่ผ่านพิมพ์ผิด แป้นพิมพ์ขึ้นตัวพิมพ์ใหญ่ให้เอง หรือรหัสผ่าน VPS เพิ่งถูกเปลี่ยนแก้ไขบัญชีผู้ใช้ในแอปแล้วพิมพ์ใหม่ช้า ๆ หรือเลือก Ask when required เพื่อกรอกเองตอนเชื่อมต่อ
หลุดทุกครั้งที่สลับไปแอปอื่นiOS พักการทำงานของแอปที่อยู่เบื้องหลังเป็นเรื่องปกติ ไม่กระทบ EA เปิดแอปแล้วเชื่อมต่อใหม่ได้เลย
แป้นพิมพ์ไม่ขึ้นยังไม่ได้เรียกแป้นพิมพ์ หรือแถบเครื่องมือถูกซ่อนแตะไอคอนคีย์บอร์ดบนแถบด้านบนของเซสชัน
คลิกไม่โดนปุ่มที่ต้องการใช้โหมด Direct touch กับปุ่มที่เล็กมากสลับเป็น Mouse pointer และซูมเข้าก่อนแตะ
ตัวอักษรที่พิมพ์ไม่ตรงกับที่กดภาษาแป้นพิมพ์บน iPhone กับบน VPS ไม่ตรงกันสลับให้เป็นภาษาเดียวกันก่อนพิมพ์ โดยเฉพาะตอนกรอกรหัสผ่าน

คำถามที่พบบ่อยเรื่อง VPS บน iPhone

ใช้ iPad แทน iPhone ได้ไหม?

ได้ ใช้ Windows App ตัวเดียวกันและตั้งค่าแบบเดียวกัน iPad มีจอใหญ่กว่าจึงอ่านกราฟและแท็บต่าง ๆ ใน MT5 ได้สบายตากว่า และยังใช้ Trackpad หรือเมาส์ร่วมด้วยได้

ล็อกจอ iPhone หรือปัดแอปทิ้ง EA จะหยุดไหม?

ไม่หยุด EA ทำงานอยู่บน VPS ไม่ได้อยู่ในมือถือ การล็อกจอหรือปิดแอปเพียงแค่ตัดการเชื่อมต่อหน้าจอ ตราบใดที่ไม่ได้ Sign out หรือปิด MT5 บน VPS ระบบก็ทำงานต่อ

ใช้แอป MT5 บน iPhone รัน EA แทน VPS ได้ไหม?

ไม่ได้ แอป MetaTrader 5 บน iOS ไม่รองรับการรัน EA ใช้สำหรับดูยอดเงิน ดูออเดอร์ และเทรดด้วยมือเท่านั้น EA ต้องทำงานบน MT5 เวอร์ชันคอมพิวเตอร์หรือบน VPS

คำเตือนความเสี่ยง: การดูระบบผ่านมือถือช่วยให้ติดตามได้สะดวก แต่ไม่ได้ทำให้การเทรดปลอดภัยขึ้น Forex ทองคำ และ CFD ยังเป็นตลาดความเสี่ยงสูง อาจเสียเงินทุนไปบางส่วนหรือทั้งหมด EA ไม่ได้รับประกันกำไร และผลในอดีตไม่ได้เป็นหลักประกันของผลในอนาคต ควรตั้งรหัสล็อกหน้าจอ iPhone และเก็บรหัสผ่าน VPS เป็นความลับ
