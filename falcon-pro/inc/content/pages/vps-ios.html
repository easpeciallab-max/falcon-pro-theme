เข้า VPS บน iPhone หรือ iPad ได้ง่าย ๆ ผ่านแอป Windows App ของ Microsoft ทำให้คุณเปิดดูหน้าจอ MT5 ที่ EA กำลังทำงานอยู่ได้จากทุกที่ ไม่ต้องรอกลับถึงบ้าน คู่มือนี้อธิบายการตั้งค่าครั้งแรก การใช้งานด้วยนิ้ว เรื่องแบตเตอรี่กับการแจ้งเตือนที่ผู้ใช้ iOS มักสงสัย และความต่างระหว่างแอป MT5 บน iPhone กับ MT5 ที่รันอยู่บน VPS

สรุปสั้น: โหลด Windows App จาก App Store → กด + เลือก PC → ใส่ IP และบัญชีผู้ใช้ของ VPS → บันทึก → แตะเพื่อเชื่อมต่อและกดยอมรับใบรับรอง → ดู MT5 เสร็จแล้วออกจากแอปได้เลย EA บน VPS ยังทำงานต่อ

ก่อนเริ่ม VPS ของคุณควรมี MT5 และ EA ติดตั้งพร้อมใช้งานแล้ว ถ้ายังไม่ได้ตั้งค่า แนะนำให้ทำบนคอมพิวเตอร์ตามคู่มือ VPS บน Windows ก่อน เพราะการติดตั้งโปรแกรมและคัดลอกไฟล์บนจอใหญ่ทำได้สะดวกกว่ามาก

สิ่งที่ต้องมีก่อนเข้า VPS บน iPhone

  • iPhone หรือ iPad ที่อัปเดต iOS / iPadOS เป็นเวอร์ชันที่ Windows App รองรับ ดูได้ในหน้าแอปบน App Store
  • IP Address ของ VPS และเลขพอร์ตถ้าผู้ให้บริการกำหนดไว้
  • ชื่อผู้ใช้และรหัสผ่าน สำหรับเข้า Windows บน VPS ซึ่งเป็นชุดเดียวกับที่ใช้บนคอม
  • สัญญาณอินเทอร์เน็ตที่ใช้งานได้ต่อเนื่อง ไม่ว่าจะเป็น Wi-Fi หรือ 4G/5G
  • MT5 บน VPS เปิดอยู่และล็อกอินบัญชีเทรดเรียบร้อย

ขั้นตอนเชื่อมต่อ Windows VPS จาก iPhone และ iPad

ขั้นตอนเหมือนกันทั้ง iPhone และ iPad หน้าตาแอปอาจต่างไปเล็กน้อยเมื่อมีการอัปเดต ให้มองหาปุ่มที่มีความหมายเดียวกัน

  1. ดาวน์โหลด Windows App จาก App Store

    ค้นหาคำว่า Windows App ใน App Store แล้วตรวจชื่อผู้พัฒนาว่าเป็น Microsoft Corporation แอปนี้เข้ามาแทนแอป Remote Desktop ตัวเดิมที่ไม่เปิดให้ดาวน์โหลดแล้ว ถ้าเครื่องเคยมีแอปเก่าอยู่ ให้อัปเดตเป็นเวอร์ชันล่าสุด

  2. เปิดแอปและจัดการสิทธิ์

    ครั้งแรกแอปอาจขออนุญาตใช้ Bluetooth และเข้าถึงเครือข่ายในบ้าน (Local Network) Microsoft แนะนำให้กด Allow ทั้งสองข้อ จากนั้นดูหน้าแนะนำจนจบ หรือกด Skip เพื่อข้าม การเชื่อมต่อ VPS ด้วย IP ไม่ต้องล็อกอินบัญชี Microsoft

  3. กด + แล้วเลือก PC

    แตะเครื่องหมาย + แล้วเลือกเพิ่มเครื่องแบบ PC (บางเวอร์ชันใช้คำว่า Add PC) เพื่อเปิดหน้ากรอกข้อมูลเครื่องปลายทาง

  4. กรอก IP ในช่อง PC name

    พิมพ์ IP Address ของ VPS ถ้ามีพอร์ตให้พิมพ์ต่อท้ายด้วยโคลอน สามารถตั้ง Friendly name เป็นชื่อที่จำง่าย เช่น VPS EA เพื่อให้แยกออกเมื่อมีหลายเครื่อง

  5. ตั้งค่าบัญชีผู้ใช้แล้วบันทึก

    ในส่วนบัญชีผู้ใช้ (User Account หรือ Credentials) เลือกเพิ่มบัญชี แล้วกรอก Username และ Password ของ VPS หรือเลือก Ask when required ถ้าต้องการให้แอปถามรหัสผ่านทุกครั้งที่เชื่อมต่อ จากนั้นกด Save

  6. แตะเพื่อเชื่อมต่อและยอมรับใบรับรอง

    แตะรายการ VPS ที่เพิ่งสร้าง ถ้ามีหน้าต่างเตือนเรื่องใบรับรองของเครื่องปลายทาง ให้ตรวจว่า IP ถูกต้อง แล้วเปิดตัวเลือกไม่ต้องถามอีกสำหรับเครื่องนี้ กด Accept หรือ Continue สักครู่หน้าจอ Windows ของ VPS จะปรากฏขึ้น

ควบคุมหน้าจอ VPS ด้วยนิ้วบน iPhone และ iPad

Windows App บน iOS มีโหมดการควบคุมให้เลือก 2 แบบ เปลี่ยนได้จากแถบเครื่องมือระหว่างใช้งาน

  • Direct touch นิ้วแตะจุดไหนก็เท่ากับคลิกจุดนั้น เหมาะกับการกดปุ่มใหญ่ ๆ หรือเลื่อนหน้าต่าง แตะค้างหนึ่งนิ้วคือคลิกขวา
  • Mouse pointer มีลูกศรเมาส์แสดงบนจอ ลากนิ้วเพื่อพาลูกศรไปวางแล้วแตะเพื่อคลิก แตะสองนิ้วพร้อมกันคือคลิกขวา แตะค้างสองนิ้วแล้วลากคือการเลื่อนหน้า และถ่างหรือจีบสองนิ้วเพื่อซูม โหมดนี้เหมาะกับปุ่มเล็ก ๆ ในแถบเครื่องมือของ MT5

ถ้าต้องพิมพ์ ให้แตะไอคอนคีย์บอร์ดบนแถบด้านบนเพื่อเรียกแป้นพิมพ์ขึ้นมา บน iPad ยังใช้ Trackpad หรือเมาส์ Bluetooth ได้ตามที่ iPadOS รองรับ ทำให้ใช้งานใกล้เคียงคอมมากขึ้น ส่วนบน iPhone การใช้นิ้วร่วมกับการซูมคือวิธีที่สะดวกที่สุด

บน iPhone ให้ใช้แนวนอนเสมอเวลาเปิด MT5 และซูมเข้าก่อนแตะปุ่มเล็กที่มุมจอ โดยเฉพาะแถวปุ่มมุมขวาบน ซึ่งมีปุ่มปิดโปรแกรมอยู่ใกล้กันจนแตะพลาดได้ง่าย

แบตเตอรี่และการแจ้งเตือน: สิ่งที่ผู้ใช้ iPhone ควรรู้

ปิดหน้าจอหรือสลับแอป EA ไม่หยุด

iOS จะพักการทำงานของแอปที่ไม่ได้อยู่บนหน้าจอ เมื่อคุณสลับไปแอปอื่นหรือล็อกจอ การเชื่อมต่อของ Windows App จะหลุดไปในไม่ช้า อาการนี้เป็นเรื่องปกติ ฝั่ง VPS จะเก็บเซสชันไว้ในสถานะตัดการเชื่อมต่อ MT5 และ EA ทำงานต่อไม่สะดุด เมื่อเปิดแอปแล้วแตะเชื่อมต่อใหม่ก็จะกลับมาที่หน้าจอเดิม

ใช้แบตเตอรี่มากกว่าแอปทั่วไป

ระหว่างเชื่อมต่อ แอปต้องรับภาพหน้าจอจาก VPS ตลอดเวลา จึงกินแบตและอินเทอร์เน็ตมากกว่าการเปิดแอปแชตหรือแอป MT5 ธรรมดา วิธีที่ดีคือเข้าไปเช็คให้เสร็จแล้วออกทันที ไม่เปิดค้างไว้ทั้งวัน การเปิดโหมดประหยัดพลังงานบน iPhone ไม่มีผลต่อ VPS เพราะ EA ไม่ได้ใช้แบตเตอรี่ของมือถือเลย

Windows App ไม่ส่งการแจ้งเตือนจาก MT5

Windows App เป็นเพียงหน้าจอระยะไกล จึงไม่แจ้งเตือนเมื่อมีออเดอร์ใหม่ ถ้าต้องการรับแจ้งเตือนบน iPhone ให้ใช้ระบบ Push Notification ของ MetaTrader 5 แทน โดยเปิดแอป MT5 บน iPhone เข้าส่วน Messages เพื่อดู MetaQuotes ID จากนั้นใน MT5 บน VPS ไปที่ Tools → Options → แท็บ Notifications ติ๊ก Enable Push Notifications แล้วใส่ MetaQuotes ID นั้น และอย่าลืมอนุญาตการแจ้งเตือนของแอป MetaTrader 5 ใน Settings ของ iPhone ประเภทการแจ้งเตือนที่ได้รับขึ้นกับตัวเลือกที่ตั้งไว้ใน MT5

แอป MT5 บน iPhone ต่างจาก MT5 บน VPS อย่างไร

หลายคนสับสนว่าทำไมต้องใช้สองแอป คำตอบคือแต่ละแอปทำหน้าที่ต่างกัน ตารางนี้สรุปให้เห็นชัดขึ้น

สรุปง่าย ๆ ถ้าอยากรู้แค่ยอดเงินหรือกำไรขาดทุนของออเดอร์ เปิดแอป MT5 ก็พอ แต่ถ้าอยากรู้ว่าตัว EA ยังทำงานปกติหรือไม่ ต้องเข้าไปดูที่ VPS

ตรวจความพร้อมของ EA ทุกครั้งที่เข้า VPS

  • แถบเครื่องมือของ MT5 มีปุ่ม Algo Trading เป็นสีเขียว ถ้าเป็นสีแดงแปลว่าการเทรดอัตโนมัติถูกปิดอยู่
  • บนกราฟที่ติดตั้ง EA มุมขวาบนแสดงชื่อ EA และไอคอนสีฟ้า (รูปหมวก หรือหน้ายิ้มใน MT5 รุ่นเก่า) ไอคอนสีเทาแปลว่า EA ยังไม่ได้รับอนุญาตให้เทรด
  • เปิดแท็บ Experts และ Journal ใน Toolbox ดูข้อความล่าสุดว่าไม่มี Error ซ้ำ ๆ
  • มุมขวาล่างของ MT5 แสดงว่าเชื่อมต่ออยู่ ไม่มีคำว่า No connection
  • ตัวเลข Balance, Equity และ Margin ในแท็บ Trade สอดคล้องกับที่คาดไว้

ถ้าพบสิ่งผิดปกติ ให้แคปหน้าจอเก็บไว้ก่อน แล้วปรึกษาทีมงาน การรีบปิดออเดอร์หรือปิด EA ทันทีโดยไม่รู้สาเหตุ อาจทำให้สถานการณ์แย่ลงกว่าเดิม

ออกจากแอปได้ แต่ห้ามปิดระบบบน VPS

การปัดปิด Windows App หรือกดตัดการเชื่อมต่อจากเมนูของแอป ถือว่าปลอดภัย เซสชันบน VPS ยังอยู่ครบ สิ่งที่ต้องระวังคือคำสั่งที่ทำให้ Windows บน VPS ปิดโปรแกรมทั้งหมด

  • เลือก Sign out จากเมนู Start ของ VPS เพราะ MT5 จะถูกปิดไปด้วย
  • สั่ง Restart หรือ Shut down VPS โดยไม่ได้วางแผนว่าจะเข้าไปเปิด MT5 ใหม่
  • แตะโดนปุ่ม X ของหน้าต่าง MT5 บน VPS ซึ่งจะปิดโปรแกรมและหยุด EA ทันที

คำถามที่พบบ่อยเรื่อง VPS บน iPhone

ใช้ iPad แทน iPhone ได้ไหม?

ได้ ใช้ Windows App ตัวเดียวกันและตั้งค่าแบบเดียวกัน iPad มีจอใหญ่กว่าจึงอ่านกราฟและแท็บต่าง ๆ ใน MT5 ได้สบายตากว่า และยังใช้ Trackpad หรือเมาส์ร่วมด้วยได้

ล็อกจอ iPhone หรือปัดแอปทิ้ง EA จะหยุดไหม?

ไม่หยุด EA ทำงานอยู่บน VPS ไม่ได้อยู่ในมือถือ การล็อกจอหรือปิดแอปเพียงแค่ตัดการเชื่อมต่อหน้าจอ ตราบใดที่ไม่ได้ Sign out หรือปิด MT5 บน VPS ระบบก็ทำงานต่อ

ใช้แอป MT5 บน iPhone รัน EA แทน VPS ได้ไหม?

ไม่ได้ แอป MetaTrader 5 บน iOS ไม่รองรับการรัน EA ใช้สำหรับดูยอดเงิน ดูออเดอร์ และเทรดด้วยมือเท่านั้น EA ต้องทำงานบน MT5 เวอร์ชันคอมพิวเตอร์หรือบน VPS

คำเตือนความเสี่ยง: การดูระบบผ่านมือถือช่วยให้ติดตามได้สะดวก แต่ไม่ได้ทำให้การเทรดปลอดภัยขึ้น การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง คุณอาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด EA ไม่ได้รับประกันกำไร และผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต ควรตั้งรหัสล็อกหน้าจอ iPhone และเก็บรหัสผ่าน VPS เป็นความลับ

ติดขั้นตอนไหน หรือเห็นข้อความใน MT5 ที่ไม่แน่ใจ ส่งภาพหน้าจอมาให้ทีมงานช่วยอ่านได้ ไม่ต้องส่งรหัสผ่าน VPS มาในแชต
