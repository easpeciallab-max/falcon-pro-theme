ถ้า EA รันอยู่บน Windows VPS แล้ว คุณไม่จำเป็นต้องเปิดคอมทุกครั้งที่อยากดูสถานะ เพราะเข้า VPS บนมือถือ Android ได้ด้วยแอป Windows App ของ Microsoft (ชื่อเดิมคือ Remote Desktop) หน้านี้สอนตั้งแต่ติดตั้งแอป เพิ่มเครื่อง VPS เชื่อมต่อ ไปจนถึงวิธีใช้นิ้วควบคุมหน้าจอ และสิ่งที่ควรเช็คใน MT5 ทุกครั้งที่เข้าไปดู

สรุปสั้น: ติดตั้ง Windows App จาก Google Play → แตะ + แล้วเพิ่ม PC → ใส่ IP ของ VPS → เพิ่มชื่อผู้ใช้และรหัสผ่าน → แตะเชื่อมต่อแล้วยอมรับใบรับรอง → เช็ค MT5 เสร็จแล้วตัดการเชื่อมต่อ ห้าม Sign out

หน้านี้เหมาะกับคนที่ตั้ง VPS และติดตั้ง MT5 พร้อม EA เรียบร้อยแล้ว ถ้ายังไม่ได้ทำ ให้เริ่มจากคู่มือ VPS บน Windows ก่อน เพราะการตั้งค่าครั้งแรกทำบนคอมจะสะดวกกว่ามาก

เตรียมอะไรก่อนเข้า VPS บนมือถือ Android

  • มือถือหรือแท็บเล็ต Android ที่เข้า Google Play ได้ และมีพื้นที่ว่างพอสำหรับติดตั้งแอป
  • IP Address ของ VPS (รวมเลขพอร์ตถ้าผู้ให้บริการระบุมา)
  • Username และ Password สำหรับเข้า Windows บน VPS ชุดเดียวกับที่ใช้บนคอม
  • อินเทอร์เน็ตที่ค่อนข้างเสถียร จะเป็น Wi-Fi หรือเน็ตมือถือก็ได้
  • VPS ที่ติดตั้ง MT5 และ EA ไว้แล้ว และ MT5 เปิดอยู่

ขั้นตอนเชื่อมต่อ VPS ด้วย Windows App บน Android

ชื่อปุ่มในแอปอาจต่างกันเล็กน้อยตามเวอร์ชัน แต่ลำดับการทำงานเหมือนกัน

  1. ติดตั้ง Windows App จาก Google Play

    เปิด Google Play ค้นหาคำว่า Windows App แล้วดูให้แน่ใจว่าผู้พัฒนาคือ Microsoft Corporation ก่อนกดติดตั้ง ถ้าเคยมีแอป Remote Desktop ตัวเก่าอยู่แล้ว แอปนั้นจะถูกอัปเดตเป็น Windows App แทน

  2. เปิดแอปครั้งแรก

    แอปจะแสดงหน้าแนะนำการใช้งาน กด Skip หรือเลื่อนดูจนจบได้ การเชื่อมต่อ VPS ด้วย IP ไม่จำเป็นต้องล็อกอินบัญชี Microsoft หรือบัญชีที่ทำงาน ข้ามขั้นตอนนั้นไปได้

  3. แตะ + แล้วเลือกเพิ่ม PC

    แตะปุ่ม + ที่มุมบนของหน้าจอ แล้วเลือก Add PC (บางเวอร์ชันแสดงเป็น PC) เพื่อสร้างรายการเครื่องใหม่

  4. ใส่ IP ของ VPS

    กรอก IP Address ลงในช่อง PC name ถ้ามีเลขพอร์ตให้ใส่ต่อท้ายด้วยโคลอน ในส่วน Additional settings หรือตัวเลือกเพิ่มเติม ตั้งชื่อที่จำง่ายได้ เช่น VPS EA จะได้แยกออกถ้ามีหลายเครื่อง

  5. เพิ่มบัญชีผู้ใช้

    ในช่อง User account เลือกเพิ่มบัญชีผู้ใช้ (Add user account) แล้วกรอก Username และ Password ของ VPS จากนั้นบันทึก ถ้าไม่อยากให้แอปจำรหัสผ่าน จะเลือกให้ถามทุกครั้งตอนเชื่อมต่อก็ได้ แล้วกด Add หรือ Save เพื่อบันทึกรายการ

  6. เชื่อมต่อและยอมรับใบรับรอง

    ในแท็บ Devices แตะปุ่ม Connect บนการ์ดของ VPS แอปอาจถามว่าเชื่อถือเครื่องปลายทางหรือไม่ และขึ้นคำเตือนว่าตรวจสอบใบรับรองไม่ได้ ซึ่งเป็นเรื่องปกติของ VPS ตรวจ IP ให้ถูกต้อง ติ๊กไม่ต้องถามอีกสำหรับเครื่องนี้ แล้วกด Connect ไม่กี่วินาทีจะเห็นหน้าจอ Windows ของ VPS

ใช้นิ้วควบคุมหน้าจอ VPS ให้คล่อง

หน้าจอ Windows ออกแบบมาให้ใช้เมาส์ บนมือถือจึงต้องรู้ทริกเล็กน้อย Windows App มีโหมดการควบคุม 2 แบบ สลับได้จากแถบเครื่องมือของเซสชัน

  • โหมด Mouse pointer มีลูกศรเมาส์บนจอ ลากนิ้วเพื่อเลื่อนลูกศร แล้วแตะเพื่อคลิก เหมาะกับปุ่มเล็ก ๆ ใน MT5 เพราะคลิกได้แม่นกว่า
  • โหมด Direct touch แตะตรงไหนก็คือคลิกตรงนั้น ไม่มีลูกศร ใช้ง่ายแต่พลาดง่ายเมื่อปุ่มอยู่ชิดกัน
ต้องการทำท่าทางบนหน้าจอ
คลิกซ้ายแตะหนึ่งครั้งด้วยนิ้วเดียว
คลิกขวาแตะค้างด้วยนิ้วเดียว หรือแตะพร้อมกันสองนิ้ว (ในโหมด Mouse pointer)
เลื่อนขึ้น-ลง (Scroll)แตะค้างด้วยสองนิ้วแล้วลากขึ้นหรือลง
ซูมเข้า-ออกใช้สองนิ้วถ่างออกเพื่อซูมเข้า และจีบเข้าเพื่อซูมออก
เปิดคีย์บอร์ดแตะไอคอนคีย์บอร์ดบนแถบเชื่อมต่อด้านบน

หมุนมือถือเป็นแนวนอนจะเห็นหน้าจอ MT5 กว้างขึ้นมาก และก่อนแตะปุ่มที่อยู่มุมขวาบน ให้ซูมเข้าก่อนเสมอ เพราะปุ่มปิดโปรแกรม MT5 อยู่ใกล้ปุ่มอื่นจนแตะพลาดได้ง่าย

เชื่อมต่อได้จากมือถือ แต่ EA ไม่ได้รันบนมือถือ

ตอนที่ใช้ Windows App มือถือทำหน้าที่เป็นเพียงจอภาพและรีโมตสำหรับสั่งงาน VPS ตัวโปรแกรม MT5 และ EA ยังทำงานอยู่บน VPS เหมือนเดิม ต่อให้คุณปิดแอป ปิดหน้าจอ หรือมือถือแบตหมด EA ก็ยังทำงานต่อ

ต่างจากแอป MetaTrader 5 บน Android ซึ่งเป็นโปรแกรมเทรดบนมือถือโดยตรง แอปนั้นใช้ดูยอดเงินและออเดอร์ได้สะดวก แต่ติดตั้งหรือรัน EA ไม่ได้ ถ้าอยากดูแค่ยอดเงิน ใช้แอป MT5 ก็พอ แต่ถ้าต้องการดูสถานะของตัว EA หรือแก้การตั้งค่า ต้องเข้า VPS ผ่าน Windows App

เช็คอะไรบ้างเมื่อเข้า VPS จากมือถือ

เข้าไปแล้วใช้เวลาไม่ถึงนาทีตรวจรายการต่อไปนี้ ถ้าครบทุกข้อแปลว่าระบบพร้อมทำงาน

  • ปุ่ม Algo Trading บนแถบเครื่องมือด้านบนของ MT5 เป็นสีเขียว
  • มุมขวาบนของกราฟมีชื่อ EA พร้อมไอคอนสีฟ้า (รูปหมวก หรือหน้ายิ้มใน MT5 รุ่นเก่า) ถ้าไอคอนเป็นสีเทาหรือมีเครื่องหมายห้าม แปลว่ายังไม่อนุญาตให้ EA เทรด
  • แท็บ Experts และ Journal ในหน้าต่าง Toolbox ไม่มีข้อความ Error ซ้ำ ๆ หรือแจ้งว่าเชื่อมต่อไม่ได้
  • สถานะการเชื่อมต่อมุมขวาล่างไม่ขึ้น No connection หรือ Invalid account
  • ยอด Balance, Equity และ Margin ในแท็บ Trade อยู่ในระดับที่คาดไว้

ถ้าเห็นอะไรผิดปกติ อย่าเพิ่งปิดออเดอร์ด้วยความตกใจ ให้แคปหน้าจอ MT5 บน VPS ส่งให้ทีมงานดูก่อน แล้วค่อยตัดสินใจร่วมกัน

ออกจาก VPS อย่างไรไม่ให้ EA หยุด

เมื่อเช็คเสร็จ ให้ตัดการเชื่อมต่อด้วยเมนูของ Windows App (Disconnect) หรือจะปัดแอปทิ้งก็ได้ เซสชันบน VPS จะยังเปิดค้างอยู่และ EA ทำงานต่อ สิ่งที่ห้ามทำมีดังนี้

  • กด Start แล้วเลือก Sign out เพราะจะปิดทุกโปรแกรมรวมถึง MT5
  • สั่ง Shut down หรือ Restart VPS ถ้าไม่ได้ตั้งใจและไม่ได้เตรียมการไว้
  • กดปุ่ม X ของหน้าต่าง MT5 บน VPS แทนการตัดการเชื่อมต่อของแอป

ควรเข้าไปเช็คเมื่อไร

ไม่จำเป็นต้องเปิดดูทั้งวัน การเฝ้าจอบ่อยเกินไปมักทำให้อยากแทรกแซงระบบโดยไม่จำเป็น แนะนำให้เช็คสั้น ๆ ในจังหวะต่อไปนี้

  • วันละครั้งในเวลาที่สะดวก เพื่อดูว่า MT5 ยังเชื่อมต่อและ EA ยังทำงานอยู่
  • เช้าวันจันทร์หลังตลาดเปิด เพราะช่วงวันหยุดเป็นช่วงที่ VPS มักอัปเดตหรือรีสตาร์ต
  • หลังได้รับแจ้งจากผู้ให้บริการ VPS หรือโบรกเกอร์ว่ามีการปิดปรับปรุงระบบ
  • หลังเปลี่ยนการตั้งค่า EA หรือเปลี่ยนรหัสผ่านบัญชีเทรด

ความปลอดภัยเมื่อเข้า VPS จากมือถือ

มือถือหายหรือถูกคนอื่นหยิบไปใช้ได้ง่ายกว่าคอมพิวเตอร์ และ VPS ที่รัน EA ก็เชื่อมกับบัญชีเทรดจริง จึงควรป้องกันไว้ก่อน

  • ตั้งรหัสล็อกหน้าจอหรือสแกนลายนิ้วมือบนมือถือเสมอ
  • ถ้ามือถือเครื่องนั้นมีคนอื่นใช้ร่วม ให้เลือกให้แอปถามรหัสผ่านทุกครั้งแทนการบันทึกไว้
  • ถ้ามือถือหาย ให้เข้าคอมแล้วเปลี่ยนรหัสผ่าน VPS ทันที
  • ไม่ส่ง IP, Username และ Password ของ VPS ในแชตกลุ่มหรือโพสต์ที่คนอื่นเห็น

แก้ปัญหาที่พบบ่อยบน Android

  • เชื่อมต่อไม่ได้เลย: ตรวจ IP และพอร์ตในรายการ PC ว่าพิมพ์ถูก ดูในแผงควบคุมว่า VPS เปิดอยู่ ถ้าใช้ Wi-Fi สาธารณะให้ลองสลับเป็นเน็ตมือถือ เพราะบางเครือข่ายบล็อกการเชื่อมต่อแบบ Remote Desktop
  • รหัสผ่านไม่ผ่าน: เปิดเมนูของการ์ด VPS (ไอคอนจุดสามจุด) แล้วเลือกแก้ไข (Edit) เพื่อตรวจ Username และ Password ใหม่ ระวังแป้นพิมพ์มือถือที่ขึ้นตัวพิมพ์ใหญ่ให้อัตโนมัติ
  • หน้าจอเล็กจนอ่านไม่ออก: หมุนเป็นแนวนอน ใช้การซูม หรือปรับความละเอียดการแสดงผลในการตั้งค่าของรายการ PC นั้น
  • แตะแล้วคลิกผิดจุด: สลับไปใช้โหมด Mouse pointer แล้วเลื่อนลูกศรไปวางบนปุ่มก่อนแตะ
  • พิมพ์แล้วได้ตัวอักษรเพี้ยน: ภาษาของแป้นพิมพ์บนมือถือกับบน VPS ไม่ตรงกัน ให้สลับภาษาให้ตรงก่อนพิมพ์ โดยเฉพาะตอนกรอกรหัสผ่าน
  • หลุดบ่อยเมื่อสัญญาณอ่อน: ไม่กระทบ EA บน VPS รอให้สัญญาณดีขึ้นแล้วแตะเชื่อมต่อใหม่ จะกลับมาที่หน้าจอเดิม

คำถามที่พบบ่อยเรื่อง VPS บนมือถือ Android

ต้องมีบัญชี Microsoft เพื่อใช้ Windows App ไหม?

ไม่จำเป็น การเพิ่ม PC ด้วย IP Address แล้วเชื่อมต่อด้วย Username และ Password ของ VPS ใช้งานได้โดยไม่ต้องล็อกอินบัญชี Microsoft ในแอป

ใช้เน็ตมือถือเข้า VPS เปลืองเน็ตไหม?

ปริมาณข้อมูลขึ้นกับความถี่ที่หน้าจอเปลี่ยนและเวลาที่เปิดค้างไว้ การเข้าไปเช็คสั้น ๆ แล้วตัดการเชื่อมต่อใช้ข้อมูลไม่มาก แต่ถ้าเปิดหน้าจอค้างไว้นานก็จะใช้ข้อมูลมากขึ้นตาม

สลับเข้า VPS จากมือถือและคอมได้ไหม?

ได้ ถ้าใช้ชื่อผู้ใช้เดียวกัน การเชื่อมต่อจากอุปกรณ์ใหม่มักดึงเซสชันเดิมมาแสดง และอุปกรณ์ก่อนหน้าจะถูกตัดการเชื่อมต่อไปเอง ซึ่งไม่กระทบ MT5 และ EA ที่ทำงานอยู่บน VPS

คำเตือนความเสี่ยง: การเข้า VPS จากมือถือเป็นเพียงช่องทางติดตามระบบ ไม่ได้ลดความเสี่ยงของการเทรด การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง คุณอาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด EA ไม่ได้รับประกันกำไร และผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต อย่าบันทึกรหัสผ่าน VPS บนมือถือที่ผู้อื่นใช้ร่วม

ถ้าเชื่อมต่อไม่ได้ หรือไม่แน่ใจว่าหน้าจอ MT5 ที่เห็นปกติหรือไม่ ส่งภาพหน้าจอมาให้ทีมงานช่วยดูได้เลย
