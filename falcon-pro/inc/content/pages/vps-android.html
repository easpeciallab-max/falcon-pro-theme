ส่วนนี้ต่อจากขั้นตอนเข้า VPS บนมือถือ Android ด้านบน รวมวิธีใช้นิ้วควบคุมหน้าจอ ความต่างระหว่างแอป MT5 กับ MT5 บน VPS วิธีออกโดยไม่ให้ EA หยุด จังหวะที่ควรเข้าไปเช็ค เรื่องความปลอดภัย และวิธีแก้ปัญหาที่พบบ่อย

ใช้นิ้วควบคุมหน้าจอ VPS ให้คล่อง

หน้าจอ Windows ออกแบบมาให้ใช้เมาส์ บนมือถือจึงต้องรู้ทริกเล็กน้อย Windows App มีโหมดการควบคุม 2 แบบ สลับได้จากแถบเครื่องมือของเซสชัน

  • โหมด Mouse pointer มีลูกศรเมาส์บนจอ ลากนิ้วเพื่อเลื่อนลูกศร แล้วแตะเพื่อคลิก เหมาะกับปุ่มเล็ก ๆ ใน MT5 เพราะคลิกได้แม่นกว่า
  • โหมด Direct touch แตะตรงไหนก็คือคลิกตรงนั้น ไม่มีลูกศร ใช้ง่ายแต่พลาดง่ายเมื่อปุ่มอยู่ชิดกัน
ต้องการทำท่าทางบนหน้าจอ
คลิกซ้ายแตะหนึ่งครั้งด้วยนิ้วเดียว
คลิกขวาแตะค้างด้วยนิ้วเดียว หรือแตะพร้อมกันสองนิ้ว (ในโหมด Mouse pointer)
เลื่อนขึ้น-ลง (Scroll)แตะค้างด้วยสองนิ้วแล้วลากขึ้นหรือลง
ซูมเข้า-ออกใช้สองนิ้วถ่างออกเพื่อซูมเข้า และจีบเข้าเพื่อซูมออก
เปิดคีย์บอร์ดแตะไอคอนคีย์บอร์ดบนแถบเชื่อมต่อด้านบน

หมุนมือถือเป็นแนวนอนจะเห็นหน้าจอ MT5 กว้างขึ้นมาก และก่อนแตะปุ่มที่อยู่มุมขวาบน ให้ซูมเข้าก่อนเสมอ เพราะปุ่มปิดโปรแกรม MT5 อยู่ใกล้ปุ่มอื่นจนแตะพลาดได้ง่าย

เชื่อมต่อได้จากมือถือ แต่ EA ไม่ได้รันบนมือถือ

ตอนที่ใช้ Windows App มือถือทำหน้าที่เป็นเพียงจอภาพและรีโมตสำหรับสั่งงาน VPS ตัวโปรแกรม MT5 และ EA ยังทำงานอยู่บน VPS เหมือนเดิม ต่อให้คุณปิดแอป ปิดหน้าจอ หรือมือถือแบตหมด EA ก็ยังทำงานต่อ

ต่างจากแอป MetaTrader 5 บน Android ซึ่งเป็นโปรแกรมเทรดบนมือถือโดยตรง แอปนั้นใช้ดูยอดเงินและออเดอร์ได้สะดวก แต่ติดตั้งหรือรัน EA ไม่ได้ ถ้าอยากดูแค่ยอดเงิน ใช้แอป MT5 ก็พอ แต่ถ้าต้องการดูสถานะของตัว EA หรือแก้การตั้งค่า ต้องเข้า VPS ผ่าน Windows App

ออกจาก VPS อย่างไรไม่ให้ EA หยุด

เมื่อเช็คเสร็จ ให้ตัดการเชื่อมต่อด้วยเมนูของ Windows App (Disconnect) หรือจะปัดแอปทิ้งก็ได้ เซสชันบน VPS จะยังเปิดค้างอยู่และ EA ทำงานต่อ สิ่งที่ห้ามทำมีดังนี้

  • กด Start แล้วเลือก Sign out เพราะจะปิดทุกโปรแกรมรวมถึง MT5
  • สั่ง Shut down หรือ Restart VPS ถ้าไม่ได้ตั้งใจและไม่ได้เตรียมการไว้
  • กดปุ่ม X ของหน้าต่าง MT5 บน VPS แทนการตัดการเชื่อมต่อของแอป

ควรเข้าไปเช็คเมื่อไร

ไม่จำเป็นต้องเปิดดูทั้งวัน การเฝ้าจอบ่อยเกินไปมักทำให้อยากแทรกแซงระบบโดยไม่จำเป็น แนะนำให้เช็คสั้น ๆ ในจังหวะต่อไปนี้

  • วันละครั้งในเวลาที่สะดวก เพื่อดูว่า MT5 ยังเชื่อมต่อและ EA ยังทำงานอยู่
  • เช้าวันจันทร์หลังตลาดเปิด เพราะช่วงวันหยุดเป็นช่วงที่ VPS มักอัปเดตหรือรีสตาร์ต
  • หลังได้รับแจ้งจากผู้ให้บริการ VPS หรือโบรกเกอร์ว่ามีการปิดปรับปรุงระบบ
  • หลังเปลี่ยนการตั้งค่า EA หรือเปลี่ยนรหัสผ่านบัญชีเทรด

ความปลอดภัยเมื่อเข้า VPS จากมือถือ

มือถือหายหรือถูกคนอื่นหยิบไปใช้ได้ง่ายกว่าคอมพิวเตอร์ และ VPS ที่รัน EA ก็เชื่อมกับบัญชีเทรดจริง จึงควรป้องกันไว้ก่อน

  • ตั้งรหัสล็อกหน้าจอหรือสแกนลายนิ้วมือบนมือถือเสมอ
  • ถ้ามือถือเครื่องนั้นมีคนอื่นใช้ร่วม ให้เลือกให้แอปถามรหัสผ่านทุกครั้งแทนการบันทึกไว้
  • ถ้ามือถือหาย ให้เข้าคอมแล้วเปลี่ยนรหัสผ่าน VPS ทันที
  • ไม่ส่ง IP, Username และ Password ของ VPS ในแชตกลุ่มหรือโพสต์ที่คนอื่นเห็น

แก้ปัญหาที่พบบ่อยบน Android

อาการสาเหตุที่เป็นไปได้วิธีแก้
เชื่อมต่อไม่ได้เลยIP หรือพอร์ตในรายการ PC พิมพ์ผิด VPS ปิดอยู่ หรือ Wi-Fi สาธารณะกับ Wi-Fi ที่ทำงานบางแห่งปิดกั้น Remote Desktop ไว้ตรวจ IP และพอร์ตในรายการ PC ดูในแผงควบคุมว่า VPS เปิดอยู่ แล้วลองเปลี่ยนไปใช้เน็ตมือถือและต่อใหม่
รหัสผ่านไม่ผ่านUsername หรือ Password ที่บันทึกไว้ไม่ตรง หรือแป้นพิมพ์มือถือขึ้นตัวพิมพ์ใหญ่ให้อัตโนมัติเปิดเมนูของการ์ด VPS (ไอคอนจุดสามจุด) แล้วเลือกแก้ไข (Edit) เพื่อตรวจ Username และ Password ใหม่
หน้าจอเล็กจนอ่านไม่ออกหน้าจอ Windows ทั้งจอถูกย่อลงมาอยู่ในจอมือถือ ตัวหนังสือจึงเล็กตามหมุนเป็นแนวนอน ใช้การซูม หรือปรับความละเอียดการแสดงผลในการตั้งค่าของรายการ PC นั้น
แตะแล้วคลิกผิดจุดอยู่ในโหมด Direct touch ซึ่งนิ้วบังปุ่มเล็กที่อยู่ชิดกันสลับไปใช้โหมด Mouse pointer แล้วเลื่อนลูกศรไปวางบนปุ่มก่อนแตะ
พิมพ์แล้วได้ตัวอักษรเพี้ยนภาษาของแป้นพิมพ์บนมือถือกับบน VPS ไม่ตรงกันสลับภาษาให้ตรงกันก่อนพิมพ์ โดยเฉพาะตอนกรอกรหัสผ่าน
หลุดบ่อยเมื่อสัญญาณอ่อนสัญญาณ Wi-Fi หรือเน็ตมือถือขาดช่วงไม่กระทบ EA บน VPS รอให้สัญญาณดีขึ้นแล้วแตะเชื่อมต่อใหม่ จะกลับมาที่หน้าจอเดิม

ถ้าลองครบทุกแถวแล้วยังต่อไม่ติด หรือเปิดหน้าจอได้แต่เจอข้อความใน MT5 ที่ไม่คุ้น ทักทีมงานทาง LINE พร้อมภาพหน้าจอได้ ทั้งในภาพและในแชตต้องไม่มี IP ชื่อผู้ใช้ หรือรหัสผ่านของ VPS

คำถามที่พบบ่อยเรื่อง VPS บนมือถือ Android

ต้องมีบัญชี Microsoft เพื่อใช้ Windows App ไหม?

ไม่จำเป็น การเพิ่ม PC ด้วย IP Address แล้วเชื่อมต่อด้วย Username และ Password ของ VPS ใช้งานได้โดยไม่ต้องล็อกอินบัญชี Microsoft ในแอป

ใช้เน็ตมือถือเข้า VPS เปลืองเน็ตไหม?

ปริมาณข้อมูลขึ้นกับความถี่ที่หน้าจอเปลี่ยนและเวลาที่เปิดค้างไว้ การเข้าไปเช็คสั้น ๆ แล้วตัดการเชื่อมต่อใช้ข้อมูลไม่มาก แต่ถ้าเปิดหน้าจอค้างไว้นานก็จะใช้ข้อมูลมากขึ้นตาม

สลับเข้า VPS จากมือถือและคอมได้ไหม?

ได้ ถ้าใช้ชื่อผู้ใช้เดียวกัน การเชื่อมต่อจากอุปกรณ์ใหม่มักดึงเซสชันเดิมมาแสดง และอุปกรณ์ก่อนหน้าจะถูกตัดการเชื่อมต่อไปเอง ซึ่งไม่กระทบ MT5 และ EA ที่ทำงานอยู่บน VPS

คำเตือนความเสี่ยง: การเข้า VPS จากมือถือเป็นเพียงช่องทางติดตามระบบ ไม่ได้ลดความเสี่ยงของการเทรด ตลาด Forex ทองคำ และ CFD มีความเสี่ยงสูง เงินทุนที่ใช้เทรดอาจหายไปบางส่วนหรือทั้งก้อน EA ไม่ได้รับประกันกำไร และผลที่ผ่านมาไม่ได้รับรองผลในอนาคต อย่าบันทึกรหัสผ่าน VPS บนมือถือที่ผู้อื่นใช้ร่วม ความเสี่ยงด้านอื่นของการใช้ EA รวมไว้ในหน้า ประกาศความเสี่ยง
