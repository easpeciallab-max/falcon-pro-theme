ส่วนนี้อธิบายต่อจากขั้นตอนเชื่อมต่อด้านบน ว่าทำไม Windows VPS จึงสำคัญกับการรัน EA ควรเลือกสเปกแบบไหน ออกจาก VPS อย่างไรไม่ให้ EA หยุด ตั้งให้ MT5 เปิดเองหลังรีสตาร์ตอย่างไร และรวมวิธีแก้ปัญหาที่เจอบ่อย

ทำไม EA ต้องใช้ VPS

EA ดูแลออเดอร์ได้เฉพาะช่วงที่ MT5 ยังเปิดและต่อกับเซิร์ฟเวอร์โบรกเกอร์ได้ พอโปรแกรมปิดหรือเน็ตหลุด ระบบก็หยุดทำงานทันที และเรื่องแบบนี้มักเกิดในจังหวะที่ราคาวิ่งแรงพอดี

  • คอมที่บ้านดับหรือเข้าโหมด Sleep เพราะไฟตก โหมดประหยัดพลังงาน หรือ Windows Update สั่งรีบูตเครื่องเอง
  • อินเทอร์เน็ตบ้านหลุด แม้หลุดเพียงไม่กี่นาที EA ก็ส่งคำสั่งหรือปรับออเดอร์ไม่ได้ในช่วงนั้น
  • ระยะห่างถึงเซิร์ฟเวอร์โบรกเกอร์ ยิ่งไกล ค่า Latency ยิ่งสูง คำสั่งใช้เวลาเดินทางนานขึ้นและมีโอกาสเกิด Slippage มากขึ้น
  • ใช้เครื่องทำงานปนกับเรื่องส่วนตัว การเปิดโปรแกรมหนัก ๆ หรือปิดเครื่องโดยลืมไปว่า EA รันอยู่ เป็นความผิดพลาดที่เจอบ่อย

VPS ไม่ได้ทำให้ EA ทำกำไรได้มากขึ้น สิ่งที่ได้คือลดความเสี่ยงด้านเทคนิคที่ไม่เกี่ยวกับตลาด ทำให้ระบบทำงานตามกฎได้ต่อเนื่องตามที่ออกแบบไว้

เลือกสเปก Windows VPS อย่างไรให้พอดีกับ EA

EA ทั่วไปไม่ได้ใช้ทรัพยากรมาก แต่ Windows เองกินหน่วยความจำพอสมควร ตารางนี้เป็นแนวทางสำหรับการรัน MT5 จำนวนไม่มาก ถ้าต้องการรันหลายบัญชีหรือเปิดกราฟจำนวนมาก ให้เพิ่มสเปกตามสัดส่วน

หัวข้อแนวทางที่แนะนำเหตุผล
ระบบปฏิบัติการWindows Server เวอร์ชันที่ยังได้รับอัปเดต หรือ Windows 10/11MT5 เป็นโปรแกรมสำหรับ Windows ติดตั้งและดูแลง่ายที่สุด
หน่วยความจำ (RAM)2–4 GB สำหรับ MT5 ประมาณ 1–3 ตัวMT5 แต่ละตัวที่เปิดกราฟหลายหน้าใช้หน่วยความจำเพิ่มขึ้น RAM ไม่พอทำให้เครื่องหน่วงหรือโปรแกรมค้าง
หน่วยประมวลผล (CPU)1–2 vCPU ขึ้นไปเพียงพอสำหรับรัน EA ส่วนงานหนักอย่าง Strategy Tester หรือ Optimization ควรทำบนคอมของตัวเอง
พื้นที่เก็บข้อมูลSSD 30 GB ขึ้นไปเผื่อพื้นที่ให้ Windows อัปเดต ข้อมูลราคาย้อนหลัง และไฟล์ Log ที่เพิ่มขึ้นทุกวัน
ที่ตั้งเซิร์ฟเวอร์ (Location)ใกล้ศูนย์ข้อมูลของเซิร์ฟเวอร์โบรกเกอร์ค่า Ping ต่ำช่วยให้คำสั่งถึงโบรกเกอร์เร็วขึ้น สอบถามโบรกเกอร์ได้ว่าเซิร์ฟเวอร์ตั้งอยู่ที่ไหน
ความเสถียร (Uptime)ผู้ให้บริการที่ระบุ Uptime ชัดเจน มีระบบสำรองข้อมูลและช่องทางติดต่อ Supportถ้า VPS ล่ม EA ก็หยุดทำงานด้วย การแก้ปัญหาได้เร็วจึงสำคัญ
การเข้าถึงรองรับ Remote Desktop (RDP) และมี IP คงที่ใช้เชื่อมต่อจากคอม Windows, Android หรือ iPhone ได้ทุกที่

Disconnect กับ Sign out ต่างกันมาก

นี่คือจุดที่ผู้ใช้ใหม่พลาดบ่อยที่สุด การออกจาก VPS มีสองแบบ และผลต่อ EA ต่างกันคนละเรื่อง

  • Disconnect (ตัดการเชื่อมต่อ) คือกดปุ่ม X บนแถบเชื่อมต่อด้านบน หรือปิดหน้าต่าง Remote Desktop ตัวเครื่อง VPS ยังเปิดอยู่ ทุกโปรแกรมรวมถึง MT5 และ EA ทำงานต่อตามปกติ นี่คือวิธีที่ควรใช้ทุกครั้ง
  • Sign out (ออกจากระบบ) จากเมนู Start จะปิดทุกโปรแกรมในเซสชันนั้น MT5 ถูกปิดและ EA หยุดทำงานทันที
  • Shut down หรือ Restart ทำให้ VPS ดับหรือรีบูต EA หยุดจนกว่าจะเข้าไปเปิด MT5 ใหม่
  • กดปิดหน้าต่าง MT5 บน VPS ถ้าเผลอกด X ของโปรแกรม MT5 แทน X ของแถบเชื่อมต่อ EA จะหยุดเช่นกัน

ถ้าคุณกด Disconnect อย่างถูกต้องแล้ว แต่พบว่า MT5 ปิดไปเองทุกครั้ง อาจเป็นเพราะ VPS ตั้งเวลาปิดเซสชันที่ถูกตัดการเชื่อมต่อไว้ ให้แจ้งผู้ให้บริการตรวจการตั้งค่านี้

ตั้งให้ MT5 เปิดเองหลัง VPS รีสตาร์ต

VPS อาจรีสตาร์ตจากการอัปเดตหรือการบำรุงรักษาของผู้ให้บริการ เตรียมการไว้ล่วงหน้าจะช่วยให้ EA กลับมาทำงานเร็วขึ้น

  1. ใส่ทางลัด MT5 ในโฟลเดอร์ Startup บน VPS คลิกขวาที่ปุ่ม Start เลือก Run พิมพ์ shell:startup แล้วกด Enter จะเปิดโฟลเดอร์ Startup ขึ้นมา (ถ้ากด Windows + R ตอนที่หน้าต่างรีโมตไม่ได้อยู่ในโหมดเต็มจอ คีย์ลัดอาจไปเปิด Run ของเครื่องคุณเองแทน) จากนั้นคัดลอกไอคอนทางลัด MT5 จากหน้า Desktop มาวางในโฟลเดอร์นี้ MT5 จะเปิดเองทุกครั้งที่ผู้ใช้นี้เข้าสู่ระบบ
  2. ติ๊ก Save password ใน MT5 เพื่อให้ MT5 ล็อกอินบัญชีเองเมื่อเปิดขึ้นมา โปรแกรมจะจำกราฟและ EA ที่ติดตั้งไว้จากการปิดครั้งล่าสุด แต่ควรตรวจซ้ำทุกครั้งว่า Algo Trading ยังเป็นสีเขียว
  3. เข้า VPS ทุกครั้งหลังรีสตาร์ต โปรแกรมในโฟลเดอร์ Startup จะทำงานเมื่อมีการเข้าสู่ระบบเท่านั้น หลัง VPS รีสตาร์ต ให้เชื่อมต่อผ่าน Remote Desktop หนึ่งครั้ง รอให้ MT5 เปิดและเชื่อมต่อ แล้วกด Disconnect ออกมา ผู้ให้บริการบางรายตั้งระบบเข้าสู่ระบบอัตโนมัติให้ได้ สอบถามเพิ่มเติมได้
  4. จัดการ Windows Update เข้า Settings → Windows Update แล้วตั้ง Active hours ให้ครอบคลุมช่วงที่ตลาดเปิด และหมั่นอัปเดตหรือรีสตาร์ตเองในวันเสาร์-อาทิตย์ที่ตลาด Forex ปิด บน Windows Server เมนูอาจอยู่ใน Settings → Update & Security ไม่แนะนำให้ปิดการอัปเดตถาวร เพราะเครื่องที่ต่ออินเทอร์เน็ตตลอดควรได้รับแพตช์ความปลอดภัย

ยังมีจุดอื่นที่ควรตั้งหลังติดตั้งเสร็จ เช่น ปิดโหมดพักเครื่อง ลดการใช้แรมของ MT5 และสิ่งที่ต้องตรวจทุกครั้งหลังเครื่องรีบูต รวมไว้ใน เช็กลิสต์ตั้งค่า VPS ให้ MT5 รันต่อเนื่อง

แก้ปัญหา VPS ที่เจอบ่อย

อาการสาเหตุที่เป็นไปได้วิธีแก้
ขึ้นว่า Remote Desktop can't connect to the remote computerIP หรือพอร์ตผิด VPS ปิดอยู่หรือกำลังรีสตาร์ต หรือเครือข่ายที่ใช้อยู่บล็อกการเชื่อมต่อตรวจ IP และพอร์ต เปิด VPS จากแผงควบคุม รอสักครู่แล้วลองใหม่ หรือลองใช้อินเทอร์เน็ตอีกเครือข่าย
ขึ้นว่า Your credentials did not workชื่อผู้ใช้หรือรหัสผ่านผิด หรือ Windows ส่งชื่อผู้ใช้ของคอมเราไปแทนกด More choices → Use a different account แล้วพิมพ์ Username และ Password ของ VPS ใหม่
หน้าจอดำหรือค้างหลังล็อกอินVPS กำลังโหลดหรือติดตั้งอัปเดตรอ 1–2 นาที ถ้ายังค้างให้ Disconnect แล้วเชื่อมต่อใหม่ หรือสั่งรีสตาร์ตจากแผงควบคุม
MT5 ปิดไปเองหลังออกจาก VPSกด Sign out แทน Disconnect หรือ VPS ตั้งเวลาปิดเซสชันไว้ใช้ปุ่ม X บนแถบเชื่อมต่อเท่านั้น ถ้ายังเกิดซ้ำให้แจ้งผู้ให้บริการ
MT5 ไม่เปิดเองหลังรีสตาร์ตไม่มีทางลัดในโฟลเดอร์ Startup หรือยังไม่มีการเข้าสู่ระบบหลังรีสตาร์ตทำตามหัวข้อตั้งให้ MT5 เปิดเอง และเชื่อมต่อ VPS หนึ่งครั้งหลังรีสตาร์ตทุกครั้ง
VPS หน่วง ช้าRAM ไม่พอ เปิด MT5 หลายตัวหรือเปิดกราฟเยอะเกินไปปิดกราฟที่ไม่ใช้ ลดค่า Max. bars in chart ใน Tools → Options → Charts หรืออัปเกรด RAM
Ping ไปเซิร์ฟเวอร์โบรกเกอร์สูงVPS อยู่ไกลจากเซิร์ฟเวอร์โบรกเกอร์ดูค่า Ping จากสถานะการเชื่อมต่อมุมขวาล่างของ MT5 ถ้าสูงผิดปกติ ให้พิจารณาย้าย Location

คำถามที่พบบ่อยเรื่อง Windows VPS

ใช้คอมที่บ้านเปิดทิ้งไว้แทน VPS ได้ไหม?

ได้ แต่ต้องปิดโหมด Sleep ตั้งเวลาอัปเดตไม่ให้รีสตาร์ตเองช่วงตลาดเปิด และมีไฟฟ้ากับอินเทอร์เน็ตที่เสถียร ความเสี่ยงเรื่องไฟดับ เน็ตหลุด และการเผลอปิดเครื่องยังมีอยู่ VPS จึงเป็นทางเลือกที่ลดความเสี่ยงด้านเทคนิคได้มากกว่า

VPS หนึ่งตัวรัน MT5 ได้กี่บัญชี?

ขึ้นกับ RAM และจำนวนกราฟที่เปิด แนวทางทั่วไปคือ RAM 2–4 GB รองรับ MT5 ประมาณ 1–3 ตัว แต่ละบัญชีต้องติดตั้ง MT5 แยกโฟลเดอร์กัน เพราะ MT5 หนึ่งโปรแกรมล็อกอินได้ครั้งละหนึ่งบัญชี

ปิดคอมที่บ้านแล้ว EA บน VPS ยังทำงานไหม?

ยังทำงานต่อ ตราบใดที่คุณออกจาก VPS ด้วยการ Disconnect ไม่ใช่ Sign out คอมที่บ้านเป็นเพียงหน้าจอสำหรับเข้าไปดู ส่วน MT5 และ EA ทำงานอยู่บน VPS

ควรเข้าไปเช็ค VPS บ่อยแค่ไหน?

แนะนำให้เช็คสั้น ๆ วันละครั้ง และทุกครั้งหลังวันหยุดสุดสัปดาห์หรือหลังได้รับแจ้งว่ามีการบำรุงรักษา ดูว่า MT5 เชื่อมต่ออยู่ Algo Trading เป็นสีเขียว และแท็บ Experts กับ Journal ไม่มีข้อความผิดปกติ ทำจากมือถือได้ด้วยคู่มือ VPS บน Android หรือ VPS บน iPhone

คำเตือนความเสี่ยง: VPS ช่วยลดปัญหาด้านเทคนิค แต่ไม่ได้ลดความเสี่ยงของตลาด การเทรด Forex ทองคำ และ CFD ยังเสี่ยงสูงเท่าเดิม ขาดทุนได้ถึงเงินทุนทั้งหมดในบัญชี EA ไม่ได้รับประกันกำไร และผลในอดีตไม่ใช่หลักประกันของผลในอนาคต ควรติดตามบัญชีอย่างสม่ำเสมอและใช้เฉพาะเงินที่เสียได้
