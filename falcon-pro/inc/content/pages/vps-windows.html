VPS สำหรับ EA คือคอมพิวเตอร์เสมือนที่เปิดอยู่ในศูนย์ข้อมูลตลอด 24 ชั่วโมง ให้ MT5 และบอทเทรดทำงานต่อได้แม้คอมที่บ้านปิดอยู่ หน้านี้อธิบายว่าทำไม EA ควรอยู่บน VPS วิธีเลือกสเปก และขั้นตอนเชื่อมต่อจากคอม Windows ด้วยโปรแกรม Remote Desktop Connection ที่มีอยู่ใน Windows แล้ว

สรุปสั้น: เช่า Windows VPS ที่อยู่ใกล้เซิร์ฟเวอร์โบรกเกอร์ → เปิด Remote Desktop Connection บนคอม → ใส่ IP, Username, Password → ติดตั้ง MT5 และ EA บน VPS → เวลาออกให้กดปิดหน้าต่าง (Disconnect) ห้าม Sign out เพื่อให้ EA ทำงานต่อ

ทำไม EA ต้องใช้ VPS

EA ทำงานได้เฉพาะตอนที่ MT5 เปิดอยู่และเชื่อมต่อกับเซิร์ฟเวอร์ของโบรกเกอร์ ถ้าโปรแกรมปิดหรือเน็ตหลุด ระบบก็หยุดดูแลออเดอร์ทันที ซึ่งอาจเกิดขึ้นในจังหวะที่ราคาเคลื่อนไหวแรงพอดี

  • คอมที่บ้านดับหรือเข้าโหมด Sleep จากไฟตก การตั้งค่าประหยัดพลังงาน หรือ Windows รีสตาร์ตเพื่ออัปเดตเอง
  • อินเทอร์เน็ตบ้านหลุด แม้หลุดเพียงไม่กี่นาที EA ก็ส่งคำสั่งหรือปรับออเดอร์ไม่ได้ในช่วงนั้น
  • ระยะห่างถึงเซิร์ฟเวอร์โบรกเกอร์ ยิ่งไกล ค่า Latency ยิ่งสูง คำสั่งใช้เวลาเดินทางนานขึ้นและมีโอกาสเกิด Slippage มากขึ้น
  • ใช้เครื่องทำงานปนกับเรื่องส่วนตัว การเปิดโปรแกรมหนัก ๆ หรือปิดเครื่องโดยลืมไปว่า EA รันอยู่ เป็นความผิดพลาดที่เจอบ่อย

VPS ไม่ได้ทำให้ EA ทำกำไรได้มากขึ้น สิ่งที่ได้คือลดความเสี่ยงด้านเทคนิคที่ไม่เกี่ยวกับตลาด ทำให้ระบบทำงานตามกฎได้ต่อเนื่องตามที่ออกแบบไว้

เลือกสเปก VPS สำหรับ EA อย่างไรให้พอดี

EA ทั่วไปไม่ได้ใช้ทรัพยากรมาก แต่ Windows เองกินหน่วยความจำพอสมควร ตารางนี้เป็นแนวทางสำหรับการรัน MT5 จำนวนไม่มาก ถ้าต้องการรันหลายบัญชีหรือเปิดกราฟจำนวนมาก ให้เพิ่มสเปกตามสัดส่วน

หัวข้อแนวทางที่แนะนำเหตุผล
ระบบปฏิบัติการWindows Server เวอร์ชันที่ยังได้รับอัปเดต หรือ Windows 10/11MT5 เป็นโปรแกรมสำหรับ Windows ติดตั้งและดูแลง่ายที่สุด
หน่วยความจำ (RAM)2–4 GB สำหรับ MT5 ประมาณ 1–3 ตัวMT5 แต่ละตัวที่เปิดกราฟหลายหน้าใช้หน่วยความจำเพิ่มขึ้น RAM ไม่พอทำให้เครื่องหน่วงหรือโปรแกรมค้าง
หน่วยประมวลผล (CPU)1–2 vCPU ขึ้นไปเพียงพอสำหรับรัน EA ส่วนงานหนักอย่าง Strategy Tester หรือ Optimization ควรทำบนคอมของตัวเอง
พื้นที่เก็บข้อมูลSSD 30 GB ขึ้นไปเผื่อพื้นที่ให้ Windows อัปเดต ข้อมูลราคาย้อนหลัง และไฟล์ Log ที่เพิ่มขึ้นทุกวัน
ที่ตั้งเซิร์ฟเวอร์ (Location)ใกล้ศูนย์ข้อมูลของเซิร์ฟเวอร์โบรกเกอร์ค่า Ping ต่ำช่วยให้คำสั่งถึงโบรกเกอร์เร็วขึ้น สอบถามโบรกเกอร์ได้ว่าเซิร์ฟเวอร์ตั้งอยู่ที่ไหน
ความเสถียร (Uptime)ผู้ให้บริการที่ระบุ Uptime ชัดเจน มีระบบสำรองข้อมูลและช่องทางติดต่อ Supportถ้า VPS ล่ม EA ก็หยุดทำงานด้วย การแก้ปัญหาได้เร็วจึงสำคัญ
การเข้าถึงรองรับ Remote Desktop (RDP) และมี IP คงที่ใช้เชื่อมต่อจากคอม Windows, Android หรือ iPhone ได้ทุกที่

ข้อมูลที่จะได้รับจากผู้ให้บริการ VPS

หลังสั่งซื้อ ผู้ให้บริการจะส่งข้อมูลเข้าเครื่องมาทางอีเมลหรือแสดงในแผงควบคุม เตรียมข้อมูลเหล่านี้ไว้ก่อนเชื่อมต่อ

  • IP Address ตัวเลขรูปแบบ 203.0.113.10 บางเจ้าจะมีเลขพอร์ตต่อท้าย เช่น 203.0.113.10:3389 ให้ใช้ทั้งชุดตามที่ได้รับ
  • Username ชื่อผู้ใช้สำหรับเข้า Windows บน VPS มักเป็น Administrator หรือชื่อที่ผู้ให้บริการกำหนด
  • Password รหัสผ่านของผู้ใช้นั้น ควรเปลี่ยนใหม่หลังเข้าใช้งานครั้งแรก และเก็บไว้ในที่ปลอดภัย
  • ลิงก์แผงควบคุม (ถ้ามี) ใช้สั่งเปิด ปิด หรือรีสตาร์ต VPS เวลาที่เชื่อมต่อผ่าน Remote Desktop ไม่ได้

วิธีเชื่อมต่อ VPS สำหรับ EA จากคอม Windows

  1. เปิดโปรแกรม Remote Desktop Connection

    กดปุ่ม Start แล้วพิมพ์ค้นหาคำว่า Remote Desktop Connection หรือกด Windows + R แล้วพิมพ์ mstsc กด Enter โปรแกรมนี้มีมาให้ใน Windows อยู่แล้ว ไม่ต้องดาวน์โหลดเพิ่ม

  2. ใส่ IP ของ VPS

    พิมพ์ IP Address ลงในช่อง Computer ถ้าได้รับเลขพอร์ตมาด้วย ให้ใส่ต่อท้ายด้วยเครื่องหมายโคลอน เช่น 203.0.113.10:3389

  3. กด Show Options แล้วใส่ชื่อผู้ใช้

    กด Show Options ด้านล่างซ้ายเพื่อขยายหน้าต่าง แล้วกรอก Username ในช่อง User name ถ้าต้องการให้จำชื่อผู้ใช้ไว้ใช้ครั้งหน้า ให้ติ๊ก Allow me to save credentials และกด Save As เพื่อบันทึกไฟล์ทางลัดไว้บนหน้าจอ จากนั้นกด Connect

  4. กรอกรหัสผ่าน

    หน้าต่าง Windows Security จะขึ้นมาให้ใส่ Password ถ้าชื่อผู้ใช้ที่แสดงเป็นบัญชีของคอมเราเองแทนที่จะเป็นของ VPS ให้กด More choices แล้วเลือก Use a different account จากนั้นกรอกทั้ง Username และ Password ใหม่ ติ๊ก Remember me เฉพาะบนคอมส่วนตัวที่ไม่มีคนอื่นใช้

  5. ยอมรับคำเตือนใบรับรอง

    ครั้งแรกจะมีข้อความว่าไม่สามารถยืนยันตัวตนของเครื่องปลายทางได้ (The identity of the remote computer cannot be verified) เป็นเรื่องปกติของ VPS ส่วนใหญ่ ตรวจว่า IP ที่แสดงตรงกับของคุณ แล้วติ๊ก Don't ask me again for connections to this computer และกด Yes

  6. เข้าสู่หน้า Desktop ของ VPS

    เมื่อเชื่อมต่อสำเร็จ จะเห็นหน้าจอ Windows ของ VPS เต็มจอ พร้อมแถบเชื่อมต่อด้านบนสำหรับย่อหรือปิดหน้าต่าง การเข้าครั้งแรกอาจใช้เวลาโหลดสักครู่ และบน Windows Server อาจมีหน้าต่าง Server Manager เปิดขึ้นมาเอง ปิดไปได้ ถ้าต้องการสลับระหว่างเต็มจอกับหน้าต่างปกติ ให้กด Ctrl + Alt + Break

หลังเชื่อมต่อแล้ว ติดตั้ง MT5 และ EA บน VPS

ตอนนี้ VPS ก็เหมือนคอมอีกเครื่องที่คุณควบคุมจากระยะไกล ขั้นตอนต่อไปทำแบบเดียวกับคอมที่บ้าน

  • เปิดเบราว์เซอร์บน VPS แล้วดาวน์โหลด MT5 จากเว็บไซต์ทางการหรือจากโบรกเกอร์ จากนั้นติดตั้งให้เรียบร้อย
  • ล็อกอินบัญชีเทรดและติ๊ก Save password ตามคู่มือ ติดตั้งและล็อกอิน MT5
  • คัดลอกไฟล์ EA นามสกุล .ex5 จากคอมของคุณ แล้ววางบน VPS ได้เลย เพราะ Remote Desktop เปิดการแชร์ Clipboard ไว้เป็นค่าเริ่มต้น (ถ้าผู้ให้บริการไม่ได้ปิดไว้) หรือจะดาวน์โหลดไฟล์บน VPS โดยตรงก็ได้
  • ใน MT5 ไปที่ File → Open Data Folder → MQL5 → Experts วางไฟล์ แล้วติดตั้ง EA บนกราฟตามคู่มือ วิธีติดตั้ง EA บน MT5
  • ตรวจว่าปุ่ม Algo Trading เป็นสีเขียว และมีชื่อ EA แสดงที่มุมขวาบนของกราฟ

ถ้าเบราว์เซอร์บน Windows Server รุ่นเก่าไม่ยอมให้ดาวน์โหลดไฟล์ ให้ใช้วิธีคัดลอกไฟล์จากคอมของคุณไปวางแทน สะดวกและไม่ต้องไปแก้การตั้งค่าความปลอดภัยของเซิร์ฟเวอร์

Disconnect กับ Sign out ต่างกันมาก

นี่คือจุดที่ผู้ใช้ใหม่พลาดบ่อยที่สุด การออกจาก VPS มีสองแบบ และผลต่อ EA ต่างกันคนละเรื่อง

  • Disconnect (ตัดการเชื่อมต่อ) คือกดปุ่ม X บนแถบเชื่อมต่อด้านบน หรือปิดหน้าต่าง Remote Desktop ตัวเครื่อง VPS ยังเปิดอยู่ ทุกโปรแกรมรวมถึง MT5 และ EA ทำงานต่อตามปกติ นี่คือวิธีที่ควรใช้ทุกครั้ง
  • Sign out (ออกจากระบบ) จากเมนู Start จะปิดทุกโปรแกรมในเซสชันนั้น MT5 ถูกปิดและ EA หยุดทำงานทันที
  • Shut down หรือ Restart ทำให้ VPS ดับหรือรีบูต EA หยุดจนกว่าจะเข้าไปเปิด MT5 ใหม่
  • กดปิดหน้าต่าง MT5 บน VPS ถ้าเผลอกด X ของโปรแกรม MT5 แทน X ของแถบเชื่อมต่อ EA จะหยุดเช่นกัน

ถ้าคุณกด Disconnect อย่างถูกต้องแล้ว แต่พบว่า MT5 ปิดไปเองทุกครั้ง อาจเป็นเพราะ VPS ตั้งเวลาปิดเซสชันที่ถูกตัดการเชื่อมต่อไว้ ให้แจ้งผู้ให้บริการตรวจการตั้งค่านี้

ตั้งให้ MT5 เปิดเองหลัง VPS รีสตาร์ต

VPS อาจรีสตาร์ตจากการอัปเดตหรือการบำรุงรักษาของผู้ให้บริการ เตรียมการไว้ล่วงหน้าจะช่วยให้ EA กลับมาทำงานเร็วขึ้น

  1. ใส่ทางลัด MT5 ในโฟลเดอร์ Startup

    บน VPS กด Windows + R พิมพ์ shell:startup แล้วกด Enter จะเปิดโฟลเดอร์ Startup ขึ้นมา จากนั้นคัดลอกไอคอนทางลัด MT5 จากหน้า Desktop มาวางในโฟลเดอร์นี้ MT5 จะเปิดเองทุกครั้งที่ผู้ใช้นี้เข้าสู่ระบบ

  2. ติ๊ก Save password ใน MT5

    เพื่อให้ MT5 ล็อกอินบัญชีเองเมื่อเปิดขึ้นมา โปรแกรมจะจำกราฟและ EA ที่ติดตั้งไว้จากการปิดครั้งล่าสุด แต่ควรตรวจซ้ำทุกครั้งว่า Algo Trading ยังเป็นสีเขียว

  3. เข้า VPS ทุกครั้งหลังรีสตาร์ต

    โปรแกรมในโฟลเดอร์ Startup จะทำงานเมื่อมีการเข้าสู่ระบบเท่านั้น หลัง VPS รีสตาร์ต ให้เชื่อมต่อผ่าน Remote Desktop หนึ่งครั้ง รอให้ MT5 เปิดและเชื่อมต่อ แล้วกด Disconnect ออกมา ผู้ให้บริการบางรายตั้งระบบเข้าสู่ระบบอัตโนมัติให้ได้ สอบถามเพิ่มเติมได้

  4. จัดการ Windows Update

    เข้า Settings → Windows Update แล้วตั้ง Active hours ให้ครอบคลุมช่วงที่ตลาดเปิด และหมั่นอัปเดตหรือรีสตาร์ตเองในวันเสาร์-อาทิตย์ที่ตลาด Forex ปิด บน Windows Server เมนูอาจอยู่ใน Settings → Update & Security ไม่แนะนำให้ปิดการอัปเดตถาวร เพราะเครื่องที่ต่ออินเทอร์เน็ตตลอดควรได้รับแพตช์ความปลอดภัย

อาการสาเหตุที่เป็นไปได้วิธีแก้

ได้ แต่ต้องปิดโหมด Sleep ตั้งเวลาอัปเดตไม่ให้รีสตาร์ตเองช่วงตลาดเปิด และมีไฟฟ้ากับอินเทอร์เน็ตที่เสถียร ความเสี่ยงเรื่องไฟดับ เน็ตหลุด และการเผลอปิดเครื่องยังมีอยู่ VPS จึงเป็นทางเลือกที่ลดความเสี่ยงด้านเทคนิคได้มากกว่า

VPS หนึ่งตัวรัน MT5 ได้กี่บัญชี?

ขึ้นกับ RAM และจำนวนกราฟที่เปิด แนวทางทั่วไปคือ RAM 2–4 GB รองรับ MT5 ประมาณ 1–3 ตัว แต่ละบัญชีต้องติดตั้ง MT5 แยกโฟลเดอร์กัน เพราะ MT5 หนึ่งโปรแกรมล็อกอินได้ครั้งละหนึ่งบัญชี

ปิดคอมที่บ้านแล้ว EA บน VPS ยังทำงานไหม?

ยังทำงานต่อ ตราบใดที่คุณออกจาก VPS ด้วยการ Disconnect ไม่ใช่ Sign out คอมที่บ้านเป็นเพียงหน้าจอสำหรับเข้าไปดู ส่วน MT5 และ EA ทำงานอยู่บน VPS

ควรเข้าไปเช็ค VPS บ่อยแค่ไหน?

แนะนำให้เช็คสั้น ๆ วันละครั้ง และทุกครั้งหลังวันหยุดสุดสัปดาห์หรือหลังได้รับแจ้งว่ามีการบำรุงรักษา ดูว่า MT5 เชื่อมต่ออยู่ Algo Trading เป็นสีเขียว และแท็บ Experts กับ Journal ไม่มีข้อความผิดปกติ ทำจากมือถือได้ด้วยคู่มือ VPS บน Android หรือ VPS บน iPhone

คำเตือนความเสี่ยง: VPS ช่วยลดปัญหาด้านเทคนิค แต่ไม่ได้ลดความเสี่ยงของตลาด การเทรด Forex ทองคำ และ CFD มีความเสี่ยงสูง คุณอาจสูญเสียเงินทุนบางส่วนหรือทั้งหมด EA ไม่ได้รับประกันกำไร และผลในอดีตไม่ได้รับประกันผลลัพธ์ในอนาคต ควรติดตามบัญชีอย่างสม่ำเสมอและใช้เฉพาะเงินที่เสียได้

ถ้าตั้งค่า VPS แล้วยังไม่มั่นใจว่า EA ทำงานถูกต้อง แคปหน้าจอ MT5 บน VPS ส่งให้ทีมงานช่วยตรวจได้ (ห้ามส่งรหัสผ่าน VPS หรือรหัสผ่านหลักของบัญชีเทรดในแชต)
